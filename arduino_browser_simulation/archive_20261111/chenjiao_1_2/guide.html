Q03 Uno 与 ESP32 能直接互换代码吗？

Uno R3 官方硬件页确认 ATmega328P、14个数字引脚、6个模拟输入和16MHz时钟；ESP32是另一芯片家族。高层 Arduino API 类似，不代表引脚、电压、定时器、库和连接方式相同。

Q04 setup 和 loop 分别负责什么？

setup用于初始化，loop反复执行控制逻辑。当前首页片段只把LED写HIGH并delay，没有LOW，因此从这段文本不能断言它会闪烁。真正Blink必须有亮/灭两次写入和相应等待。

Q05 PWM 是否真的输出一个连续模拟电压？

通常不是，它在高低电平间切换，用占空比控制平均效果。LED亮度与电机速度会受负载、驱动和频率影响；不能把PWM引脚直接当电机供电，也不能把网页转速当实物转速。

Q06 如何从回波时间得到距离？

取声速343m/s这一教学假设，距离cm=回波微秒×0.0343÷2，除2是因为声波往返。实跑580μs得到9.947cm；温度、反射角度和超时会改变真实读数，此处没有标定。

Q07 交通灯的阈值如何写清楚？

练习定义小于20cm红灯、20到不足50cm黄灯、50cm及以上绿灯。边界样本19.9、20、49.9、50分别命中对应分支；每个输入只返回一个状态，避免独立if导致多灯同时亮。

Q08 为什么距离抖一下灯就闪？

阈值附近的噪声会使状态来回越线。演示输入19、21交替，无迟滞切换5次；把离开红灯阈值设23、进入红灯阈值设17后切换0次。这个结果来自自写模型，不是原站或硬件性能。

Q09 传感器没回波时能当0厘米吗？

不应默认如此。0可能是超时或故障码，需要独立unknown/fault状态，再根据用途选择停机或提示。主实验只覆盖有限有效数值，没有模拟全部故障；进一步应加入负数、非数值、断线和过期数据。

Q10 怎么知道真正学会而不是只看动画？

先预测每个边界样本的输出，再运行自己的代码核对CSV和断言；然后才去页面接线、运行并解释差异。网页交互、编译能力、真实电气安全和学习效果是四类不同证据，本批只完成数值层。
