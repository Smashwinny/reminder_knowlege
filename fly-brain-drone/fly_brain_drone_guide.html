疑问清单（12 问，从"这是真的吗"到"我自己能不能跑"）
01
"果蝇大脑开无人机"是真的吗？到底是什么开了无人机？

先说结论：是真的，但开的是"仿真里的无人机"，不是天上飞的真机。抖音这条视频（作者"阿博粒"）讲的硬核实验，源头是 2026 年 9 月海外开发者圈刷屏的一组工作：开发者在 X（推特）上展示"果蝇的连接组控制 FPV 无人机仿真——保持低空飞行，并主动躲开它看到的一切障碍"；随后开源社区出现了完整复刻仓库 ClutchMedia775/fly-brain-drone，README 第一句就是："果蝇大脑的完整接线图（FlyWire v783，138,639 个神经元、5400 万突触）作为脉冲 LIF 网络运行，接上一台仿真四旋翼。不训练任何参数。"

三个关键词把这事钉死：零训练（没有任何参数被梯度更新过）、零飞行代码（没有"见到障碍就左转"这种 if-else）、真实布线（神经网络的每一个连接都来自真实果蝇大脑的重建数据）。"会躲障碍"不是写出来的，也不是练出来的，而是从布线里涌现的。

🏠 类比你熟悉的东西：这就像把别人家已经布好线的整栋配电盘原样搬到自己家，通上电灯泡就亮——你没写任何"开灯逻辑"，灯亮是因为线本来就是那么接的。
02
"连接组"是什么？FlyWire 又是什么？14 万个神经元怎么数清楚的？

连接组（Connectome）= 一个大脑里所有神经元之间的全部连接关系，相当于大脑的"完整电路图"。拿到它要把果蝇大脑切成上万张纳米级切片、用电镜成像、再用算法+人力把每个神经元的每一段轮廓描出来。

FlyWire 是普林斯顿大学牵头的国际合作项目，2024 年发布成年黑腹果蝇（雌性）全脑连接组公开版 v783：138,639 个神经元，配套的细胞类型标注由 Schlegel et al. 2024 完成。这条数据链是整个"果蝇开无人机"的地基——没有 FlyWire，一切免谈。后来又有雄性全连接组 MaleCNS v1.0，无人机仓库用它做了第二套大脑的复刻验证。

我的实验一直接打开了这个数据文件：Completeness_783.csv 里不多不少正好 138,639 行，连接表 Connectivity_783.parquet 有 15,091,983 条聚合连接记录（"54M 突触"是切片级原始计数，15M 是按"神经元对+神经递质"聚合后的条目口径——同一个大脑，两种数法）。

📄 数据许可：FlyWire 连接组 CC BY 4.0，模型代码开源（philshiu/Drosophila_brain_model，360★）。这正是"一篇 Nature 论文 + 开源代码"能长出一整个玩家生态的原因。
03
有了电路图，怎么让大脑"跑"起来？LIF 神经元是什么？

连接组是静态的图，要"活"起来需要给每个神经元一个动力学模型。这个项目用的是最经典的 LIF（Leaky Integrate-and-Fire，泄漏积分发放）神经元。想象一个会漏水的杯子：

每个神经元记两个数：膜电位 v（水位）和 突触电流 g（刚倒进来的水）。水往上加、同时往"静息电位 −52mV"漏；碰到阈值 −45mV 就发放一个尖峰，然后清零重来，还有 2.2ms 不应期。整颗大脑 13 万个这样的杯子，按 FlyWire 的接线互相倒水——这就是全脑仿真。

⚠️ 我实验二踩的第一个坑就出在这：模型里有两个时间常数——t_mbr=20ms 管"水位怎么漏"，tau=5ms 管"刚倒进来的水怎么消失"。混用其中任何一个，整颗大脑直接静默。读参数要读每一行用在哪个变量上。
04
为什么完全不用训练？神经网络的"权重"从哪来？

深度学习里权重靠梯度下降练出来；这里权重直接照抄上帝的接线图：

连接强（突触多）权重就大；神经递质极性决定符号——兴奋性（如乙酰胆碱）记 +1，抑制性（如 GABA）记 −1。这三个信息全部来自对真实组织的测量，不含任何学习。

这也是为什么唯一有说服力的对照实验是打乱布线（shuffle）：每条突触保留自己的强度和符号，只把"接到哪"随机换掉。如果行为真来自布线，打乱后行为应当消失。实验三里官方 n=20 数据完全验证了这一点。

05
"刺激几个神经元 → 果蝇想吃糖"是怎么发生的？

Shiu et al. 2024（Nature）论文的招牌例子：人工激活 21 个糖感知神经元（模拟"尝到糖"），全脑仿真跑 1 秒，看MN9 运动神经元（管伸喙进食动作）的反应——论文用它证明这个粗糙的 LIF 模型能复现真实的感知运动通路。

我在实验二里用 numpy 手写了同一套 LIF 动力学，把 127,400 个神经元（论文用的 v630 版连接组）整个跑起来：

结果：基线（不刺激）0 Hz → 刺激 + 真实布线 MN9 每秒发放 102 次 → 刺激 + 打乱布线 0 次。信号能从"尝到糖"流到"伸出喙"，靠的就是那 59 条特定的两跳连接。

🔍 一个反直觉发现：糖感知神经元到 MN9 的直接突触是 0 条（实验一实测），全靠 286 个中转神经元接力；而且把布线打乱后"两跳内可达 MN9"的概率依然是 20/20——因为这张网太密了，谁都能绕到谁。布线的特异性不在"能不能到达"，而在"连接有多强"。这正是 shuffle 对照必须保留强度的原因。
06
无人机"看到的画面"怎么变成大脑的输入？looming 检测是什么？

仿真里无人机摄像头看到的障碍物，被解析成两组视觉神经元的激活频率（解析视网膜，不开真摄像头也能算）：

① looming 检测：东西在视野里越来越大 = 要撞上了。果蝇大脑里真有专管这事的回路——LPLC2 神经元只对"放大的运动"起反应，直接连到巨纤维（Giant Fiber, DNp01）逃逸通路。仿真喂给它逼近物体，它就亮。

② 旋转光流：整个视野往一个方向流 = 自己被风吹歪了。果蝇用 T4/T5 等运动检测神经元做光模反应（optomotor）自动回正——仿真喂给它旋转光流，无人机就稳住偏航。

实测：威胁从 az+30° 来时，有脑试次在 0.12 秒内下行神经元开始响应，转向指令峰值 1.00、逃逸爬升 0.88；无脑对照全部为 0（实验三实查逐帧日志）。

07
大脑的"决定"怎么变成无人机动作？整条链路长什么样？

要注意这条链上唯一不是来自果蝇的环节：DN 发放率到舵量的换算（Bridge）是工程化线性读出——但它的符号约定全部照抄果蝇电生理记录（同侧 DNa02 激活→同侧转向等），并且作者做了读出消融实验证明结论不依赖读出细节（见第 8 问）。这种"哪段是仿真生物、哪段是工程"的诚实标注，正是硬核实验和流量玄学的分界线。

08
怎么证明是"大脑在开"，而不是碰巧？

仓库作者设计了四组对照 × 每组 20 次飞行，我逐一从原始飞行日志里复核过（实验三）：

条件含义平均最近距离95% CI逃避成功率

shuffle1保强度换目标(种子1)0.59 m[0.33, 0.81]50%
shuffle2 / shuffle3同上(种子2/3)0.00 m[0, 0]0%

真布线显著甩开一切随机对照，置信区间完全不重叠。再叠加单变量消融：摘掉任何一个下行神经元（哪怕摘掉巨纤维 DNp01）避障照样成立（1.81~2.06m）——说明行为不是某一根"神线"撑起来的，而是分布式的；只有把全部转向读出摘掉，min_dist 才掉到 0.85m、转向指令归零。结论的鲁棒性做得很扎实。

所以……"果蝇大脑被上传了"？91% 是什么意思？

自媒体标题党说"果蝇大脑被完整上传，行为准确率 91%"。91% 的真实含义是：模型预测的神经响应与真实果蝇测量吻合的比例，不是"行为复刻率"，更不是"上传成功"。

冷静派（如 LessWrong《No, we haven't uploaded a fly yet》）的批评有四条，条条成立：① LIF 是粗糙简化——真实神经元有树突计算、离子通道动力学、神经调质；② 只有静态连接，缺神经调节状态；③ 无人机行为里的读出层是工程化的，行为好不等于大脑"懂"了飞行；④ 连接组是"死果蝇的解剖"，没有可塑性。

更准确的定位是：这是"连接组驱动的感知运动仿真"——从接线图预测功能的里程碑，但离数字生命还差几个数量级。看懂这个边界，比看懂"会开无人机"本身更有价值。

这件事对我这个工科生，真正值得带走的是什么？

① "先查证再转发"的完整示范：从一条抖音短视频出发，一路钉到 Nature 论文、360★ 官方代码、15M 行连接组数据、逐帧飞行日志——热点视频的每一句夸张说法都能被原始数据检验。

③ 涌现的直觉：不需要训练、不需要规则，"接线对 + 动力学对"就能出功能——对理解大模型为什么"会"做事是很好的对照物。

④ 量级感：14 万神经元在笔记本上毫秒级拍点可跑；人脑 860 亿神经元，直接差 8 个数量级——为什么"上传大脑"还早，心里有数了。

动手实验手册（三个实验，全部真机运行验证过）

实验一：解剖 138,639 个神经元的连接组

步骤 1 ｜ 操作：
git clone https://github.com/philshiu/Drosophila_brain_model repo # 371MB, 自带 v630/v783 连接组 git clone https://github.com/ClutchMedia775/fly-brain-drone drone_repo # 17MB, 仿真代码+飞行日志
目的：拿到原始连接组数据和无人机仿真代码。实现：两个仓库克隆成功（模型仓库 HEAD 91bdd1e，无人机仓库 d017a6c）。
步骤 2 ｜ 操作：python -X utf8 ex1_connectome_dissect.py ／ 目的：亲手数清"大脑里有什么"。
✅ 预期结果（实测）：v783 神经元总数 = 138,639（与 README 逐字一致）；连接条目 15,091,983；突触权重合计 10,496,512；中位出度 124 / 中位入度 14；糖感知→MN9 直接突触 = 0 条，经 286 个中转 2 跳可达；打乱布线 20/20 仍 2 跳可达 → 布线特异性在强度不在可达性。

实验二：numpy 手写 127,400 神经元全脑 LIF 仿真

步骤 1 ｜ 操作：python -X utf8 ex2_mini_brain_lif.py ／ 目的：不装 Brian2，把论文动力学原样复刻，验证"刺激糖感知→MN9 兴奋"且依赖真实布线。
步骤 2 ｜ 对照：同一代码跑三组——基线(不刺激) / 真实布线 / 打乱布线(保强度保符号换目标, seed=1)。
✅ 预期结果（实测，每次约 23s）：基线 MN9 0 Hz → 真实布线 + 糖刺激 → MN9 102 Hz（全脑总发放 16,067）→ 打乱布线 → MN9 0 Hz。行为差异完全由布线携带——这就是"零训练也会躲障碍"的最小复刻。
⚠️ 三个真实坑：① t_mbr=20ms 管膜积分、tau=5ms 管 g 衰减，两者混用整脑静默；② 论文 Poisson 驱动是直接加在膜电位 v 上（每事件 +68.75mV 必过阈），打在 g 上则驱动力不足；③ CSR 出边索引必须按突触前神经元排序——我曾按 postsynaptic 排序却按 presynaptive 建索引，传播全断（MN9 恒 0Hz），修正后立刻 102Hz。

实验三：无人机飞行日志取证

步骤 1 ｜ 操作：python -X utf8 ex3_flight_log_forensics.py ／ 目的：不动仿真器，直接用仓库自带的真实输出逐帧验证宣传结论。
步骤 2 ｜ 看什么：phase3 开环（有脑 vs 无脑）、phase4（真布线 vs 打乱）、phase56_summary.json（n=20 官方统计）、消融表。
✅ 预期结果（实测）：有脑避障 min(dist)=1.98m / 1.80m，无脑 0.00m 撞毁且 turn/gf 全程为 0；首次神经响应 t=0.12s；真布线平均 1.80m vs 打乱平均 0.30m；官方 n=20：real 逃避率 100% vs shuffle1 50% / shuffle2·3 0% / rand 0~50%；消融显示单摘任一下行神经元避障仍在（冗余），全摘转向读出才失效（0.85m）。
