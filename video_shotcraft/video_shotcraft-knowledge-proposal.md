## 建议新增的三个概念

### 1. 镜头配方三读契约

- 一句话：先用 Gallery 索引校验卡名与 style-key，再读配方卡的意图/参数/命门，最后按“参考实现”读取准确 demo TSX；卡片是语义地图，demo 才是调校参数真相。
- 领域：AI / 视频 / 动效资产工程。
- 关联：`[[补间动画与缓动函数]]`、`[[证据优先质检ProofOverClaims]]`、`[[风格即渲染器]]`。
- 本项目证据：`SKILL.md` 核心理念 6、`references/pipeline.md` 阶段 5、124 卡/150 镜头目录。

### 2. 音画双偏移钉帧

- 一句话：音效启动帧 = 目标峰值帧 − 音源内部峰值滞后 − 当前渲染管线输出音轨偏移；两项都靠实测，旧常数不能跨管线搬运。
- 领域：AI / 视频 / 声音工程。
- 关联：`[[React逐帧视频渲染]]`、`[[词锚定语义时间]]`、`[[事实与判断分离]]`。
- 本项目证据：`references/sound-design.md` §4.6；本实验三音源滞后 21.75/16.65/13.65f，三探针在 4.0.532 管线测得输出偏移约 0。
- 必带限制：10ms RMS/sample peak 不是 LUFS/true peak，不自动等于语义落点。

### 3. 同源可编辑视频清单

- 一句话：Main 与 `src/workbench.ts` 共享 SHOTS/SFX/CAPTIONS，镜头以 component+props+schema 拆成可编辑多轨，并以 original/imported 同帧像素对照证明拆解无损。
- 领域：AI / 视频 / 编辑工程。
- 关联：`[[分镜表驱动生成]]`（数据时间轴）、`[[JSON-IR类型化中间表示]]`（结构化中间表示）、`[[React逐帧视频渲染]]`（执行器）、`[[确定性脚本]]`。
- 本项目证据：`references/workbench.md`、`template/src/workbench.ts`、本实验 2+1+1+3 轨清单执行断言。
- 必带限制：清单结构通过不等于浏览器 UI 或官方 parity 通过。
