# Shotcraft learning lab

A six-second, deterministic Remotion experiment for the restored
`Vincentwei1021/video-shotcraft` repository at commit `1266a3e`.

The lab focuses on the project's additions rather than a generic Remotion tutorial:
one hero product-shot arc, a flash transition, measured SFX timing, and a workbench
manifest whose timing imports the same tables as the render.

The three MP3 files are historical Ink Press regression assets copied from the
upstream template. Their original attribution is retained in `public/audio/`.
They are not represented as newly sourced Freesound assets.
