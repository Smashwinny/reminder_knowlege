# 候选：把3D动效写成可随机寻址的时间函数

## 查重与定位
固定旧库SHA a8674777e18302b8804b137212b1396cbfe5a747；已读总览、[[Three.js与场景图]]、[[补间动画与缓动函数]]、[[分镜表驱动生成]]、[[确定性快进与真渲染取证]]、[[词锚定语义时间]]。这些概念不重复立题；以下为建议补充，不写入仓库。

## 一句话定义
离线动效将任意时刻t映射到完整画面和事件，不依赖上一帧的累计状态；渲染器负责资产就绪、快门曝光积分、编码和证据留痕。

## 建议新增/补充
### 随机寻址seek合约（补确定性取证）
__ready承诺字体/贴图/模型解码就绪；__seek(t)承诺本次完整状态已应用且绘制结束；__meta.dur声明时长。不按顺序调用仍得同一画面，是并行分帧与子帧运动模糊的前提。本次测试0→1.6→8.5→13与反序寻址数值完全一致；只是原创CPU场景，不代表上游任何页面都正确。

### 快门积分不是后期高斯模糊（补缓动函数）
180°快门在24fps下曝光窗口1/48秒；窗口内多次调用同一f(t)，先将sRGB解码成线性光，再平均，再编码回sRGB。黑白等权平均应约188而不是128，练习已实测。若窗口跨硬切，应分侧积分，否则凭空制造混帧；本次连续场景没有实现硬切检测，不能夸大为完整onetake渲染器。

### 音画使用同一事件表（补分镜表）
事件时间t同时映射到视频帧索引round(t·fps)和音频样本round(t·48000)，避免分别手调两个时钟。本次5事件样本量化误差0、PCM峰值0.452683、削波0；AAC后音频与视频均13秒并可完整解码。数值对齐不代表真人听感或实际设备延迟为0。

### 节奏/连贯/创意分开验收
onetake的rhythm.md公开案例中，节奏断言通过的片仍被认为PPT。节段长度变化、静止段和carry（跨段存续对象）只是辅助指标；0个边界的“全通过”尤其不是连贯证明。本练习参数边界差小于0.001，也不声称得到观众认可。
