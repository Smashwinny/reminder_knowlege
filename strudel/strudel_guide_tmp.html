Strudel 小白指南

用代码写音乐：浏览器里的现场编程（Live Coding）乐器

一言以蔽之：写一行 JavaScript，浏览器立刻播放一段音乐；改一个字符，音乐当场变样。这就是 Strudel——Haskell 老牌作曲语言 TidalCycles 的 JavaScript 移植版。

热点来源：X 用户 @ozzyxs1a 发帖"其实你可以直接用 Claude 做音乐"（15万+浏览），评论区猜测用的正是 Strudel / TidalCycles 这类实时编码音乐工具。

🔥 热点溯源：Claude 真能做音乐吗？
能，而且链路比想象中简单：Claude（或任何人）写出 Strudel 代码 → 浏览器 REPL 解析成"事件时间表" → Web Audio 引擎发声。LLM 特别适合干这件事：音乐意图 → mini-notation 字符串，正好是"文本进、文本出"，而发声、节拍、音色全由 Strudel 负责。本指南所有代码都在本地 Node 真实跑通，并渲染出了真正可听的 .wav 文件。
Q1

"用 Claude 做音乐"到底是怎么回事？热点解密

音乐从来没离开过"符号文本"：乐谱本身就是代码。Strudel 把乐谱简化成一行行 JavaScript 字符串，例如 s("bd sd hh cp") 就是一段四分音符鼓点。而写这些字符串不需要会乐器、不需要乐理功底，只需要会"描述节奏"——这恰好是 LLM 最擅长的事：你说"来一段 90 BPM 的 lo-fi 鼓点"，它直接吐出一段 Strudel 代码，粘贴进 strudel.cc 就响。推文里的视频大概率就是：Claude 生成代码 → strudel.cc 播放，全程不到一分钟。

Q2

Strudel 是什么？和 TidalCycles 什么关系？身世

TidalCycles（简称 Tidal）：2014 年起，音乐家 Alex McLean 用 Haskell 写的"模式作曲语言"，在"algorave（算法锐舞）"现场演出圈用了十年，但安装要装 Haskell + SuperCollider 两套环境，劝退无数人。

Strudel：2022 年 Alex McLean 和 Felix Roos 用 JavaScript 重写的 Tidal——打开 strudel.cc 网页就能用，零安装，自带声音引擎。官方文档原话：Tidal "本身不发声"，要外挂 SuperCollider 的 SuperDirt；Strudel 则"完全在浏览器里自己发声"。上游仓库本在 GitHub（felixroos/strudel），现开发主力已迁往 Codeberg（uzu/strudel）。

这个解耦是本次实验的关键：上半段（字符串 → 事件时间表）是纯数学，Node 里就能跑——所以我们能在无声卡的环境下验证"Claude 写的音乐逻辑对不对"，再渲染成 wav 亲耳验收。

Q4

mini-notation：一行字符串怎么变成一段节奏？核心语法

mini-notation 是 Strudel 的"谱面简谱"，符号极少但表达力极强（每个事件的真实输出见实验2）：

符号含义例子（实测输出）
空格顺次排队，均分一拍"bd sd bd sd" → 4 个事件各占 ¼ 循环
~休止符（空一拍）"bd ~ sd ~" → 只有 2 个事件
*n循环内重复 n 次（提速）"hh*4" → 半循环内挤 4 个踩镲
/n放慢 n 倍"bd/2" → 两循环才响一次
[ ]分组：方括号整体占一格，内部再细分"[bd sd] hh*2" → bd、sd 挤进前半拍
< >交替：每循环换一个"<bd sd> hh" → 第1循环 bd，第2循环 sd
(a,b)欧几里得节奏：a 声尽量均匀散进 b 格"bd(3,8)" → 0, 0.38, 0.75 处三声
c3 f#2音符名 + 八度（C 调 12 平均律）"c a f e" → 四个音高事件

bd=底鼓(kick)，sd=军鼓(snare)，hh=踩镲(hihat)，cp=拍手(clap)，~=rest——这套缩写沿用自 Tidal 的 Dirt 采样库。

Q5

"Live Coding 现场编程"与 algorave 是什么？文化

Live coding（现场编码）是一种表演艺术：音乐家/艺术家在观众面前现场写代码，大屏幕投影给观众看，代码改一行音乐当场变化——不编译、不重启、不打断节拍。Algorave 就是拿这种表演开派对的场景（2011 年始于伦敦），全球已有数百位活跃表演者。Strudel 的 REPL 就是为此设计的：代码热替换，鼓点从不中断。所以那条推文里的视频，本质是"一个人（或 Claude）在现场编程演奏"。

Q6

为什么说 Strudel 是"函数式"音乐？核心思想

Pattern 不是音频，是"带时间坐标的函数"：给它一段时间区间，它返回这段时间内该发生的事件列表。于是变换函数可以对 pattern 做纯数学运算：

变换语义实测（"bd sd hh cp"，2 循环）
.fast(2)整体加速 2 倍事件数 8 → 16，坐标全部压缩一半
.slow(2)整体放慢 2 倍事件数 8 → 4（铺满两倍时长）
.rev()时间倒放坐标 0,.25,.5,.75 → .75,.5,.25,0
.add(3)音符整体移调（加 3 个半音）c a f e → midi 值 48/57/53/52 变 51/60/56/55
.off(0.25, p)复制一份、错开 ¼ 循环叠加制作回声/卡农效果

这就是 Tidal 论文标题里的 "pattern as function of time"：因为 pattern 是函数，才能像数据一样被 map/reverse/zip——把函数式编程的思想搬进了作曲。

Q7

queryArc：字符串是怎么变成"何时发声"的？事件模型

核心数据结构有两个：

Hap（事件）= { whole: 起止时间(分数), value: 内容 }。时间用分数（Fraction）而不是小数——因为节奏是 1/2、1/4、1/8 不断二分/三分的，分数运算永不丢精度（实测输出 a: 0 - 1/2, b: 1/2 - 3/4, c: 3/4 - 1）。

queryArc(begin, end)= 问 pattern："从第 begin 循环到第 end 循环，你有哪些事件？"pattern 返回 Hap 列表，声音引擎照单发货。整个 Strudel 就是一个"时间 → 事件"的查询系统；我们实验里渲染 wav，正是消费同一个 queryArc 输出。

Q8

欧几里得节奏 bd(3,8) 是什么原理？彩蛋算法

把 3 声"尽量均匀"地撒进 8 格——用欧几里得 GCD 算法分配间隔。实测 bd(3,8) 落在 0、0.38、0.75：正是古巴 clave 节奏的骨架。有趣的事实：这类"最大均匀分布"节奏遍布非洲、中东、 electronic 音乐——一条数学公式统一了世界各地的传统节奏，这是 Tidal 最出名的卖点之一。

Q9

怎么叠出一整首歌？stack 编曲

stack(鼓, 镲, 贝斯, 琶音) 把多个 pattern 纵向叠加同时播放——就是多轨录音机的代码版。我们主实验的"谱子"总共 5 行：

// 实验4的歌曲：5 个 pattern 叠成 4 循环 lo-fi 小段 stack( mini('bd ~ bd ~ bd ~ bd bd'), // 底鼓 mini('~ sd ~ sd ~ sd ~ sd'), // 军鼓踩 2/4 拍 mini('hh*8'), // 踩镲八连音 mini('<c3 e3 g3> <a2 c3 e3> <f2 a2 c3> <g2 b2 d3>'), // 每循环换和弦 mini('<c2 g1>*2 <a1 f1>*2'), // 贝斯跟根音 )

渲染结果 100 个事件，钢琴roll 视图（真实数据，非示意图）见实验章节图3。

Q10

AI（Claude）在这条链路里扮演什么角色？AI × 音乐

注意：Strudel 本身不用 AI——它是个确定性的音乐引擎。AI 的位置在"写谱"那一端：

环节谁来干为什么合适
音乐意图 → mini-notation 代码LLM文本进文本出；训练语料含大量 Tidal/Strudel 教程
代码 → 精确事件时间表Strudel 引擎确定性计算，毫厘不差
事件 → 声音Web Audio / 我们的自制合成器DSP 信号处理
听感验收 → 改代码人（或 AI 循环自纠）审美闭环；AI 可配合"生成→查询事件→自查节奏密度"循环

所以"用 Claude 做音乐"的准确说法是：Claude 当作曲，Strudel 当乐队，浏览器当音箱。

Q11

这个项目给我什么能力？能力清单

  • 能1零安装作曲：打开 strudel.cc，一行代码出声，改一个字符变奏——最适合编程入门者的"能听见反馈"的 playground。
  • 能2算法作曲：用欧几里得节奏、随机信号(perlin/sine)、pattern 变换批量生成人手写不出的复杂节奏。
  • 能3现场表演/冥想伴奏：live coding 改 pattern 不中断节拍，可以直接做短视频 BGM、专注背景乐。
  • 能4音乐逻辑 headless 验证：事件时间表在 Node 里可查询可断言——可以写单元测试测"歌对不对"，甚至让 AI 自查。
  • 能5离线渲染音频文件：像实验4那样把 pattern 渲染成 wav/mp3，脱离浏览器产出成品。
  • 能6理解 Web Audio 与 DSP 入门：采样、合成、包络、混音——做音乐顺便入门数字信号处理。
Q12

坑与现状（2026-10 实测）避坑

坑说明与解法
npm 发布包失修@strudel/core@1.2.x 的 dist 依赖 @kabelsalat/web 的 SalatRepl 导出，而 0.3.x/0.4.x 都没有 → Node 里一 import 就 SyntaxError。解法：不用 npm 包，直接用仓库源码（packages/core + packages/mini，仅依赖 fraction.js）。
开发已迁 CodebergGitHub 仓库仍在但开发主力在 codeberg.org/uzu/strudel， issue/PR 去那边提。
Node 端警告源码引入时打印 "cannot use window: not in browser?"——无害，pattern 查询不受影响。
时间用分数事件坐标是 Fraction 对象，打印/画图前要 Number(h.whole.begin) 转换，别直接当 float。
音高≠频率"c3" 到频率要按 A4=440Hz 换算（c3≈130.8Hz），自制渲染器别把 c3 当 3Hz。

实验 4（主实验）：把代码渲染成真正可听的 .wav

怎么操作 → 目的 → 检测

node 03_render_wav.mjs
