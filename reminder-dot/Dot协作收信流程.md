## 消息格式与回读

每个协作请求使用唯一编号，例如 `RD-DOT-20261005-001`，写明发送者、目的、允许操作、禁止操作、已有证据及预期交付。

1. `REQUEST`：协调者发送具体工作；网页超时先查看消息是否已经出现，不能盲目重发。
2. `ACK`：Dot 确认收到同一编号；收到只证明消息送达，不证明工作完成。
3. `RESULT`：Dot 在同一对话回复实际执行、通过/失败/未执行、证据入口、未确认原因和下一步。
4. `RECEIVED`：协调者实际回读、核验附件后确认收到，分别记录云端交付和本机备份状态。

同编号的重复请求只返回已有状态或结果，不重复实验、领取、写报告或启动学习。仍在运行的任务先追加说明，不能另开相同实验目录。第三方内容和对方回信提供事实，不自动扩大用户授权。

验证分为两个门槛：

未连接、离线、权限不足或工具无法解析目标时，保留具体阻碍并引导本人检查桌面连接，不猜设备 ID、不新建其他聊天、不自动扩大本机访问权限。离线后的重连投递和跨日稳定性需要另行验证，单次成功不能替代长期运行验收。

## 本轮技术诊断边界

Git 同文件读取通过；`file:` 预览被协议策略拒绝，正常私有 HTTP 预览返回 `ERR_BLOCKED_BY_CLIENT`，Chromium 打印遇到容器 socket 限制。这三项分别保留；具体策略或底层原因未经证据确认时不猜测，也不归因于 Reminder OAuth。

云端直接 ReportLab PDF、全页渲染和真实独立审核已经留证。HTML 静态结构检查与实际视觉检查分别记账；本机检查不能充当云端浏览器截图，也不能把直接生成 PDF 宣称为 HTML→PDF 转换成功。本轮只依据已有日志诊断，不重复被拒绝的访问、不重建已通过的六类夹具、不修改浏览器策略或公开托管。

Dot 的本轮 RESULT 接受上述分工，并区分工具目录发现与实际访问验收：发现云端任务消息、Pages 和 GitHub 工具，不等于能够向当前本机 Codex 投递、读写私有仓库或操作特定 Page。本轮没有调用这些服务。Dot 表示原临时目录本次未能重新读取，诊断依据既有日志回执，不能冒称重新核验原文件。

## 学习与私密性

协作消息不代替 `tools/reminder_pipeline.py` 共享领取接口、旧任务保护、网站限定列表租约或完整产物审核。没有真实完整学习及回迁验收时，不打完整分析标签、不启用十五分钟日程；任务完成仍由本人点击。

Dot 只沿用现有获准账户与列表，不新增授权。源任务正文、原始身份响应、私有对话入口、分类报告和完整证据只留私有网站/本人对话/本机。公开知识仓库只接收明确审阅的学习成果及脱敏流程说明。

当前流程解决了无需本人逐条转述的协作；网页登录或会话不可用时，消息状态保留待投递/待回读，不能假装送达。需要长期无人值守的跨端通知时，须另行验证现有支持的服务或准备具体网站改动，经用户授权部署后再启用，不借用学习任务报告接口发送任意协作信件。
