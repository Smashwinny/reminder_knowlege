Q1

Gemini 4 Argon 是什么？长输出是什么概念？

Google 2026-09-30 发布的旗舰模型，最大卖点：单次输出从 64K 暴涨到 100 万 token——一次响应可以写完一部长篇小说。

原帖的用法：在 Antigravity 里先让 Claude Opus 4.6 写大纲，再让 Argon 一次生成百万字小说，最后传番茄小说平台。这条链路牵出三个真问题：①1M token 到底是多少字？②上下文窗口怎么算？③一次成型失败了怎么办？

Q2

1M token 到底能写多少中文字？（本指南实测）

用 tiktoken (cl100k_base) 对 21,478 个真实汉字分词实测：

每 token 汉字数: 0.87
→ 1M 输出 token ≈ 874,868 汉字
英文对照: 4.5 字符/token → 1M token ≈ 450 万字符

"百万字小说"按 token 口径约 87 万字（Gemini 自家分词器会有 ±10-20% 偏差，但量级不变）。原帖的"百万字"是约数不是承诺；且官方明说输出上限是能力边界不是完成篇幅保证——生成可能提前结束。

Q3

统一窗口的预算陷阱是什么？

Argon 的 1,048,576 token 窗口是输入+输出合计。想输出接近 1M，输入侧（大纲+人物卡+设定集）就只剩 ~48K token。换算：

大纲体积可用输出预算后果
≤10K token~1M✅ 完整成形
48K token~1M 上限边缘⚠️ 贴顶，可能截断
200K token 细纲只剩 ~850K❌ 输出被挤占

所以"Opus 写大纲"环节的交接契约是：大纲必须浓缩在 ≤48K token——这正是知识库 [[混合模型分工流水线]] 里"工序间交接要有契约"的硬数字版本，也呼应 [[上下文接力]]（规划现场到执行现场的物料管道）。

Q4

一次百万字成形的成本是多少？

项目价格单次成本
1M 输出（优惠期至 2026-11-30）$10 / 1M token≈ $10
1M 输出（2026-12-01 起）$20 / 1M token≈ $20
输入侧（大纲 48K）$2 / 1M（优惠期）≈ $0.1（可忽略）
失败重试 ×3—$30–60

对比：87 万字人工写作是数千小时。生成端便宜到可以忽略——真正的成本是失败与质量：提前截断、人物漂移、时间线崩坏后的重试与人工修订。

Q5

超长生成的真正难点不在"能写长"，而在"不散架"

单次生成 87 万字，到后半段模型"记得"开头吗？难点清单：

  • 一致性：人物名/称谓/关系在 87 万字中不漂移；时间线前后不自相矛盾；
  • 提前截断：官方明说上限≠保证，可能在任何位置停止；
  • 结构塌缩：后期节奏崩坏、反复灌水——长输出模型通病；
  • 验收不可自动化：谁读完 87 万字？抽查+程序性检查（人名表对账、时间线提取）是务实路径（[[事实与判断分离]]：程序查事实，人读抽样）。

Q8

不想花 $20，能低成本体验"超长输出"吗？

  • 先小窗试：用 100K 输出档位（若开放）验证一致性表现，再决定是否上 1M；
  • 程序性验收先行：写好"人名表对账+时间线提取"脚本，用它决定续写/重试，不凭感觉；
  • 分段+续写策略：若 1M 性价比不佳，"每卷 200K × 5 卷 + 交接契约"可能质量更稳（[[Checkpoint存档与持久执行]] 思路）；
  • 别为优惠期冲动：11-30 前 $10 与之后 $20，对实验成本都不是主要矛盾——重试才是。
