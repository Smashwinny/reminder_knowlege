### 步骤 2：1M token 到底是多少字？（本地分词实测）

用 tiktoken (cl100k_base) 对 21,478 个真实汉字（vault 概念笔记样本）分词：

```
每 token 汉字数: 0.87
→ 1M 输出 token ≈ 874,868 汉字
英文对照: 4.5 字符/token → 1M token ≈ 450 万字符
```

→ 结论：<span>百万字中文小说 ≠ 百万 token</span>，实测约 87 万字（±10-20% 视 Gemini 分词器而定）；
原帖"一次生成百万字小说"按 token 口径约 87 万字，量级接近但"百万字"是约数。

### 步骤 3：统一窗口的预算陷阱（关键发现）

上下文窗口 1,048,576 = 输入+输出**合计**。要让 Argon 输出接近 1M token，
输入侧（大纲+人物设定+前文）只剩 ~48K token 余量——
原帖"Opus 4.6 先写大纲 → Argon 写全文"的交接必须在 **≤48K token 的大纲**内完成，
否则要砍输出预算。这是"大纲模型与正文模型的交接契约"的硬约束版本。
