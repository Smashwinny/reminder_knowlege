1
"动效描述"是什么？一句话说清

动效描述 = 把"我想要什么样的动画"翻译成 AI 能精确执行的词汇。你跟裁缝说"做件好看的衣服"，做出来一定不对味；说"修身、深蓝、混纺、袖口一寸"，一次就对。AI 写动效同理：它会的 CSS 动画词汇成百上千，你只会说"高级一点""灵动一点"，它就只能瞎猜。

💡 Vibecoding 的"Vibe"不是玄学：感觉越"玄"，越需要一套精确的语言把它钉死。动效描述词表就是这套语言。
2
为什么 AI 写的动效总"不对味"？

做一个对照实验就明白。坏描述 vs 好描述，同一个 AI，差的是一个词表：

坏描述「帮我做个卡片动画」好描述「加载时5张卡片从下滑入，先快后慢，每张300ms，错峰60ms」
触发❌ AI 猜（可能用滚动？）✅ 页面加载
动作❌ 淡入？飞入？随缘✅ 从下方滑入
性格❌ 默认 linear，机械感✅ 先快后慢 = ease-out
节奏❌ 默认 0s，瞬间闪现✅ 300ms + 错峰 60ms
⚠️ 短视频的原话点就是这："学到了名词，我就知道怎么做了"——不是 AI 不行，是你没给它名词。

缓动（easing）性格库：曲线即性格

缓动决定"中间怎么走"。同样 300ms，曲线不同，性格完全不同。我们用 Python 实测采样（ex2，数字为真实输出）：

术语CSS 写法性格实测特征（真跑数据）
linearlinear匀速机械，进度条专用t=0.3 → 0.300，毫无惊喜
ease-outcubic-bezier(0,0,0.2,1)快进慢出，入场首选t=0.3 → 0.657：前30%时间走完65%路
ease-incubic-bezier(0.4,0,1,1)慢起加速，离场/消失前段磨蹭，后段冲出
ease-in-outcubic-bezier(0.4,0,0.2,1)两头慢中间快，位移换位t=0.5 才到 0.500，对称
springcubic-bezier(0.34,1.56,0.64,1)过冲回弹，果冻感easeOutBack 实测峰值 1.100：冲过头再回来
bouncecubic-bezier(0.28,0.84,0.42,1)落地弹跳，夸张强调多次衰减过冲
✅ 口诀：入场用 ease-out（先给结果再优雅收尾），离场用 ease-in，换位用 ease-in-out，卖萌用 spring。
5
spring 和 cubic-bezier 有什么本质区别？

cubic-bezier 是"纪录片"：整条曲线预先画死，从头到尾一模一样。spring 是"物理片"：给物体一个质量、弹簧刚度（stiffness）、阻尼（damping），让它真按物理规律跑——目标变了它会自己重新收敛，拖拽跟手、可中断交互必须用它。

💡 描述词里说"回弹/果冻/跟手"→ 用 spring 系；说"滑入/淡入/收尾"→ 用 bezier 系。写清是哪族，AI 就不会拿错工具。
6
时序原语：duration 与 stagger 的数字感

时长不是越长越优雅。UI 动效的行业共识区间（Material 3 速查）：

场景推荐时长为什么
悬停/按压微反馈50~150ms再长就"黏手"
入场/淡入（小元素）150~300ms用户在等下一个动作
大面板/转场300~500ms面积大，需要时间读清
错峰 stagger 间隔20~90ms/个实测 60ms×5 = "排队生长"最舒服
⚠️ 记一个反例：超过 500ms 的入场动画，用户会觉得网站卡了。动效是沟通，不是表演。
💡 描述模板："每张 300ms，错峰 60ms"——两个数字就把节奏定死了，AI 没有发挥空间，也没有翻车空间。

万能模板：一句话需求 → 结构化描述

把四要素填空化，描述就永远不会缺项：

【触发】当（页面加载 / 用户点击 X / 悬停 / 滚动进入视口） 【动作】（元素）做（fade / slide-up / scale-in / blur-in / pop） 【性格】（先快后慢 ease-out / 回弹 spring / 匀速 linear） 【节奏】时长（150~500ms）ms；（如有多元素）错峰（20~90ms）ms 例：页面加载时，5 张卡片从下方滑入，先快后慢，每张 300ms，错峰 60ms。
10
AI 生成后，怎么验收动效？

动效的坑在于"看一眼觉得行，细节全是错的"。两板斧：

① 结构验收（机器可查）：像 ex3 那样 grep 关键证据——缓动曲线在不在、时长对不对、错峰 delay 序列 60/120/180/240 全不全。5/5 PASS 才算过。
② 慢放验收（人眼可查）：把 duration 临时改到 3000ms 慢放——看起点对不对、有没有闪烁（FOUC：先闪一下再动）、离场有没有残留。人眼只在慢放里才能看清曲线。
⚠️ 常见翻车点：AI 给了 transition 但初始态写在错误位置 → 页面加载先闪现后动画；overflow 没裁 → 滑入的卡片从父容器外"穿墙"进来。
