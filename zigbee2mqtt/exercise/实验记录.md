# Zigbee2MQTT 动手实验记录

本机环境：Windows 11，Node v24.21.0，pnpm 11.26.0（npm 全局安装后自动切换），无 Docker、无 Zigbee 硬件。
上游代码：`../repo`（github.com/Koenkk/zigbee2mqtt，v2.14.2，commit 344b6e0，depth-1 克隆）。

所有命令均在本机真实执行，以下为真实输出摘录。

---

## 实验① 从源码编译 Zigbee2MQTT

```bash
git clone --depth 1 https://github.com/Koenkk/zigbee2mqtt.git repo
cd repo
pnpm install        # 5m46s 完成
pnpm run build      # tsc && node index.js writehash
```

真实输出（末尾）：

```
$ tsc && node index.js writehash
exit=0
```

**踩坑记录**：typescript 7.0.2 是原生编译版（tsgo），依赖平台二进制包 `@typescript/typescript-win32-x64`；
pnpm install 后该包目录为空，且反复 `pnpm install` / `--force` 都提示 "Already up to date"。
修复：用 `npm pack @typescript/typescript-win32-x64@7.0.2` 拉取 tarball，手动解压进
`node_modules/.pnpm/@typescript+typescript-win32-x64@7.0.2/node_modules/@typescript/typescript-win32-x64` 后 tsc 恢复。

## 实验② 搭建本地 MQTT broker（aedes）

`mqtt_broker.js` 用 aedes 在本机 1883 端口起一个 MQTT broker，并打印每条经过的消息。

真实输出：

```
[broker] 本地 MQTT broker 已启动: mqtt://127.0.0.1:1883
```

**踩坑记录**：aedes 1.2.0 两处 API 变化——
1. 模块导出从"工厂函数"变为命名导出 `{ Aedes }`；
2. 必须用 `await Aedes.createBroker()` 创建实例；直接 `new Aedes()` 虽然能监听端口，
   但客户端永远收不到 CONNACK（症状：connack timeout）。

## 实验③ 让 Zigbee2MQTT 真跑起来：看它在没有硬件时的真实行为

配置 `data/configuration.yaml`（数据目录用 `ZIGBEE2MQTT_DATA` 环境变量指定）：

```yaml
mqtt:
  base_topic: zigbee2mqtt
  server: mqtt://127.0.0.1:1883
serial:
  port: COM99            # 本机没有协调器，故意写不存在串口
frontend:
  enabled: false
homeassistant:
  enabled: true
advanced:
  log_level: info
```

启动命令：

```bash
cd ../repo
ZIGBEE2MQTT_DATA=<repo>/../exercise/data node index.js
```

真实输出（去色后摘录）：

```
z2m: Starting Zigbee2MQTT version 2.14.2 (commit #344b6e03)
z2m: Starting zigbee-herdsman (10.10.0)
z2m: Error while starting zigbee-herdsman
z2m: Failed to start zigbee-herdsman
z2m: Error: USB adapter discovery error (No valid USB adapter found).
      Specify valid 'adapter' and 'port' in your configuration.
z2m: Exiting...
```

结论（重要）：
- zigbee-herdsman 在**适配器发现阶段**就失败了，进程直接退出；
- 同时观察 broker 日志：**z2m 在 herdsman 启动成功之前不会连接 MQTT**——
  说明 Zigbee 协调器硬件是整个系统的大门，没有它后面全部免谈。

## 实验④ 用 zigbee-herdsman-converters 查"翻译词典"

`device_lookup.js` 直接加载 repo 依赖里的设备定义库并查询两个典型设备。

真实输出：

```
zigbee-herdsman-converters 版本: 26.115.1
内置设备定义总数: 4560
覆盖厂商数: 467
其中 Xiaomi: 13 款，Aqara: 172 款，IKEA: 100 款

===== 小米 Aqara 温湿度传感器（model: WSDCGQ11LM）=====
  厂商: Aqara | 描述: Temperature and humidity sensor
  支持的 Zigbee 特性（exposes）:
    - numeric battery [读写属性: 1] 单位:%
    - numeric temperature [读写属性: 1] 单位:°C
    - numeric humidity [读写属性: 1] 单位:%
    - numeric pressure [读写属性: 1] 单位:hPa
    - numeric voltage [读写属性: 1] 单位:mV

===== 宜家 TRADFRI 灯泡（model: LED1623G12）=====
  厂商: IKEA | 描述: TRADFRI bulb E27, white, globe, opal, 1000 lm
  支持的 Zigbee 特性（exposes）:
    - light
    - enum effect [读写属性: 2]
    - enum power_on_behavior [读写属性: 7]
    - enum identify [读写属性: 2]
```

注意：官方网页宣称 5600+ 设备，是算了白牌/贴牌变体；本地定义库原始条目为 4560 条，更贴近"代码里的真实数字"。

**踩坑记录**：老设备定义没有直接写 `exposes` 字段（用 `extend` 数组组合特性），
要调用库自带的 `prepareDefinition(raw)` 才能拿到最终特性列表——这正是 Z2M 运行时的做法。

## 实验⑤ 模拟 Home Assistant 自动发现握手

`fake_z2m_device.js` 手动复刻 Z2M（`homeassistant.enabled=true`）对每台设备做的事：
先发 3 条 `homeassistant/.../config` 发现消息，再循环上报设备状态到 `zigbee2mqtt/<设备名>`。
`mqtt_observer.js` 扮演 Home Assistant 订阅这两类主题。

真实输出（observer 侧摘录）：

```
[observer] 收到 homeassistant/sensor/livingroom_aqara_sensor/temperature/config
           {"name":"Temperature",...,"stat_t":"zigbee2mqtt/livingroom_aqara_sensor","val_tpl":"{{ value_json.temperature }}"}
[observer] 收到 homeassistant/sensor/livingroom_aqara_sensor/humidity/config
[observer] 收到 homeassistant/sensor/livingroom_aqara_sensor/battery/config
[observer] 收到 zigbee2mqtt/livingroom_aqara_sensor
           {"temperature":24.5,"humidity":55,"battery":87}
...（共 3 条发现消息 + 6 条状态消息，全部收到）
```

这一条实验把"一台 Zigbee 设备怎么变成 HA 界面里的传感器"完整跑通了：
发现消息 = 传感器的"出生证明"，状态消息 = 实时数值。

## 复现实验的步骤

```bash
cd F:\reminder\zigbee2mqtt\exercise
npm install            # 安装 aedes / mqtt（仅需一次）
node mqtt_broker.js    # 终端1：起 broker
node mqtt_observer.js  # 终端2：观察（可选，对照 broker 日志看也行）
node fake_z2m_device.js  # 终端3：模拟设备上线
node device_lookup.js    # 任意时刻可查设备词典
# 实验③ 另需先完成实验①编译，再：
cd ../repo && set ZIGBEE2MQTT_DATA=F:\reminder\zigbee2mqtt\exercise\data && node index.js
```
