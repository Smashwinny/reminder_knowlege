# Grok Bot：让代码库适合代理协作（候选）

## 查重与新增边界
已有 [[Agent指令文件AgentMd]] 定义规则文件，[[AgentHarness智能体挽具]] 定义执行环境，[[多Agent协作乱序竞态]] 定义并行依赖。不要重复创建这些概念，也不要重写旧实验。
本批只补三个可执行差分：
1. **合并证据绑定提交**：tests/lint 的成功必须对应当前 HEAD；缺少检查一律拒绝。补到 [[质检Gate与自我纠错循环]] 与 [[证据优先质检ProofOverClaims]]。
2. **门禁控制面不可由候选修改**：保护 tests/、tools/、.github/、AGENTS.md；本地脚本放仓库外，按实际 diff 白名单判断。补到 [[提示注入]] / [[AgentHarness智能体挽具]]。这不是完整沙箱，也不能防住所有测试盲区。
3. **缓存也会制造假绿**：首轮复制含 __pycache__ 的基线，等长快速改动被旧 pyc 掩盖；真实断言失败后修复为复制时排除 pycache，并保留失败日志。补到 [[确定性脚本]]，建议生产用干净工作区、构建缓存键绑定内容。
