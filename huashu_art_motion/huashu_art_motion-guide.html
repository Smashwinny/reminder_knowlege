Q1这个 skill 是什么？

一句话：一个让 coding agent"用代码画画并做成动画"的 Agent Skill——你是导演+分镜+原画+动画+剪辑，但画笔是 Canvas 代码。它来自一次真实复刻（2026-10-04 复刻 @cherry_mx_reds 的 15 秒"艺术史速通"，16 个艺术时代），把复刻经验固化成可重复使用的方法库。

Q2核心资产是什么？（三类）

① 35 张风格配方卡（references/风格配方/）：每张 = 核心渲染器手法 + 母题动作（画怎么活）+ 签名转场（怎么进入它）+ 质量星级 + 当前短板——是"实做的参数和坑"，不是唯一画法；② 9 种视频语法卡（references/动画语法/）：每种解说风格一张配方，引擎里对应可参数化渲染的 clips/ 库；③ 完整代码工程（scripts/engine/）：可以复制开新片，改 eras.js 段落表、写 scenes/<id>.js。

形态创新点：它不是"一个工具"，而是"给 agent 的职业技能包"——SKILL.md 是路由表，按用户说的话决定读哪些参考文档。这与 vault 的 [[AgentSkills技能包]] 概念同构，是 skill 形态的成熟样本。

Q3"五层机制"——它让画"活"的公式

复刻"艺术史速通"提炼出的通用公式：固定场景骨架 × 每幕都是活的画（主角动作+风格母题小循环）× 转场用下一风格的签名语言 × 节拍网格加速 × 连续叙事锚+结尾角色梗。换题材照样成立——这是从"复刻一次"到"可复制方法"的关键一跃。

配套硬规则（"窄桥"）：画面必须动（自检要量帧差）；场景与风格用代码画、真人角色用 AI 生帧+代码合成；复刻学机制不逐像素；新方向先出三帧给用户挑；所有随机用种子，同一时刻渲两次逐像素一致；成片交付前派没参与制作的 agent 独立审片。

最值钱的诚实：每张卡都写了"当前短板"（梵高"每帧 120ms 最重"、皮影"121ms 偏慢"、8-bit"猫头压窗台"）——这是实做者的笔记，不是营销文档。普遍短板是角色（背景过了风格渲染器就像，角色平涂就像贴上去的）。

Q59 种视频语法——口播驱动的片段渲染

对解说视频，它把"风格"细分为频道级语法：3b1b 数学动画、Keynote 式 UI 演示、财经图表、Kurzgesagt、Vox、白板手绘、Storytime、动态字排、真人讲解员。8 种带示范片和 JSON spec——给一段口播转录，按 spec 渲出时长精确对齐的片段：render.py --spec 直接出片。本机校验：examples/ 下 8 个 JSON spec 全部合法可解析。

Q6引擎工程里有什么？

scripts/engine/ = engine.js（种子/时间轴/世界画布）+ lib/（brush 笔触/paint/camera/collage/diagram 绘画库 + woff 字体）+ scenes/ 35+1 个风格场景 JS + render.py（Playwright 无头渲染静帧/mp4）+ clip.html/clip.js + clips/ 9 个语法片段库 + demos/ 8 支示范 + compare.py 参考并排对比。另附 analyze/breakdown.py 参考片拆解工具。

种子确定性本机验证：lib/util.js 实现 mulberry32，全引擎 53 处 rng(seed) 种子调用——"渲两次逐像素一致"的宣称有真实实现面支撑。

Q8质量边界与祛魅

① 角色是普遍短板（INDEX 自己承认）；② 性能：梵高 120ms/帧、皮影 121ms——长片渲染时间是真成本；③ 口播整片参考代码（spacex/）需自备角色帧和音频，"开箱即整片"不成立；④ 35 张卡的质量星级是"当前实做水平"不是风格难度上限；⑤ 它是给 agent 的技能包， solo 人类照 SKILL.md 手工做会慢很多——价值在 agent 编排。

Q9这个项目给我什么（能力清单）

① 风格即渲染器：每种艺术风格=一个程序化渲染器+母题+签名转场的三元组，可拆解可复刻。
② 先一帧后运动：静态帧过关再谈动画的"一帧先行"工作流。
③ 种子确定性：所有随机种子化=可复现可回归，动画工程的质量基线。
④ 语法分层：频道级视觉语法（9 种）比"风格"更细，是解说视频的可组合单元。
⑤ Skill 形态：SKILL.md 路由表+参考文档+代码工程=职业技能包的标准结构。
⑥ 诚实标注法：质量星级+当前短板的自我披露，比"全都能做"可信十倍。
