ChatSEO 六技能：让 Agent 当"SEO 主管"的纪律手册

情报层（ChatSEO MCP）+ 执行层（Claude Code）+ 审批层（人）——最有价值的不是工具，是六条确定性纪律

Q1

这套东西是什么？一句话能说清吗？

一套"SEO Agent 工作流"：Claude Code（Opus 5.5）扮演 SEO 主管负责规划、改写和例行工作；ChatSEO MCP 提供搜索控制台数据、搜索量、SERP 分析等情报；任何触碰线上页面的动作都要人审批。六个技能文件（money-keywords / page-brief / ship-page / geo-rankings / pattern-drip / weekly-seo）定义了全部纪律，作者强调它们是"免费给的规则"，但数据服务并不免费。

Q2

为什么 SEO 适合 Agent 化？难点在哪？

SEO 是"数据密集 + 高纪律 + 长周期"的苦活：每周要看 Search Console 环比、判断改旧页还是新建、控制改动别弄丢老内容——全是重复性决策，恰是 Agent 的主场。

但难点也同样清楚：①需要真实搜索数据（Agent 自己编不出搜索量）；②改线上页面有风险（作者亲述：Claude 曾静默删掉排名页面的表格）；③排名有观察期，"改完就有效"是幻觉。六技能全是围绕这三点立的纪律。

Q3

六个技能各自管什么？纪律是什么？

技能干什么核心纪律
money-keywords找商业价值关键词只要商业意图词；top3 是落地页才留；没量的写 n/a，绝不编数字
page-brief单个词的页面简报已有 URL 在获点击→停手改旧页，不新建重复页
ship-page安全写页/发布DIFF GATE：上线前列出旧版有新版丢的全部元素；草稿/分支先行；人批准后发
geo-rankingsAI 搜索引用规划"best X 年份"查询谁被 AI 引用；只能经简报流程改标题，不直接改
pattern-drip规模化产出一次一页；只换城市名的页不发；diff 通过才放行
weekly-seo周一复盘28 天环比；60 天内动过的页不碰；90 天无起色列外链候选；输出 5 个动作按业务价值排序
Q4

DIFF GATE 为什么是整个体系的灵魂？（本机实测）

因为它治的是"AI 静默破坏"——作者亲身踩过：Claude 改写时把线上页面的排名表格悄悄删了。这与知识库 [[证据优先质检ProofOverClaims]] 完全同构："改写完成"的宣称不算证据，新旧 diff 清单才是。

本机用示例数据复刻了该闸门（chatseo_skills\exercise\diff_gate.py，零依赖），三轮实测全部符合预期：

① 旧版有 pricing 表格、改写版静默删掉 →
   ❌ DIFF GATE 拦截：- 表格 pricing   exit=7
② 同页对比 → ✅ 通过  exit=0（无误报）
③ 把表格补回再比 → ✅ 通过  exit=0（修复即放行）
结论：闸门机制 3/3 验证。设计要点：fail-closed（有丢失即退出码 7，与 content_guard 同款）、清单化（逐项列出而非"有改动"）、人工确认后才放行。
Q5

ChatSEO 数据层的真实门槛是什么？

chatseo.app/mcp 官方文档直读：https://api.chatseo.app/mcp（Streamable HTTP），38 个工具（GSC 读取/审核/简报/Shopify 发布等），认证用 OAuth 2.1 + RFC 9728（免贴 Key 自动引导——正是知识库 [[OAuth资源发现]] 的实例）。

门槛：Pro 及以上，€49/月起，页面无免费试用说明。所以"技能文件免费"≠"整套方案免费"：规则可白嫖，数据要付费。评估方案时记住这条拆分。

Q6

合规边界在哪？

Google 搜索垃圾政策明确：购买链接、排名交换、无用户价值的大规模生成内容都是垃圾行为。"每天只发一页"不构成质量或合规保证。pattern-drip 的"只换城市名的页不发"正是把这条政策翻译成了 Agent 纪律——值得抄这个"政策→纪律"的翻译手法。

作者也坦承：新域名即使用这套流程打竞争大词，照样排名 40 开外——技能不创造权重，只让有权重的站更高效。

Q8

"规划-执行-审批"三层分工为什么重要？

因为 SEO 的错误成本不对称：写 100 页简报很便宜，弄丢一个排名页很昂贵。三层分工让便宜的动作自动化（找词、写简报、复盘），让昂贵的动作过人（上线、删内容、改标题）。这也是 [[代码管边界提示词管判断]] 的财务版：回不了的（线上损坏）归审批，回得了的（草稿改写）归 Agent。

Q9

不订阅 ChatSEO，这套方法还能用吗？

能，纪律全部可用，数据层找替代。

  • 六条纪律（n/a 不编/先查旧页/diff 后上线/一次一页/60 天观察期/周复盘）不依赖任何付费服务；
  • 数据替代：自己的 GSC 导出 CSV + 搜索量用免费额度工具 + SERP 手动抽样；
  • DIFF GATE 已在本指南本地复刻（diff_gate.py），直接可接入你自己的发布流程；
  • 周复盘用任何表格软件都能跑 28 天环比。
