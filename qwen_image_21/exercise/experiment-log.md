## 步骤与真实输出

### 步骤 1：型号与许可核实（HF 官方 API）

```
curl https://huggingface.co/api/models/Qwen/Qwen-Image-2.1
```
- license tag：`other`（实为 Qwen Research License）
- downloads：196,152/月，likes：3,477
- LICENSE 正文要点（官方页面直读）：标准授权**限定于非商业研究或评估**；
  **商业用途需单独许可**——原帖"无需授权许可"的说法与官方许可矛盾 ⚠️

### 步骤 2：权重体积实测（HF tree API，不下载权重）

```
curl .../api/models/Qwen/Qwen-Image-2.1/tree/main[/text_encoder|/transformer]
```

| 组件 | 文件 | 大小 |
|---|---|---|
| text_encoder | 4 个分片 | 5.00+4.92+4.92+2.70 = **17.54 GB** |
| transformer（视觉生成器） | 2 个分片 | 9.97+4.26 = **14.23 GB** |
| **权重合计** | | **31.76 GB（BF16）** |

关键发现：模型卡说"7B"仅指**视觉生成组件**（transformer ≈ 14.2GB ≈ 7.1B 参数 × 2 字节，
数字自洽）；但 text_encoder 另有约 8.7B 参数（17.5GB）。
→ 文章"整个管道只有 7B"的暗示不成立；**磁盘预算要按 32GB 算**，不是 14GB。

### 步骤 3：显存账单核算

- BF16 权重全量驻留显存：31.76 GB × 2 字节/参数口径下约 **63.5 GiB** 量级
  （含激活只会更多）→ **24GB 的 4090 全量装载必爆**；
- 模型卡示例用 `enable_model_cpu_offload()`——权重分批驻留，峰值显存可压到远低于 63.5 GiB，
  代价是**出图速度随 offload 换入换出显著下降**；
- 原帖"32GB 保证不爆显存"：**仅在 CPU offload 前提下成立**，裸装 32GB 同样不够；
  "31 秒出图"是作者条件下的单点陈述，无独立复现。

### 步骤 4：AutoDL 费用核实（官方计费文档 + 行情比对）

- 官方文档：按量实例**从开机到关机计费**，不以是否实际使用 GPU 为准；
  默认 50GB 免费本地数据盘，付费扩容部分**关机后仍计费**；
  → "停下 Python 程序 ≠ 停止计费"，"关机 ≠ 存储费用归零"。
- 权重 31.76GB：50GB 免费盘刚好够装权重+最小依赖，但余量紧张（缓存、输出图会顶满）；
- 价格行情（2026-10 检索）：AutoDL 4090 约 **1.61–2.50 元/小时**区间浮动
  （原帖 1.58 元/小时属特定时刻/卡的个案，不作当前报价）；
- 算账示例：32GB 显存级实例（如 4090 24GB 需 offload / A6000 48GB 可全量）按 2 元/小时，
  每天玩 2 小时 = 4 元/天；**忘记关机一天 = 48 元**——费用风险大头是生命周期管理不是单价。

## 结论

- "7B"只是视觉组件；全管道权重 31.76GB，磁盘与显存都要按这个数预算；
- 24GB 消费卡需 CPU offload 才能跑，性能打折；"32GB 保证不爆"是有条件真；
- 许可红线：非商业研究/评估免费，商用需单独授权——营销文"无需许可"不可信；
- 云端部署的真成本 = 时租 × 开机时长 + 磁盘费 + "忘关机"风险，生命周期管理 > 单价。
