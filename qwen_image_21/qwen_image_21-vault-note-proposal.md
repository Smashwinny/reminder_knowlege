### 1. 组件口径宣传陷阱（"7B"陷阱）
- 一句话定义：多组件模型（text encoder + transformer + VAE）拿单一组件参数当整体宣传，导致用户按错误预算准备磁盘/显存；防御法——用仓库 tree API 查分片实测体积再算账。
- 领域：AI / 模型工程
- 已有概念关联：[[证据优先质检ProofOverClaims]]（官方文档也是待核实来源）；[[面数口径与减面下限]] 的同构陷阱（"先问口径"思维跨域复现）
- 来源项目：qwen_image_21（text_encoder 17.54GB + transformer 14.23GB 实测）

### 2. 云端实例生命周期计费
- 一句话定义：按量 GPU 实例从开机到关机持续计费（与进程是否在跑无关），付费磁盘关机后仍计费；省钱大头是生命周期管理（无卡下载→有卡推理→关机→释放磁盘）而非单价。
- 领域：AI / 成本工程
- 已有概念关联：[[付费调用回执与预算熔断]]（租赁版预算纪律）；[[能力地板选型]] 的成本侧
