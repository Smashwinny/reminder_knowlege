# 深拷贝与浅拷贝学习笔记（测试知识库用）

## 浅拷贝（shallow copy）

浅拷贝只复制对象的第一层：新对象的外壳是新的，但里面装的可变元素仍然指向原来的对象。
Python 中创建浅拷贝的方式有三种：`copy.copy(obj)`、`list[:]` 切片、`dict.copy()`。

例子：`a = [[1, 2], [3, 4]]`，`b = a[:]`。此时 `b[0]` 和 `a[0]` 是**同一个**内层列表，
修改 `b[0].append(99)` 之后 `a` 也会变成 `[[1, 2, 99], [3, 4]]`。

## 深拷贝（deep copy）

深拷贝递归复制所有层级，新对象和原对象完全独立，互不影响。Python 标准库的
`copy.deepcopy(obj)` 会沿对象图递归下行，把每一层可变对象都新建一份，并用
memo 字典处理循环引用，避免无限递归。

## 关键区别

| 维度 | 浅拷贝 | 深拷贝 |
|---|---|---|
| 复制层级 | 只有第一层 | 所有层级递归复制 |
| 内层可变对象 | 与原对象共享 | 完全独立 |
| 速度 | 快 | 慢（要遍历整个对象图） |
| 典型 API | `copy.copy()`、切片 | `copy.deepcopy()` |

## 常见考点

1. 不可变元素（数字、字符串、元组）在浅拷贝中共享是安全的，因为它们不可变。
2. deepcopy 的 memo 机制同时保证了共享子对象在副本中仍然共享（保持对象图拓扑）。
3. 自定义类可以通过 `__copy__` 和 `__deepcopy__` 魔法方法控制拷贝行为。
