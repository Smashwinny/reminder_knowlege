### 步骤 5：直调分类器验证证据状态机
```
node -e "import('./src/evidence.mjs').then(m=>console.log(m.classify('...',{truncated:false,author:'thsottiaux'})))"
```
六组用例实测（RULES_VERSION 1.4.2）：
| 输入 | 完整版 | 截断版 |
|---|---|---|
| Global reset landing tomorrow 10am PST for all paid ChatGPT accounts. | global/announced/explicit-announcement | signal/unconfirmed/truncated |
| Reset has propagated. All reset for everyone. | global/reported/explicit-completion | signal/unconfirmed/truncated |
| We will grant affected subscribers a reset credit... | banked/announced/explicit-bank-announcement | signal/unconfirmed/truncated |
| GPT-6.1 Sol is now the default model in Codex. | other/information/unrelated | other/information/unrelated |
| 否定/玩笑句 | signal/unconfirmed/ambiguous | — |

核心结论：**截断一律 unconfirmed；预告(announced)≠完成(reported)；无关新闻即使含 usage 也不入 feed。**

## 坑记录
- classify 第一参数是纯文本字符串，options 是第二参数——按对象风格传参会报 `text.replace is not a function`。
- 根路径 `/` 是 313 字节的 meta-refresh 跳板，真正的页面在 `/en/` `/zh/` 等 locale 目录下（静态 locale 路由，canonical 指向生产域名）。
