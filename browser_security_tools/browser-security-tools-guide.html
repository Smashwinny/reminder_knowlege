Q2

"点击链接就被精确定位/偷拍"是真的吗？

半真半假——这正是最需要祛魅的地方。把采集分成两类，防御策略完全不同：

类别例子需要授权？防御
被动指纹浏览器类型、CPU 核数、内存、显卡型号、屏幕尺寸、系统版本❌ 不需要，进页面即泄露反指纹插件/浏览器加固
敏感权限GPS 精确定位、摄像头、麦克风✅ 必须用户点"允许"一律拒绝 + 检查权限图标
主动输入仿冒登录页的账号密码—（被骗输入）核对域名/官方客户端

Seeker 源码（本机克隆核对）证实了这个二分：location.js 先把 UA 解析出的平台/浏览器/核数/内存/显卡 POST 给服务器（无授权弹窗），然后才调用 navigator.geolocation.getCurrentPosition() 请求定位——并且源码明确处理 PERMISSION_DENIED 分支（"User denied the request"）。

结论：不点"允许"，GPS 坐标拿不到；但你的设备指纹已经走了。宣传里"点链接即定位"把两类混为一谈。

Q3

浏览器权限机制到底怎么保护我？（本机实测）

自建测试页 exercise/permission-test.html 在 Headless Edge 真实运行：

① isSecureContext = true
② geolocation 权限状态（请求前）: prompt     ← 浏览器先问，绝不默认放行
③ 定位被拒: code=1 User denied Geolocation    ← 拒绝即拿不到坐标
  • 安全上下文：Geolocation/getUserMedia 只在 HTTPS（或 localhost）可用，HTTP 裸站直接被拒；
  • 权限状态机：每个敏感权限三态 prompt → granted / denied，默认 prompt；
  • 拒绝即失效：denied 后 API 走 error 回调，页面拿不到数据（实测 code=1）；
  • 摄像头额外有硬件指示灯：被调用时物理灯亮，这是最后一道肉眼可验的证据（[[证据优先质检ProofOverClaims]] 的硬件版）。
实测还发现一个口径细节：Edge 把 file:// 也视为安全上下文（isSecureContext=true）。所以"安全上下文"不等于"HTTPS 网站"，评估风险时别只看协议。
Q4

Zphisher 这类钓鱼页怎么防？

钓鱼页不依赖任何高级技术——它依赖你"没看域名"。Zphisher 生成与官方登录页几乎一样的仿冒页，唯一破绽是域名。

  • 域名三查：官方域名是否完全一致（注意仿冒拼写如 wechat-login.com）、是否 HTTPS、是否从官方 App 内跳转而来；
  • 习惯防线：重要账号只在官方 App/收藏夹入口登录，从不点短信/私信里的链接；
  • 输入前停顿：任何要输密码的页面，先看地址栏——这一秒值你所有账号；
  • 双重验证兜底：即使密码被骗，2FA 也能挡住多数接管。
Q5

被动指纹泄露有多大危害？

单次泄露看似无害（"知道我用 Chrome 怎么了"），但组合起来：浏览器+系统+屏幕+显卡+核数+内存的组合在你的设备群里大概率唯一，可用于跨站追踪（不依赖 Cookie）和欺诈画像。Seeker 把它作为"第一道菜"正是因为它零成本。

防御：反指纹插件（改 UA/混淆屏幕与硬件报告）、Tor Browser（统一指纹）、日常与敏感操作分浏览器。

Q6

夸大宣称本身为什么也是防御素材？

"点一下就被定位/偷拍"的恐吓式传播随处可见。用本指南的三问拆穿：①哪类数据？（被动/授权/主动输入）②浏览器权限机制允许吗？③源码或文档有没有证据？拆完你会发现：绝大多数"黑科技" = 被动指纹 + 诱导授权 + 钓鱼输入的组合拳，没有一项是魔法。理解机制的人不会被机制吓唬。

Q8

日常使用浏览器的好习惯清单

  1. 网站要定位/摄像头/麦克风权限——默认拒绝，真需要再单独开；
  2. 定期检查浏览器"网站设置"里的 granted 列表，清掉不再信的站；
  3. 重要账号密码只在官方入口输入，看域名再输；
  4. 敏感账号开 2FA；
  5. 装反指纹/广告拦截插件，降低被动画像精度；
  6. 看到"点链接即被定位"的说法——用 Q6 三问拆它。
Q9

这套防御框架能平移到哪里？

"采集分级 + 权限状态机 + 证据核验"是通用防御三件套。平移示例：审查手机 App 权限（通讯录/相册/定位同样是 prompt→granted/denied）；审查桌面软件的网络请求；审查任何"能看你一切"类产品的宣称。凡是不能说出数据类别+授权路径+证据的能力宣传，一律按夸大处理。

一页总结

  • 宣称分三类：被动指纹（无授权）/ 敏感权限（必授权）/ 钓鱼输入（骗你输）；
  • 浏览器是防线：权限状态机默认 prompt，拒绝即失效（实测 code=1）；
  • "点链接即定位"是夸大：不点允许拿不到 GPS，但设备指纹已泄露；
  • 钓鱼唯一破绽是域名：官方入口 + 2FA 兜底；
  • 三问拆宣称：数据类别？授权路径？证据在哪？
