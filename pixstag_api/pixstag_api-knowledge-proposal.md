## 一、新概念笔记（建议新建，vault 查重未见同名）

### 1. 异步任务五态契约
- 一句话定义：长耗时生成服务的标准接口形态——创建即返回 task_id，状态机 queued/running/succeeded/failed/cancelled 轮询或 webhook 推进；客户端必须区分"受理"与"完成"，终态才取货并对账。
- 领域：AI / 视频生成
- 已有概念关联：[[可逆派生状态]]（pending 是铁证）；[[任务票据与状态外置]]；[[快照契约与不可变只读]] 的写侧版
- 来源项目：pixstag_api（官方文档直读 + 本地模拟 3 轮到达终态）

### 2. 按秒用量对账
- 一句话定义：视频生成按秒计费的回执核对——请求时长×单价必须等于 usage.total_seconds，不符即拒付复核；另需盯积分有效期与失败重试的隐性成本。
- 领域：AI / 成本工程
- 已有概念关联：[[付费调用回执与预算熔断]]（按秒版）；[[云端实例生命周期计费]] 的同族
- 来源项目：pixstag_api（对账脚本实测：一致放行/篡改拒付）
