① 官方八条原则，落地后到底能干哪些活？

Q1
从"怎么写提示词"到"能接什么活"——9 大场景全景

上一篇的八要素解决"提示词怎么写"，本篇回答"写好之后能交付什么"。作者把场景按交付物分成两层：

个人玩法是"娱乐级"（动了就行），电商玩法是"商业级"（瓶身、Logo、文字、标签差一点都不能上线）——所以后面 6 个问题里真正值得抠工程细节的全在下半区。

② 逐问精读

Q2
为什么让模型直接生成 6 帧 / 10 帧，拼出来的 GIF 会"抖"？

作者实测：先让模型生成 6 帧、10 帧分镜头再拼 GIF，抖动明显。原因一句话：图像模型每生成一帧，都是把这帧重新画一遍——没有"上一帧"这个概念。

这与上一篇的官方结论完全同源：[[修改与约束分离]] 里就写过"每轮编辑都是重新画一遍，像素级必须不动的区域，官方建议把已批准的局部直接合成回原图，别指望提示词"。作者用整条 GIF 管线把这句话实践了一遍。

Q3
"1 张底图 + Python 扫光"为什么能让瓶身 / Logo / 文字绝对不动？

作者给出的生产顺序：上传商品图 → Image 生成一张漂亮商品照（只有这一步用 AI）→ Python 只负责"移动摄影棚光" → 输出高级循环 GIF。 Python 部分读取这唯一一张底图，商品像素从头到尾完全复用，只在上面叠加一条很宽、透明度很低、边缘高斯羽化的竖向光带。

为什么这叫"构造性保证"而不是"碰运气"：不动的原因不写在提示词里（提示词可能被忽略），而是写在程序的数学结构里——每一帧 = 底图 + 光带，光带是一条只依赖横坐标 x 的纯函数，光带没碰到的列，像素连加都加不上。ex4 实测：48 帧里光带支撑域之外 逐像素偏差 = 0（48/48 PASS），Logo/文字区 29/29 帧零改动。

这个思路还能用在哪

凡是要"画面钉死、只动一个元素"的动态效果都可以套：扫光、飘雪/下雨叠加层、价格牌闪烁、渐变角标……AI 出一张"完美的静帧"，代码出"运动的那部分"。

代价是什么

光带只能"加减亮度"，不能改变商品的透视、遮挡、反光形状——需要物理真实运动（水花、布料）时，仍得回到视频模型。

Q4
softbox 高斯光带和"纯白矩形"差在哪？

作者特别强调：光带不要简单做纯白矩形，要模拟摄影棚柔光箱（softbox）——中心亮、边缘羽化、轻微暖色。三种参数决定"假光"和"棚光"的距离：

参数纯白矩形softbox 高斯光带（ex4 采用）
亮度分布带内均匀 → 生硬"贴纸感"高斯分布 exp(−x²/2σ²)，中心最亮向两侧羽化（σ=56px）
强度不透明/高透明度 → 过曝峰值仅 34/255（≈13%），只是"提亮"不是"覆盖"
色温纯白 → 冷、塑料感R 通道增益最大（暖 0.55）、B 提升最少 → 钨光灯的暖调
支撑域矩形边界突变高斯自然衰减 + 3.2σ 外硬截止 → 有确定的"照不到"区域，可严格验证

这也是 [[修改与约束分离]] 的思想在代码层的对应物：把"例外"（光带照到的地方才会变）写得清清楚楚，约束之间才不打架。

Q5
九大场景各自的"翻车点"是什么？（检查项地图）

作者做每个场景都先问"以前容易翻车的是什么"，把翻车点变成显式检查项——这正是官方第 8 条"谨慎迭代"的实操化：

场景提示词要点⚠ 验收时检查什么
弹跳 GIF 贴纸先出贴纸素材，再补"同一对话里继续"做帧角色是否逐帧走形
九宫格表情包官方模板换 emoji；注意批量生成 9 个效果差，逐张出表情之间是否还像同一张脸
慢扫光广告AI 只出底图，光带交给 Python瓶身/Logo/文字零位移（ex4 已验证 = 0）
海报换款图1=模板、图2=商品；模板用通用文案旧商品的型号/价格是否残留
衣服试穿人脸+服装分工；动作让模型自调手部接触关系、裤装衔接
透明商品换景换背景后透过瓶身看到的背景也要换透光区有没有残留旧背景、反射、接触阴影
人物当模特图1 脸、图2 商品，各给分工人脸、包装、手部接触三保住
多品组合主图每件必须来自对应参考；先用尺寸接近的商品测少件/多件/瓶盖张冠李戴
包装稿 → 立体盒给清晰折线、裁切线的展开稿文字图案是否落在正确的面，跨折线图案对齐（作者标注"尚未验证稳定性"）

值得学的是这个动作本身：每接一个商单，先列"翻车点清单"，出图后逐项打勾——和 [[质检Gate与自我纠错循环]] 的"验收标准写进输入"完全同构。

Q6
五种提示词写法 = 官方八要素的逐条实例化？

文章结尾给出的 5 条"存成常用片段"的写法，与上一篇入库的官方八要素一一对应（ex5 已用规则机验证 4 组配对全部单调提升）：

文章技巧对应官方要素实操一句版
1 修改项与保留项分开写要素⑥ → [[修改与约束分离]]"只把 X 换成 Y"+逐项点名不许动的清单（换灯就要连带说灯光阴影跟不跟着变）
2 给多张参考图明确分工要素⑦ 参考图分配角色"图1 只提供版式，图2 只提供商品"
3 把文字当成固定内容交付要素⑤ 准确文本三件套模板文字"逐字保留原样"，一个标点都不许改
4 用可见细节替换"高级感"要素③ 描述可见细节"做得高级一点" → "柔光箱顶光+浅景深+玻璃高光+哑光质感"
5 给创意设置一个锚点要素④/构图（ex5 新增 R9）画面只许有一个主角："以图1 为主角，作为唯一视觉锚点"
# ex5 实测（确定性规则机，无 API）：同一场景 口语版 → 文章配方版
海报换款    33 → 67    人物当模特  33 → 50
多品组合    50 → 100   扫光底图    50 → 100   # 4/4 单调提升
两个诚实发现：① 即使按文章重建的配方，也常缺要素②的"标签段"结构（图1是…没有写成 主体：式分区）—— Recipes 可以再进化；② "只让人物拿起商品"没过 R6 动词表（改/换/替换…不含"拿起/穿戴"）——机检分数是必要条件，不是充分条件，动词盲区要靠人工补检。
Q7
哪些活必须交给代码？（合成边界）

交给提示词 ✍

一次性生成、允许微差、需要"理解"的活：换背景、试穿、组合理解、风格迁移。这些活代码写不出来，只能靠模型语义能力。

交给代码 ⌨

同一个东西出现两次以上的活：GIF 的 48 帧、水印循环、批量换字。凡是"第二份拷贝"，模型就会重画，代码才是复印机。

判据一句话："重复 = 复印，交给代码；理解 = 生成，交给模型。" 这也是 Q3 构造性保证的推广形式。

④ 动手实验（全部真实运行，无 API key 也成立）

诚实声明：文章的完整提示词以截图嵌入原文（无文本层），实验配方按正文描述重建；"逐帧重绘抖动"反例用确定性仿射抖动模拟（seed=7），演示量级而非真实模型输出；管线与验证代码全部真实运行。

1合成商品底图（AI 位的替身）

目的：用 PIL 画一张带瓶身/Logo/文字的"商品照"，代替需要 API 的模型输出。命令：python ex4_light_sweep_gif.py

✅ 预期：生成 ex4_base.png (800×800)，琥珀瓶+标签"LUMI AMBER SERUM 30ml"
2写 softbox 光带函数

目的：把"高斯羽化+低峰值+暖色偏+3.2σ 硬截止"翻译成纯函数 softbox_frame(base, center_x)，只动亮度色温、不动几何。

✅ 预期：光带 band=224px，σ=56px，峰值 34/255；同一底图传入不同 center 得到不同帧
3生成 48 帧扫光 GIF

目的：底图像素从头到尾复用，光带中心从 −0.25W 扫到 1.25W，50ms/帧、无限循环。

✅ 预期：ex4_light_sweep.gif 1.0MB，回读 n_frames=48、loop=0
4构造性验证（本实验的灵魂）

目的：证明"瓶身/Logo/文字不动"不是观感，是数学事实。

✅ 实测输出：
[V1] 48帧光带支撑域外逐像素==底图: 48/48 (最大偏差 0) PASS
[V2] Logo/文字区零改动帧: 29/29 PASS
[V3] GIF 回读: 48帧/loop=0，量化色差 mean=1.43（256 色调色板有损编码的正常代价，几何不变）
5反例对照：模拟"逐帧重绘"到底有多抖

目的：确定性仿射抖动（±3px/±0.4°，seed=7）模拟模型逐帧重画，测瓶身边缘位移。

✅ 实测：重绘反例瓶身左边缘逐帧位移 +3/+1/−3/+3/−3/+2 px（MAD max 2.13）；底图复用管线 +0 px（MAD 0.00）——Q2 的"抖"被量化坐实。
6ex5 配方体检器：五技巧拍回八要素

目的：验证文章技巧与官方规则的映射不是嘴上说说的。规则机复用上一篇 ex1 的 8 条规则 + 新增 R9 单一视觉锚点。

✅ 实测：4 组配对单调提升 33→67 / 33→50 / 50→100 / 50→100；两个诚实发现见 Q6 淡黄框
实验中踩的真坑（代码层）：光带叠加向量若 reshape 成 (1,W,1) 再与 (H,W) 的通道切片相加，当 H==W 时 numpy 会静默广播成 (H,W,W)——800×800 图直接生成 4GB 临时数组，且每个像素错拿 prof[0] 的值，结果全错但不报任何错。修法：保持 1D (W,) 做尾轴广播。另：GIF 是 256 色有损调色板，几何不变量必须在合成帧层验证，不能拿 GIF 回读当证据。

⑥ 坑与结论（速查）

坑1 多帧分镜必抖：图像模型没有"上一帧"概念，别让模型出动画帧序列。
坑2 批量 9 宫格一次出：作者实测效果差，逐张串行才稳。
坑3 模板残留旧商品信息：换款海报的模板要用通用文案，验收查型号/价格。
坑4 透明商品换景：验收必须看"透过瓶身看到的背景"是否同步换了。
坑5 机检的动词盲区：R6 动词表不含"拿起/穿戴"，机检+人工双轨。
坑6 numpy (1,W,1) 广播陷阱：H==W 时静默升维，结果全错不报错。
一句话收束：官方指南给"规则"，这篇给"战例"——9 个配方把八要素打进了电商现场，而其中最硬的一条工程结论（底图复用+代码叠加）已经在 ex4 里被我们用 48 帧 × 逐像素 = 0 的方式重新证明了一遍。
