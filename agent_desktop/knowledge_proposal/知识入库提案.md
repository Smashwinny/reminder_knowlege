# agent-desktop 知识入库提案

## 范围与查重

来源固定为 `vercel-labs/agent-desktop` 提交 `6660fbac768dc7e7332837b90ed465684859afa3`，npm 包为 `agent-desktop@1.1.0`。已只读检查总览及 Agent、MCP、GUI 自动化相关笔记；现有 [[Agent循环]]、[[MCP协议]]、[[GUIAgent与多模态定位]]、[[预执行安全网与执行事件]] 不能替代下列四个新概念，建议新增而非重复解释通用协议。

## 建议新增

1. [[概念/无障碍树语义桌面自动化]]：从操作系统无障碍接口读取角色、名称、状态和层级，以语义观察补充截图坐标；不把“后台”误写成拥有独立虚拟桌面。
2. [[概念/快照限定Ref与严格重识别]]：`@<snapshot_id>:e<N>` 只在原快照及会话中解析；完整观测与唯一身份匹配是动作前提，禁止拿裸 `@e1` 或旧编号猜测目标。
3. [[概念/动作投递语义与安全重试]]：只有 `not_delivered` 可自动安全重试；`delivery_uncertain`、`delivered_unverified`、`delivered_verified` 都须先核查副作用，`unknown` 不等于安全。
4. [[概念/Headless与Headed交互策略]]：默认 headless 禁止抢焦点和移动真实指针；`--headed` 是明确的物理输入授权，不是 headless 失败后的自动降级。

## 必须保留的限制

- 本实验只运行 `version`、两个 `skills get`，另做两组固定源码静态契约检查；harness 白名单拒绝所有桌面适配器命令。
- 独立审核发现 `click` 在 ref 校验前会做 Linux AT-SPI 权限探测，初版两个 ref 运行用例已撤除，不再声称删除环境变量即可证明无桌面访问。
- 没有控制真实应用、鼠标、键盘、焦点或剪贴板；没有验证真实无障碍树、MCP 长驻服务、C FFI、Rust 编译、macOS/Windows 或 Linux AT-SPI 动作。
- `ok:true` 不等于业务成功；截图、会话、trace、剪贴板和命令输出可能含私密桌面内容。
- 网站任务完成仍由用户本人点击，本提案不代表网站状态已改变。
