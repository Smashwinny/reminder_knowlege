## 审核发现并修复的问题

1. 原 Gen-4 分支只剥离负向词，再附加“负向约束已改写为正向描述”的元说明；并没有真正输出正向目标。日志与指南却称已改写，名实不符。
2. 原“模型大概率只执行前两个动作”没有生成实验依据，已删除。
3. 原“重生成/改时长后同步关系仍成立”过度保证，改为事件锚只明确意图，仍需逐帧验收。
4. 原“只写 zoom 出来的只是变焦”过度确定，改为 zoom 有歧义，不能据此判定 Dolly Zoom 成功。

## 修订后的真实复跑

`shot_compiler.py` 现在要求 `positive_rewrites` 提供每个负向约束的正向目标；缺失项进入 `unresolved`，不再静默宣称成功。新增断言：

- generic 输出包含全部“禁止<约束>”；
- runway-gen4 输出不含“禁止”，且包含全部正向改写；
- 默认例 7 条验收项，FPV 例 5 条；未转换列表均为空。

实际命令（仓库根目录，`PYTHONDONTWRITEBYTECODE=1 PYTHONUTF8=1 python -I`）：

```bash
python -I ai_camera_movement/exercise/shot_compiler.py
python -I ai_camera_movement/exercise/shot_compiler.py --example fpv
```

两次均正常退出并打印 PASS：

- 默认：稳定器推近/环绕/Dolly Zoom、POV、抬手触发上摇，7 条验收项；Gen-4 真正输出“保持同一个连续镜头”和“主体与场景保持合理空间关系，结构完整稳定”。
- FPV：低空前进→穿窗→落地跟拍，落地触发低机位跟拍，5 条验收项；正向改写为“穿窗、落地和跟拍之间保持连续飞行画面”。
