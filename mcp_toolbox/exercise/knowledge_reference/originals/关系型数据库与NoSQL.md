# 关系型数据库与NoSQL

**一句话定义**：RDBMS（MySQL/PostgreSQL）= 表格 + SQL + 事务（ACID），天然强一致但难水平扩展；NoSQL（Redis 键值 / MongoDB 文档 / Cassandra 宽表 / Neo4j 图）= 结构灵活、为海量数据分布式水平扩展而生，多为最终一致。

**属于领域**：数据库 / 存储选型

**通俗理解**：RDBMS 像规范的大酒店前台（一切按登记簿来，慢但绝不出错）；NoSQL 像灵活的便利店货架（上货飞快，偶尔标签还没贴好）。选型默认路线：拿不准就用关系型（久经考验）；规模逼过来时才引入 NoSQL 这个针对性武器。
