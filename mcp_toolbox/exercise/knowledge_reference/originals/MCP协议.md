# MCP协议

**一句话定义**：MCP（Model Context Protocol）是 2024 年 11 月 Anthropic 开源的开放标准，让任何 AI 应用用同一套"插口"连接外部工具与数据源，把集成的复杂度从 M×N 降到 M+N。

**属于领域**：AI 工具生态 / 协议设计。

**通俗理解**（比喻/例子，讲完落回术语）：AI 的 USB-C。以前每个 AI 应用为每个工具单独写对接代码（M×N 份胶水代码）；有了协议，应用只需实现一次 MCP 客户端，工具只需包成一次 MCP 服务器，两边互不认识也能协作。底层消息格式是 **JSON-RPC 2.0**（"发方法名+参数、收回执"的通用远程调用格式）。架构三角色：宿主 Host（AI 应用）内部跑 MCP 客户端（连接器，每个服务器一个实例），对端是 MCP 服务器（见 [[MCP服务器]]）。一次工具调用三步曲：initialize 握手（协商协议版本+能力）→ tools/list → tools/call。
