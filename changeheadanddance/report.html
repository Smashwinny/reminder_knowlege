🎬 MiniMax-H3 视频换人 LoRA
小白上手报告

模型：akatz-ai/MiniMax-H3-Character-Swap-LoRA · 底模：Comfy-Org/MiniMax-H3 · 平台：ComfyUI

视频换人参考图驱动4~5 秒短镜头实验性作品

① 这是什么？

一句话玩法
给一段原视频（里面有人）+ 一张角色参考图 → 模型把视频里指定的人换成参考图角色，背景、镜头、动作全部保留。
它是什么形态
LoRA = 只有几十 MB 的「补丁」，必须搭配 MiniMax H3 底模（ref2va 版）使用，运行平台是 ComfyUI（版本 ≥ 0.30.0）。

② 硬件与环境要求（第 0 步）

项目要求说明
显卡NVIDIA，建议 24GB+ 显存训练用 32GB 卡；RTX 3090 / 4090 体验较好
硬盘至少 80~100GB 空闲底模 + 文本编码器 + VAE 体量大
软件ComfyUI Desktop ≥ 0.30.0 comfy.org/download 下载安装
CUDAint8_convrot 需 PyTorch cu130老 CUDA 版改用 fp8_scaled 版底模

③ 必下载的 5 个文件（第 2 步）

#文件存放位置
1底模 minimax_h3_ref2va_pruned_int8_convrot.safetensorsmodels/diffusion_models/
2文本编码器 qwen3vl_32b_minimax_h3_nvfp4_awq.safetensorsmodels/text_encoders/
3视频 VAE minimax_h3_video_vae_int8_convrot.safetensorsmodels/vae/
4音频 VAE minimax_h3_audio_vae_fp32.safetensorsmodels/vae/
5换人 LoRA 本体（akatz-ai 仓库 final 版 safetensors）models/loras/

⚠️ 底模必须选 ref2va 版本（吃「视频 + 参考图」）；nvfp4 文本编码器不需要特殊显卡。

⛔ 作者声明的局限
  • 长镜头易漂移、硬切（跳剪）会翻车 → 只用 4~5 秒连续镜头
  • 表情还原不准；仅支持单人替换，双人不行

④ 六步操作流程

第 1 步 · 安装 ComfyUI Desktop

目的获得运行模型的节点式工作台
  • comfy.org/download 下载 Windows 版，常规安装，确认版本 ≥ 0.30.0
效果得到一个能跑 AI 视频的节点画布软件

第 2 步 · 下载 5 类模型并归位

目的LoRA 只是补丁，必须有底模 / 编码器 / VAE 才能跑
  • 按第 1 页表格逐个下载放入对应目录，底模认准 ref2va
效果弹药全部就位，ComfyUI 能识别所有模型

第 3 步 · 打开官方模板工作流

目的不搭节点，直接用现成流水线
  • 菜单 → Template Library → Video → MiniMax H3: Reference to Video
效果画布出现完整流程：加载模型 → 提示词 → 采样 → 保存视频

第 4 步 · 挂载换人 LoRA（关键）

目的给底模打上「会换人」的补丁
  • 双击画布搜 LoraLoaderModelOnly 添加（不要用带 CLIP 的普通版）
  • 接线：UNETLoader 的 MODEL → LoRA 的 model 输入；LoRA 的 MODEL → BasicGuider
  • 选中 character-swap 文件，强度 strength = 1.0；本 LoRA 不需要 Turbo 加速插件
效果模型从普通视频生成切换为换人模式

第 5 步 · 喂素材 + 写提示词 → 生成

目的核心使用环节
  • Video 1：4~5 秒、24fps、无跳切、画面内只有 1 个目标人物
  • Picture 1：清晰角色图（全身/大半身、背景干净，三视图设定表也可）
  • 分辨率 16:9 用 1344×768（Megapixels ≈ 0.98）
效果得到原场景原动作、人已换成你的角色的视频

第 6 步 · 调优与排错

目的玩熟的关键
  • 人没被换掉 → 提示词明确描述目标人物（衣服颜色/位置），确认强度 1.0
  • 参考图背景入画 → 保留 "Do not show the reference sheet..." 一句
  • 背景漂移 → 缩到 4 秒内、换无跳切素材
效果稳定复现可用结果

⑤ 提示词模板（直接抄）

Replace only the man in the purple shirt in <Video 1> with the character in <Picture 1>. Keep the replacement character's identity, outfit, and art style from <Picture 1>. Preserve the source video's camera, background, lighting, objects, and all other people. Match the target person's position, scale, pose, and movement. Do not show the reference sheet or its background. 中文意思：只把 <视频1> 里穿紫衣服的男人换成 <图1> 的角色；保留角色长相/服装/画风；保留原视频镜头、背景、光照、物品和其他人；匹配目标的位置、大小与动作；不要把参考图本身画进画面。
💡 提示词要点
  • 训练时用的是很短的句子（如 "Swap the man in the purple shirt..."），别写太长
  • 不要强加表情要求 —— 实测加上后换人可能直接失效

⑥ 音频与收尾

模型会顺带生成音频，但作者实测不可靠。收尾做法：用剪映等工具把原视频的音频轨直接复制到成片上。

⑦ 显存不够怎么办

方案说明
换 fp8 底模无 cu130 环境时用 minimax_h3_ref2va_pruned_fp8_scaled.safetensors
租云 GPURunPod 等按小时计费的 24GB+ 卡，适合只想尝鲜的用户
降低预期12~16GB 显存需 CPU 分载，速度慢、体验差
