Q1这是什么仓库？数据从哪来？

一句话：有人把 35 家 AI 公司公开发布的面经里的面试题，逐公司整理成一份"考情地图"，约 600 道题，常见题还标注了"哪些公司问过"（比如 KV 缓存一题被 8 家公司问过），能答的题附了答案链接。它由 Outcome School 维护，Apache-2.0 协议，仍在活跃更新（快照前一天刚推送）。

事实项实测数据（本指南实验统计）
题目总数598 道（README 子弹列表全量解析）
带答案链接232 道（38.8%），多为 Outcome School 博客深链
标注"问过公司"的公共题97 道
覆盖公司35 家：OpenAI/Anthropic/DeepSeek/Moonshot/NVIDIA/Cursor/Sierra…
适用岗位AI Engineer / LLM Engineer / Agentic AI Engineer / MLOps 等 13 类
注意边界：题目全部来自公开面经（自述），非任何公司内部真题；面试 loop 随团队/级别/地区变化，作者自己也强调"把它当考情地图看，别当押题脚本"。

Q2它和普通"面试八股文"有什么区别？

三个结构性优势：① 公司维度——每家有 roles、公开报道的面试 loop、按主题分组的公司专属题；② 频次证据——公共题带"Asked at: 哪几家"，复习优先级可以用数据排（KV 缓存 8 家 > MoE 6 家）；③ 答案可追溯——38.8% 的题带答案链接，且多数指向同一作者的深度博客，形成"题→答→体系"链路。这和你知识库"证据优先质检"的品味完全一致：标注来源、区分事实与转述。

Q3仓库的结构是怎么组织的？

实测分布：前沿实验室（OpenAI/Anthropic/DeepSeek/Moonshot 等 12 家）197 题 > AI 原生产品公司（Cursor/Sierra/Harvey 等 11 家）114 题 > 大厂（Microsoft/NVIDIA/Apple 等）82 题 > 基础设施（Databricks/Groq/HuggingFace 等）66 题 > Palantir 20 题。越靠近模型本体，题越偏"内部原理"；越靠近产品，题越偏"系统设计"。

Q6怎么用这个仓库效率最高？

  • 第一步永远是公共题：作者特意把跨公司重复题只在公共节列一次，公司节不再重复——这是为了不让你浪费时间。
  • 答案不够时回自己的知识库：这个仓库的答案覆盖 38.8%，剩下的正好用你已学的概念笔记补齐（见 Q8）。
  • 警惕时效：面试 loop 持续变化，快照会老化；本指南基于 2026-10-07 的 commit b62705c。

🧰 这个项目给我什么（能力清单）

① 数据化的复习优先级
用 Asked at 频次排序，先攻 KV 缓存/MoE/选型框架这类"8 家公司都问"的枢纽题。

③ 自查缺口清单

④ 结构化知识库的样例
单一 README + 锚点互链 + 来源标注的组织方式，可借鉴到自己的 vault 维护。
⑤ 自测工具链
本指南实验的 quiz_generator.py 可持续使用：换主题、换种子就出一张新卷子。
⑥ 批判性阅读样本
它自称"来源公开面经"，教你区分：整理事实、公司标注、答案链接、作者课程引流四层信息。

Q10动手实验：题库分析器 + 种子化自测卷（全部实测）

实验材料在 ai_engineering_interview_questions/exercise/quiz_generator.py（纯标准库），直接解析仓库 README 的真实结构。以下输出为 2026-10-07 本机实测。

第 1 步 · 全库统计

cd ai_engineering_interview_questions\exercise set PYTHONUTF8=1 && python quiz_generator.py stats
实测输出（节选）： 题目总数：598 带答案链接：232（38.8%） Frontier AI Labs 197 题 / 公共题 119 / AI 原生产品 114 / 大厂 82 / 基础设施 66 公司提及榜：Anthropic 13 / OpenAI 12 / NVIDIA 11 / Perplexity 11 / Microsoft 11 …
✅ 预期结果：数字与 Q1 表格一致；过程中会发现目录/说明区的列表项被误当题目（已用分区白名单修正）。

第 2 步 · 按主题抽自测卷

python quiz_generator.py quiz --topic "RAG" --count 5 --seed 42
实测输出：从 12 道 RAG 题中抽出 5 道（分块策略/BM25vs稠密/HyDE/索引保鲜/管线评估）， 生成 quiz_RAG.md + quiz_RAG.html（彩色表格，含问过公司与有无答案）。
✅ 预期结果：生成两个文件；同种子重跑结果完全一致（可复现）。

第 3 步 · 换种子出新卷

python quiz_generator.py quiz --topic "RAG" --count 5 --seed 7
✅ 预期结果（实测）：换到另一组 5 题（agentic RAG/reranker/语义漂移等）——同一题库，两张不同卷子。
