- ## 首次失败与真实诊断 初次clearance执行发生AssertionError：`assert all(x['passed_depth_threshold'] for x in rows if x['offset_mm']==[0.,0.])`。 原因：起始销底在板顶上1mm，板厚10mm且下面有地板，居中落距最多约11mm；初稿要求12mm不可能达到。 诊断实际测得20/100/500µm三种居中落距均11.0000668mm；偏2mm为5.1873/5.5954/6.1421mm。 据此将阈值明确改为落距>9mm，保留其“中心深度代理、非整面入孔”含义并重跑。首次标准输出保存在exercise/first-attempt-output.txt；其异常栈未重定向到该文件，本段依据实际工具异常记录补记，不假称原日志已含stderr。
