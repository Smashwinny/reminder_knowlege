# ARCHITECTURE.md —— 订单利润日报工具（架构与异常处理）

> 本文件对应工作流中"Claude 角色"的产出：完整架构、异常处理、操作说明。
> 代码实现见 order_profit_daily.py（"Codex 角色"产出）。

## 一句 spec

把指定目录下多份订单 CSV 合并为一份利润日报 HTML：按平台汇总 + 明细标红异常订单。

## 架构

1. **加载层** `load_orders`：遍历目录 *.csv（utf-8-sig 兼容 Excel 导出 BOM），追加 `_来源文件` 列溯源。
2. **计算层** `compute`：利润 = 实收 − 成本 − 运费 − 平台扣点（扣点率显式配置于 `PLATFORM_FEES`，禁止硬编码魔法数字）。
3. **渲染层** `render`：KPI 卡 + 按平台汇总表 + 明细表；利润率 < 10% 的订单行标红。

## 异常处理（对应"AI 算账死穴"的三道防线）

| 风险 | 防线 |
|---|---|
| 隐藏成本（扣点漏算→假利润） | 扣点率必须显式配置；未知平台**拒绝运行**而非静默按 0 处理 |
| 字段缺失/脏数据 | 字段异常时显式报错并指出文件名与缺失字段，exit=1 |
| 除零（实收为 0） | 利润率按 0 处理，不抛异常 |

## 定时逻辑（交付客户时的建议）

Windows 任务计划程序：`schtasks /create /tn 订单日报 /tr "python order_profit_daily.py 数据目录" /sc daily /st 08:00`。
客户场景数据目录固定后一次配置即可，符合"开机自己跑"的交付承诺。

## 操作说明（交付 README 同款）

1. 把导出的订单 CSV（含表头：订单号，平台，实收，成本，运费）放进数据目录；
2. 双击运行 `run.bat`（或命令行执行上方命令）；
3. 打开生成的 `日报.html` 查看，红色行为异常订单。
