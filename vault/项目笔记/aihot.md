# AIHOT / 行业热点框架

**这是什么**：后台采集、筛选、归组和编写刊物，前台只读已发布内容的行业热点站。

**固定版本**：3343fe2b20db4be7269113752d82d3992fc52b6b。源码克隆在 `aihot/repo/`，不纳入学习总仓提交。

**它给我什么能力**：把 GeniusQI 项目摘要和学习内容移到后台/构建期；多个三维主题共享公开内容；按项目归组版本与证据；后台 AI 有成本和质量护栏。

**引入的概念**：
- [[统一公开读取层]]
- [[缓存有效期与发布边界]]
- [[付费调用回执与预算熔断]]
- 关联补强 [[先量后优化性能法]]、[[Three.js与场景图]]，不另建重复基础概念。

**实验记录**：原版架构检查 3/5，Windows 路径归一化夹具 5/5；6 个上游缓存纯函数测试 + 5 个自建快照断言通过。公开候选 7 个，其中 Fork 6 个；街区猫王是非 Fork 的改编实现候选，Demo 未实际验证。现有 4 个 VRM 的 gzip 解压后逐字节一致，审计只统计资源不声称提速。

**坑与结论**：新闻服务器毫秒级响应不能类比为人物可操作时间。已有 Three.js，不因学习另一个站就换框架。Edge 无头打印本环境未输出，改用本地 ReportLab 生成彩色 13 页 PDF，Poppler 渲染检查，保留 HTML。

**成果**：[图文指南](../../aihot/aihot_guide.html)、[彩色PDF](../../aihot/AIHOT-小白指南与网站应用.pdf)、[互动学习实验](../../aihot/learning_lab.html)。本地脚本在 aiHOT 的 exercise/，无需 API Key。

**未做/下一步**：未运行全套 Docker/数据库/模型采集；未修改公开网站。下一轮补 click-to-controllable 分段埋点与同条件 A/B，再决定 KTX2/Meshopt/编译预准备；另行接入街区猫王和学习展厅。
