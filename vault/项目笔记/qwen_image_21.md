# Qwen-Image-2.1 云端部署核算

Qwen/Qwen-Image-2.1 是文生图与编辑统一管道。HF 月下载约 19.6 万；本次只核实版本、权重体积、许可与云成本，未租 GPU、未下载权重、未实际推理。

## 带来的概念
- [[组件口径宣传陷阱]]：“7B”仅指视觉 transformer，不能代表整个管道的磁盘与显存需求。
- [[云端实例生命周期计费]]：开机时长与付费磁盘生命周期往往比单价更决定成本。

## 实测
HF tree API 实测 text_encoder 17.54GB + transformer 14.23GB，BF16 权重合计 31.76GB。视觉 transformer 约 7.1B 参数与官方 7B 自洽，text_encoder 另约 8.7B。BF16 全量驻留显存约 63.5GiB，24GB 卡需 CPU offload；“32GB 保证不爆”只在 offload 前提下成立。

LICENSE 限定非商业研究/评估，商用需单独许可，与原帖“无需许可”矛盾。AutoDL 按开机计费，付费盘关机仍计费；50GB 免费盘装权重后余量紧张。1.58 元/小时与 31 秒出图均为作者个案，未独立复现。
