# agent-engineering（AI 工程化五件套）

**这是什么**（一句话）：Miles Ma 的免费 X 长文《我们说的 AI 工程化，到底是什么》——把 Context/Harness/Loop/Eval/Graph 五个时髦词拆成"核心还是提示词"的一套生产级工程方法；推文以"闲鱼 49.9 的课免费开源"引流，本体是作者原文，非盗版非搞钱课。

**带来了哪些概念**（4 个新概念）：
- [[上下文工程四操作]] — Write/Select/Compress/Isolate 全景分类（[[Compaction上下文压缩算法]]、[[上下文预算与战略压缩]] 各占其中一格）
- [[失败反馈具体化]] — step/missing/fix 三要素；0 比特反馈=原样重跑（exp1：5 轮烧完 vs 2 轮收敛）
- [[评估钻空子EvalGaming]] — 白卷满分演示＋意外发现"死抠字面会误杀诚实者"（exp3）
- [[代码管边界提示词管判断]] — 总准绳：挽回不了的归代码，能挽回的归提示词

**实验做了什么**（3 个零 API 实验，全部真跑通，exercise/）：
1. exp1_loop_feedback.py — 同一规则策略同一套工具，只变反馈信息量：坏反馈 5 轮全烧完，三要素反馈 2 轮收敛 TOTAL:800
2. exp2_context_ops.py — 旧文档词频 21:4 骗过关键词策略选中废弃 v1；四操作后 token 681→265(38%) 选对 v2。坑：Select 切分点写错一位（6 应为 7）致首跑结论翻车
3. exp3_eval_gaming.py — "总结：详见原文。"骗过糊涂校验器满分；严格校验器拦住；但"耳痛"被字面"耳朵疼"误杀——评估标准要机器可查+语义容错

**坑与结论**：
- 判定要点："闲鱼 49.9 开源课"顺链查证 = 作者本人免费长文，无仓库无盗版 → 学习类
- 文章没有 GitHub 仓库，实验全部自造（规则策略模拟模型，确定性可复现）
- 动工顺序建议：Eval → Loop → Context → Harness → Graph（校验器既是评分官又是反馈源）
