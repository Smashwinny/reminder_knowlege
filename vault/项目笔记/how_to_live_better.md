# HowToLiveBetter：证据组织与可追溯检索

**这是什么**：把人生建议组织为可检索条目、证据标签和成本收益信息的公开知识项目。本次学习其证据组织方式，未验证全部建议，也不提供个人健康、法律或金融指导。

**固定版本**：`bc149af3a02e721f0e3d03a673a0ec64fca765c4`。该版本 README 自述 658 条、34 节，本次没有重数全部条目。学习只读第 4 节 18 条，深查 3、6、7 三条。

**得到的能力**：从 README 定位完整条目；将条目追到 DOI 和核实记录；区分仓库事实、研究转述、作者算账假设和建议；信息不足时弃权；用固定版本与哈希复跑并发现跨文件更新缺口。

- [[可读层级与来源追踪]]

**已有知识关联**：沿用 [[事实与判断分离]]、[[证据状态机]]、[[置信度门控与弃权]]、[[证据优先质检ProofOverClaims]] 和 [[AI味模式库与信号非证据]]。已查本机概念名、别名及正文，三项新笔记分别覆盖取舍维度、实际阅读层级和同提交文件不同步，与既有概念相关但不等同。

**真实实验**：自建只读 Python 标准库脚本实际运行六个显示检查点及端到端命令，每次执行 11 类检查。6 个 DOI 都能定位到仓库核实记录；未知百分比为 `null`，不存在条目和缺来源不补写，损坏输入拒绝。Windows 独立复跑七次，稳定结果逐字段一致，仅排除开始/结束时间；另三种损坏输入分别以退出码 1 拒绝且不生成结果目录。源文件前后哈希保持不变。

**产物与审核**：[11 页彩色指南](../../how_to_live_better/HowToLiveBetter-小白指南.pdf)、[HTML](../../how_to_live_better/guide.html)、[练习说明](../../how_to_live_better/exercise/README.md)。Dot 独立审核修正许可、术语与图示后重新检查全部 PDF 页面；Windows 再实际查看 11 页并复跑实验。ReportLab 直接 PDF 已通过，云端 HTML 浏览器预览及 HTML→PDF 受阻，不能写成通过。

**结论边界**：找到引用不等于独立重验论文。脚本未读外部论文；云端外源补充只到官方摘要/元数据，全文未读。正文 4.11 与旧核实记录不同步，只记为溯源缺口，不判断该数值真假。任务是否勾选完成由本人决定。
