# ai-video-pipeline（AI 热点长视频生产流水线）

**这是什么**：Simon聊AI（@HanZhang415188，十年 NLP 算法工程师）2026-09-18 X 长文《用 AI 做热点长视频：单条 108 万播放，3 天涨粉近万的实操复盘》的完整拆解与离线复刻。一套"人守两头（选题门+事实门）、AI 跑中间"的热点深度长视频生产流水线：抓热点→审选题→跑生产（Skill 全自动：查原始文档→口播稿→TTS→Remotion 渲染）→细核对→8 平台分发。数据战绩：7 天 258 万播放、3 天涨粉 9149、单条 108 万。作者预告下篇将开源制作 Skill 源码。

**它给我什么能力**：
- 五阀选题评分器（确定性代码，可改口径复用到任何内容赛道）
- 分句 TTS + 实测时长时间轴 → 数据驱动视频渲染（改 props 出新片）
- 成本-产量模型（订阅费÷月产量=单件成本，评估任何 AI 订阅档位）
- 《核心事实卡》合规纪律（观点↔信源↔时间戳三挂钩）

**引入的概念**：
- [[React逐帧视频渲染]] — Remotion：每帧=React 组件一次绘制，props 进 mp4 出
- [[质量标准死卡与执行手段放开]] — 全局 Skill=岗位职责书：验收标准死卡、执行路径放开 + 分步交付
- [[无约束实验与经验格式化]] — 旧 Skill 固化范式是新模型的天花板，定期剥预设只留交付标准
- [[情绪脱水测试]] — 删情绪词验事实密度；选题五阀一票否决

**实验记录**（exercise\，全部真实运行）：
- ex1_xuanti.py：五项内审法评分器，零依赖。好题"物业暗扣"5/5 PASS（36h 时效/泛化钩子/2 条一手信源/脱水保留 100%+4 处事实/叙事轮换）；坏题"A市阳光花园物业跑路"5/5 一票否决（3348h 旧闻/个案地名/无链接信源/仅剩 53%+0 事实/同型连打）。10/10 断言过。
- ex2_tts.py：edge-tts 7.2.7 逐句配音（zh-CN-YunxiNeural），5 句共 30.38s，逐段 ffmpeg 实测时长生成 timeline.json，分段和==整条（断言过）。
- ex3 remotion_app：React 组件 calculateMetadata 由真实音频时长驱动（1002 帧=(30.38+3)s×30fps），npx remotion render 真出 demo.mp4 2.9MB（h264+aac，1280x720）。抽帧验证声画同步：22s 处"关键事实 4/5"对应旁白 19s∈第 3 句（18.64~23.85s）。
- ex4_cost.py：文章账单复算吻合（$100÷60=$1.67、÷10=$10）；本地复刻版 edge-tts ¥0 + Remotion 个人免费 = 零 API 费。

**坑**：
1. `--props=timeline.json` 直接传内层数据，组件 prop 是 `{timeline:...}`——key 缺失静默回退 defaultProps 占位句，渲染"成功"但全片只有片头卡；抽帧定位后包一层 props.json 修复。
2. ffmpeg 不在 PATH，用 imageio-ffmpeg 自带静态二进制（沿用 ai_shortdrama_tools 判例）。
3. 文中"下篇开源 Skill"尚未发布——本篇是方法论层复刻，工程细节（素材检索 Agent、合成参数）等开源后做补充篇对拍。
