# 12306-mcp：12306 车票查询 MCP 服务器

> worker 按协调者 2026-10-07 裁定新建。概念提案见 `12306_mcp/12306_mcp-knowledge-proposal.md`。

## 是什么

Joooook 开源的 TypeScript MCP 服务器（MIT，快照 ff6439d，2026-10-07 实测 2258 stars）：
把 12306 网页接口包装成 8 个 MCP 工具，让 Claude Desktop / Claude Code / Codex 等
用自然语言查余票、中转、经停站。只查不买。

## 结构

- 启动：抓 12306 站名 JS 建四张索引（STATIONS/CITY_STATIONS/CITY_CODES/NAME_STATIONS），
  并动态探测 leftTicket/lcQuery 现行查询路径（应对官方改路径的关键设计）
- 基础层工具（5）：get-current-date、get-stations-code-in-city、get-station-code-of-citys、
  get-station-code-by-names、get-station-by-telecode
- 核心层工具（3）：get-tickets、get-interline-tickets（只回前10条）、get-train-route-stations
- 传输：stdio（本地子进程）或 HTTP/SSE（--port）；zod 做参数守门
- 调用链：Cookie 预处理 → kyfw.12306.cn /otn/leftTicket/query 等接口 → 结果格式化为自然语言

## 实验（真实运行，exit=0）

`exercise/mcp_client.mjs`（MCP stdio 客户端）五步调用：
listTools → get-current-date → 城市代码翻译 → get-tickets（2026-10-08 北京→上海 G，
真实返回 6521 字符余票表，G1 二等座 661 元剩 1 张）→ G531 经停 13 站时刻表。
完整输出在 exercise/run_output.txt；日志 12306_mcp-experiment-log.md。

坑：Windows 下 import.meta.url.pathname 需 fileURLToPath；参数名以 zod schema 为准
（citys/trainCode/departDate）；克隆仓库 npm i 用 --ignore-scripts 规避生命周期脚本。

## 结论边界

依赖 12306 网页接口现行结构，官方改版即可能失效；中转只回前 10 条；余票为查询时刻快照。
可作为"包装网页接口为 AI 工具"的通用范本（动态路径探测+Cookie 预处理+输入输出双层翻译）。
