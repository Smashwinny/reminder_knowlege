# today_topic_radar：引用帖选题工作流与五项启发式

## 项目是什么

学习原引用帖的“候选与理由→来源保留→只产草稿”工作流，并与 Today 官网的常驻助理产品描述分开。2026-11-22 官网未承诺独立“选题雷达”、免费无限、任意任务成功或 Token 赠送。

## 来源核实

- 官网：https://today.ai/
- 原引用帖作者入口：https://x.com/LufzzLiz

2026-10-28 曾真实读取 GitHub/HN API 得到 11 候选；该历史榜单不作为当前事实。2026-11-22 复核官网并改用合成夹具，未重跑实时 API。

## 带来的概念

- [[候选来源草稿三段式]]：候选、来源、草稿三阶段，发布权保留给人。
- [[情绪脱水测试]]：追加简化评分变体的边界；标题词初筛不等于全文脱水。
- [[中继交叉印证]]：HN 是直接讨论信号，不等于原报道核验。

## 实验做了什么

初版只有四类加分却称五阀，并无叙事轮换，HN 也无条件送时效分。新版五项各 1 分：时效、目标受众、直接信号、标题脱水初筛、叙事轮换。5 条合成候选输出 `radar-draft-v2.md`，7 项 unittest 全部通过。

## 坑与结论

- 评分只排序，不证明事实、质量、传播效果或授权。
- v2 指南逐页渲染审核，原 PDF 保留，manifest 指向 v2。
- 指南：`today_topic_radar/today-radar-guide.html`；审核版：`today_topic_radar/Today选题雷达工作流-小白指南-v2.pdf`。
