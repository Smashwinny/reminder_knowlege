# ai_camera_movement：运镜工单与真实方言转换

## 项目是什么

从《AI 视频运镜词典（下篇）》学习稳定方式、空间路径、观看视角、时间结构和触发点，把自然语言运镜意图变成可编译、可检查的结构化工单；对照 generic 与 Runway Gen-4 两种文本输出。

## 来源核实

- 原记录：https://x.com/goan999999/status/2105201441543696531
- Runway：https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide

初学习记录称通过 web 读取官方“不支持负向措辞、正向描述并逐项迭代”；2026-11-22 复核该页为 403，未重新取得正文，指南如实区分。Dolly Zoom 双条件作为摄影定义和验收判据保留，不冒称真实生成已验证。

## 带来的概念

- [[运镜四要素工单]]：稳定/路径/视角/时间+触发点，文本明确不等于模型执行。
- [[提示词方言适配]]：必须真正输出目标模型表达，未转换项 fail-closed。
- [[动效描述词表]]：跨领域参数化关联，不把 CSS 缓动指标套到空间运镜。
- [[PromptAsCode提示词即代码]]：追加模型方言适配层与文本断言。

## 实验做了什么

初版 Gen-4 分支只剥离负向词并附“已改写”元说明，没有真正改写。修订后 `positive_rewrites` 提供具体正向目标，缺失项进入 `unresolved`。默认与 FPV 两命令实际复跑：generic 含全部“禁止”，Gen-4 不含“禁止”且包含全部正向目标；默认 7 条、FPV 5 条验收项，断言全部 PASS。

## 坑与结论

- 未生成任何真实视频，未验证运镜质量、跨模型成功率或官方示例。
- 删除“模型大概率只执行前两个动作”等无依据断言；一镜头一主运动仅是保守起步策略。
- v2 指南共 9 页，全部逐页渲染检查，原 PDF 保留，manifest 指向 v2。
- 指南：`ai_camera_movement/ai-camera-guide.html`；审核版：`ai_camera_movement/AI进阶运镜-小白指南-v2.pdf`。
