按领域分区，概念间用 `[[双链]]` 关联。新概念若与已有概念是同一事物，合并进旧笔记并加别名。

### 领域：三维图形

- [[Three.js与场景图]] — 浏览器三维渲染库 + 父子层级树

### 领域：软件工程 / AI 协作

- [[确定性脚本]] — 同输入同输出，是 Gate 可信的前提
- [[零依赖编程]] — 只用标准库，随处可跑

### 领域：AI 工具生态
- [[MCP协议]] — AI 连接外部工具的开放标准，M×N → M+N；底层 [[MCP服务器]] 与 [[stdio与流式HTTP传输]]
- [[MCP服务器]] — Tools/Resources/Prompts 三能力；一条命令装进 Claude，三步自造
- [[stdio与流式HTTP传输]] — 本地子进程 vs 远程 URL，对应 🏠/☁️
- [[MCP模型上下文协议]] — 同一协议的并行批次笔记（与 [[MCP协议]] 互链）；报文层见 [[JSON-RPC与stdio传输]]
- [[JSON-RPC与stdio传输]] — JSON-RPC 2.0 三种消息 + stdio 通道纪律（stdout 即协议）
- [[工具调用生命周期]] — 发现→决策→调用→执行→返回；与 [[LLM工具调用]] 互为协议侧/框架侧
- [[M×N集成问题]] — 协议之所以存在的经济学：M×N 定制对接 → M+N
- [[提示注入]] — 藏在数据里的恶意指令；Gate + 最小授权 + 审计三防

概念主线：**流水线拆解复杂任务 → 各 Pass 之间设 Gate → Gate 依赖确定性裁判 → AI 借此自我纠错 → 产出程序化 Three.js 模型**；AI 工具生态主线：**MCP 协议标准化工具接口 → 框架（LangChain/CrewAI）管编排 → 服务器管能力复用**

### 领域：AI / LLM 应用
- [[ChatModel与消息类型]] — 统一模型接口（万能转接头）+ 4 种消息角色（System/Human/AI/Tool）
- [[LLM工具调用]] — LLM 只"点菜"（输出 JSON），框架"炒菜"（真正执行函数）
- [[Agent循环]] — 模型↔工具自动循环直到任务完成，错误回流即自纠
- [[RAG检索增强生成]] — 开卷考试：先检索相关段落再回答（Embedding 语义坐标 + VectorStore）
- [[提示词模板]] — 带变量槽位的提示词对象，组装过程确定可测
- [[LangGraph与Agent编排]] — 状态图引擎：节点+边+全局状态，Agent 循环只是最简单的两站环线
- [[共享状态与Reducer]] — 共享白板：节点进全量快照、写回增量；Reducer 管并行写入合并
- [[Checkpoint存档与持久执行]] — 每步一快照，崩了从存档续跑不重花钱；thread_id 一人一档
- [[人机协同Interrupt]] — "暂停等人"= 存档+退出，Command(resume) 带答案唤醒
- [[Agent中间件]] — 插进 Agent 循环的钩子：摘要记忆、人工审批、隐私抹除

概念主线：**ChatModel 统一接口 → LLM"点菜"框架执行（工具调用） → 错误回流模型自纠（Agent 循环 ≈ [[质检Gate与自我纠错循环]] 的 LLM 版） → LangGraph 状态图保证可控 → middleware 插槽扩展**
