# 反思模式 Reflection

**一句话定义**：让 LLM 生成 → 另一个 LLM（或同模型换角色）当批评家打分给意见 → 带意见重写，循环到达标或到上限——《Agentic Design Patterns》模式 4。

**属于领域**：AI Agent 质量工程

**通俗理解**："写作文 → 对照评分标准自检 → 修改"的 AI 版。实验实测：文案 4 分（缺数据）→ 7 分（数据无来源）→ 9 分（达标提前停），逐轮可解释地收敛。

**为什么必须两个停止条件**（本模式最重要的工程细节）：
- 只有"分数达标才停"→ 碰上永远不合格的任务无限烧钱；
- 只有"最多 N 轮"→ N 轮后可能是无人知晓的半成品。
**阈值管质量，轮数上限管成本，缺一不可。**

**与已有概念的关联**：
- [[质检Gate与自我纠错循环]]：同一思想；区别在 Gate 的打分器要求确定性脚本，而反思的批评家本身是 LLM（有随机性）——所以需要 [[LLM裁判与自动评估]] 再校准批评家
- [[Agent循环]]：错误回流即自纠是其内置形态；反思模式把"批评"显式独立成一个角色
- [[护栏模式Guardrails]]：护栏拒收的错误信息正是反思循环最好的修改素材（Ch4×Ch18 组合拳）
