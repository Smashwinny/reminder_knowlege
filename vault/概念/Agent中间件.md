# Agent 中间件

**一句话定义**：Middleware 是插在 Agent 循环各环节（模型调用前后、工具调用前后、循环结束时）的钩子组件，`create_agent(middleware=[...])` 传入；LangChain v1 内置了摘要压缩、人工审批、隐私抹除、参数强制修正等现成中间件。

**属于领域**：LLM 应用 / Agent 工程

**通俗理解**：像**海关安检通道**设在旅途中必经之路上——所有行李（发给模型的内容）过境前统一检查/加工，不用改每个"旅客"本身。典型用途：对话太长自动压缩成摘要（省上下文=长期记忆）、危险工具调用前暂停等人类点批准、发模型前抹掉手机号身份证号。
