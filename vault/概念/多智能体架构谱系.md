# 多智能体架构谱系

**一句话定义**：多个 Agent 在同一任务上协作的不同组织方式——共享黑板竞价、轮流辩论投票、编辑部流水线、或由一个路由器分诊派活。

**属于领域**：AI / LLM 应用（Agent 架构）

**通俗理解**：
- **Blackboard**（1980s HEARSAY-II 语音识别老祖宗）：无中央指挥，所有 Agent 每轮看共享黑板、自评"我能贡献多少"竞价，最自信者写一笔，无人出价即结束——头脑风暴会议室。
- **Debate**：K 轮 × N 个 Agent 各抒己见+互评，末轮多数表决——辩论赛+观众投票。
- **STORM**：固定流水线（头脑风暴视角→出题→作答→汇成大纲），写长文调研专用。
- **Meta-Controller**：一个 LLM 看任务选架构（写作走 Reflection、多跳调研走 ReAct）——分诊台护士，让 35 种架构可以共存在一个系统里。
- 与 Ensemble 区别：Ensemble 的投票者跑同一任务不同 prompt，Debate 的投票者互相看得见。
