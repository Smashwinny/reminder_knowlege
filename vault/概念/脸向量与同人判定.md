# 脸向量与同人判定

**一句话定义**：把脸变成一个 L2 归一化的 256 维向量，"是不是同一人"就变成"两个向量方向够不够近"——本 SDK 的打分公式 `(sum(f1·f2)+1)×50` 把余弦相似度拉皮成 0~100 分，阈值 75 等价于 cos≥0.5。

**属于领域**：计算机视觉（度量学习/人脸验证）

**通俗理解**：每个特征网络（如 IR-50）训练时只干一件事：把同一个人的脸在向量空间里拉近、不同人的推远。训练完把分类层扔掉，倒数一层输出就是"脸的身份证号"。比较时逐元素相乘求和（点积）——因为向量已归一化（范数=1），点积直接等于余弦相似度，不需要再除分母。`+1)×50` 是线性映射：cos=-1→0 分、cos=0→50 分、cos=1→100 分。

**与已有概念的关联**：
- 就是 [[向量与Embedding]] 在人脸上的实例 + [[余弦相似度]] 的直接应用
- 衡量模型好坏的第一指标是**同异分离度**（gap）：实测同人跨角度 cos≈0.725、不同人 cos≈0.18~0.37，阈值 0.5 躺在沟里才可用
- "常规变装（翻转/旋转/模糊/提亮/缩放）打不倒、角度刁钻才掉分"——因为对齐+归一化专治像素级变化，几何大变化才伤向量
- 用外部"别人"样例补测拒绝能力（官方 demo 常只有同人图）——[[证据优先质检ProofOverClaims]] 的模型版
