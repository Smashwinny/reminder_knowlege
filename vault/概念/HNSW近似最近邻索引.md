# HNSW近似最近邻索引

**一句话定义**：把全库向量组织成多层"邻居图"，查询从顶层稀疏图大步跳、逐层下降、底层精确收尾，用对数次跳转在亿级数据里毫秒找到近似最近邻。

**属于领域**：算法 / 近似最近邻搜索（ANN）

**通俗理解**：像"先走高速、再走省道、最后走小巷"。顶层只有少数"枢纽点"、边长（跨得远），越往下越密、边越短；查询点从顶层随便一个入口出发，每层贪心走向离目标更近的邻居，到底层时已站在目标附近。代价是**"近似"**——可能错过真正的第一名，但用 `hnsw_ef` 等参数可权衡精度与速度，99% 场景无感。对比：暴力比对是精确的但 O(N)；HNSW 是 O(log N)。写入后索引在后台异步构建。

**与已有概念的关联**：
- 服务于 [[向量数据库]] 的检索加速（Qdrant 默认索引）
- 检索时打分用 [[余弦相似度]]
- 结构思想类似跳表（多层稀疏/稠密），但节点是向量、边权是语义距离
