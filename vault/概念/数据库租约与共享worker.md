# 数据库租约与共享worker

**一句话定义**：在 GUI、idalib/idat worker 和多个客户端之间共享同一个 IDB 时，每个连接持有独立租约；关闭一个客户端只释放自己的租约，不等于关闭别人的 GUI 或删除共享数据库。

**领域**：逆向工程 / 生命周期与协作。来源：[[项目笔记/ida_pro_mcp]]（官方 ida-mcp/Nexus 文档）。

它与 [[构建流水线与Pass]] 的生命周期视角相关：必须分别验证打开、保存、释放、取消与外部 GUI 状态，不能把单客户端 close 当成全局终止。本次仅文档学习，未验证实机 Nexus 行为。
