# 人脸识别流水线

**一句话定义**：人脸识别不是"看一眼认出你"，而是 检测→关键点→对齐→特征→比对 五道工序的流水线，每道工序为下一道"减负"。

**属于领域**：计算机视觉（本地生物识别）

**通俗理解**：像工厂流水线造车——先在海量原料里圈出"有脸的区域"（检测，MB-Tiny SSD 这类 1MB 级单阶段检测器，多尺度特征网格上一格放 anchor 一次预测），再标出眼角鼻尖嘴角 68 个坐标（关键点，MobileFaceNet 从 64×64 灰度小图**回归**出 136 个数——分类网络改最后一层神经元个数就能输出连续坐标），再把歪的头"扶正"成 128×128 标准小图（对齐，仿射变换），最后把标准脸变成一串数字去比对。分工越细，每个模型越小越快——这是全链路能纯 CPU 单脸 50ms 的原因（实测：检测 20ms + 关键点 6ms + 对齐 1ms + 特征 21ms）。

**与已有概念的关联**：
- 特征环节产出的就是 [[向量与Embedding]]：脸 → 256 维 L2 归一化坐标（IR-50 骨干网，InsightFace 血统，度量学习"同拉近异推远"）
- 比对就是 [[余弦相似度]]：见 [[脸向量与同人判定]]
- "数据不出设备"哲学与 [[本地推理引擎]]（ollama）同源：权重在自家厨房；与 [[个人记忆流水线]] 的本地加工纪律互链
- 关键点 → 对齐的"神经网络算相对值、确定性代码管换算"分工，是 [[事实与判断分离]] 的视觉版
