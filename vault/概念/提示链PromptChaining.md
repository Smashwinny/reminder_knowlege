# 提示链 PromptChaining

**一句话定义**：把任务拆成固定的几个 LLM 调用站顺序执行，站与站之间用结构化输出（JSON）契约交接，不给模型流程自主权——《Agentic Design Patterns》模式 1。

**属于领域**：AI Agent 编排

**通俗理解**：工厂流水线，不是老师傅带徒孙。每站只干一件事（抽关键词→写大纲→成稿），上一站产出什么形状的 JSON、下一站就吃什么形状——坏在哪一站立刻知道，因为每站都能单独断言。

**与 [[Agent循环]] 的选型法则**：能用提示链解决就别上 Agent 循环——提示链确定性高、省 token、可单测；只有"下一步做什么"本身需要模型临场决定时才升级为循环。LangGraph 里提示链就是最简单的单向状态图（见 [[LangGraph与Agent编排]]）。

**与已有概念的关联**：
- [[构建流水线与Pass]]：同一思想在 AI 编程协作的版本；提示链是 LLM 版
- [[提示词模板]]：每一站的提示词就是个带变量槽的模板对象
- [[确定性脚本]]：站间交接用代码校验，不靠模型自觉
