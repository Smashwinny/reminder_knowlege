# 本地推理引擎

**一句话定义**：在自己电脑的 GPU/CPU 上直接运行大语言模型（而非调用云端 API）的软件层，代表：Ollama、llama.cpp、vLLM。

**属于领域**：AI / 大模型工程

**通俗理解**：云端大模型像"叫外卖"，本地推理像"自家厨房"——食材（模型权重）要自己买、灶台（显存）要够大，但菜怎么做、数据给谁看全由自己控制。比喻讲完落回术语：推理引擎的核心工作是**把模型权重从磁盘载入显存、调度计算、逐 token 生成**，其中"谁常驻显存、谁被换出"由调度器决定（[[构建流水线与Pass]]思想的运行时版本）。

**关键数字**（RTX 4070 12GB 实测）：模型常驻显存后首 token 从 40s 降到 1s；Q4 量化下每 1B 参数约占 0.6GB 显存。

- 权重载入/推理/卸载的调度：[[构建流水线与Pass]]
- 显存构成中的动态部分：[[KV缓存与上下文]]
- 权重能变小的前提：[[量化与GGUF]]
