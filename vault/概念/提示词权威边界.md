# 提示词权威边界

**一句话定义**：在多文件协作的 Agent Skill 里，把"谁有权改提示词的哪一部分"写死成规则——美学原文（宪法）逐字进请求且禁止概括/翻译/替换，运行时层（军规）只准追加交付变量（模式/尺寸/语言），生成前还要自检结构（恰好一个 OUTPUT MODE 行）。

**属于领域**：AI 工具生态 / 提示词工程

**通俗理解**：AI 最爱"自由发挥"——你给它一段精心写的风格提示词，它常偷偷概括、润色、加戏。权威边界就是给提示词划"产权"：**宪法管审美**（主体怎么变、配色从哪来、留白多少），**军规管物流**（画布多大、原图可见不可见、文字什么语言），两边互不越权；组装顺序固定（宪法全文 → 前言 → 恰好一个模式块 → 恰好一个文字块 → 用户额外要求）。配套的"消毒输出"纪律：工具脚本只打印脱敏状态码，绝不打印提供商名、endpoint、凭证、提示词原文。落回术语：这是提示词工程中防漂移（prompt drift）的结构性方案，比"请一定要原样使用"的口头嘱咐可靠得多。

**与已有概念的关联**：
- 是 [[AgentSkills技能包]] 的内部治理结构：小小东 xxd-panel 军团用它让一个家族运行时（soldier-runtime）配 56 份不同美学宪法（original-prompt）
- 防漂移效果即 [[规格书先行SpecDriven]] 的提示词版：原文即合同
- 消毒输出是 [[提示注入]] 防护的姊妹纪律（不外泄、不越权）
