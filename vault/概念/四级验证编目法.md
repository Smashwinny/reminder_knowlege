# 四级验证编目法

**一句话定义**：给每条收录记录依次标注附件确认、主张核对、独立复现、完整复核；允许大量记录停在低级，但不把“编目完成”冒充“验证完成”。

**领域**：知识管理 / 可信数据。来源：[[项目笔记/awesome_ai_motion]]（1728 条实测：附件 100%、主张 98.1%、复现 0、复核 0）。

它是 [[证据状态机]] 在编目侧的镜像，也与 [[中继交叉印证]] 的发现与核对双通道一致。数据膨胀时应查 cases.json 真源，不引用滞后 README 数字。
