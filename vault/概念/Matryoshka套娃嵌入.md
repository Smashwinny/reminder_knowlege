# Matryoshka套娃嵌入

**一句话定义**：训练 embedding 模型时让每个向量的**每一个前缀**（前 64 维、前 256 维、前 512 维……）都单独可用，像俄罗斯套娃一样一层包一层；用的时候按需截断 + 重新归一化即可得到低维向量。

**属于领域**：AI / 表示学习 / 向量检索

**通俗理解**：普通 embedding 像一支定长的卷尺（512 维就是 512 维，不能少）；Matryoshka 像一本书的章节——只读第 1 章是简版，读前三章是中等版，全读是完整版，每一级都是自洽的完整故事。比喻落回术语：实现上只是在训练损失里让每个截断前缀都参与对比学习，让每个前缀方向都"学会检索"，推理时 `normalize(emb[:d])` 两行代码完成降维。

**与已有概念的关联**：
- 是 [[向量与Embedding]] 的维度优化变体：代价是同维数下略低于专用维度模型上限，换来存储/带宽/延迟按维度比例自由换挡
- 存储对象仍是 [[向量数据库]]，低维截断可显著降低其内存与索引（如 [[HNSW近似最近邻索引]]）占用
- 实例：腾讯 WeMM-Embedding 支持 64~4096 维截断（2B/4B/9B 各档不同）
