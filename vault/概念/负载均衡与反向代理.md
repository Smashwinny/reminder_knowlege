# 负载均衡与反向代理

**一句话定义**：站在所有服务器前面的"领班"，按策略（轮询/加权/最少连接/IP哈希）把请求分给某台后端机器；反向代理是同一位置的更大概念（替服务器收请求），负载均衡是其最重要的用途。

**属于领域**：分布式系统 / 网络架构

**通俗理解**：奶茶店排队排到马路上，与其把老板娘练成三头六臂（垂直扩展），不如雇一个领班 + 多个店员。领班还兼职"体检"：某台机器挂了就踢出轮换，其余机器自动接手，用户无感——这是高可用的第一块基石。注意方向：反向代理站在服务器这边替服务器出面；正向代理站在用户这边替用户出面，名字像镜子一样对称。
