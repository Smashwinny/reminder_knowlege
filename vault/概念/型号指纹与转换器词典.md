# 型号指纹与转换器词典

**一句话定义**：用设备入网时自报的"型号指纹"（modelID）为 key，查一本社区共建的转换器词典（zigbee-herdsman-converters），把各厂商私有的 Zigbee 报文方言翻译成统一的 JSON 人话——"以指纹查词典"的设备接入模式。

**属于领域**：物联网设备互操作 / 开源社区协作模式

**通俗理解**（比喻/例子，讲完落回术语）：像万国词典：设备自报"我是 lumi.weather"（指纹），词典翻到小米这一页，就知道它会上报温度/湿度/气压/电池，并且知道怎么把"调亮"翻译回小米的私有报文格式。词典查不到的新型号，可以自己写一份"外部转换器"（external converter）补进去，不必等官方发版。实测本地库：4560 条定义、467 个厂商（Aqara 172 / IKEA 100）。

**与已有概念的关联**：

- 类比：[[MCP服务器]]（都是"社区共建适配层"模式：每多一个设备/工具，只需多一条适配定义，主体不动）
