# 无障碍树语义桌面自动化

**一句话定义**：通过 macOS AX、Windows UI Automation 或 Linux AT-SPI 等操作系统无障碍接口读取应用控件的角色、名称、状态与层级，让 Agent 用“哪个按钮、哪个输入框”理解和操作桌面，而不只依赖截图像素与绝对坐标。

**属于领域**：AI Agent / computer use / 可访问性工程。

**通俗理解**（比喻/例子，讲完落回术语）：截图方法像隔着玻璃看仪表盘，只能猜“左上角那块蓝色也许是按钮”；无障碍树像拿到设备面板的名册，写着“按钮：保存”“文本框：文件名”。但名册不等于操作权：能否读到、读到多少、能否写入，仍受系统权限和应用实现限制。“后台运行”也不等于每台机器自动拥有互不影响的虚拟桌面。

**工程边界**：语义树可能缺少自绘控件的信息，部分快照会标 `complete:false`。观察结果还需 [[快照限定Ref与严格重识别]] 固定身份，动作结果还需 [[动作投递语义与安全重试]] 判断能否重试。

**与已有概念的关联**：
- [[GUIAgent与多模态定位]]：前者包含视觉定位；本条强调操作系统提供的结构化语义通道。
- [[Agent循环]]：无障碍观察可成为循环中的 Observation，但工具本身不是模型或决策循环。
- [[MCP协议]]：可把观察/动作能力经 stdio MCP 暴露给不同宿主，协议接入不证明动作成功。
