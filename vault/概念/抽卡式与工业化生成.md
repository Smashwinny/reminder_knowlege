# 抽卡式与工业化生成

**一句话定义**：AI 视频工具的两代范式——**抽卡式**（输入一句话，每帧独立生成，拼运气）vs **工业化**（剧本→角色/场景资产入库→关键帧锁定→镜头生成，BigBanana 称 Script-to-Asset-to-Keyframe："先有演员和片场，再开机"）。

**属于领域**：AI 视频生成 / 工具选型

**通俗理解**（比喻/例子，讲完落回术语）：抽卡式像**盲盒手办**——每抽一个都可能不一样，便宜、快、惊喜感；工业化像**模型厂流水线**——先开模再量产，贵、慢，但每个都长得一样。解说/科普短视频（旁白为主、人物少）用抽卡式够用；连载短剧/网文改编（角色要跨集存活）必须工业化，否则 [[角色一致性锚定]] 问题会直接劝退观众。

- 选型判断与 [[能力层与后端路由]] 同型：先明确需求形态，再挑工具，而不是反过来
