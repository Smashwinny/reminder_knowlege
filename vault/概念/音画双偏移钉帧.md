# 音画双偏移钉帧

**一句话定义**：音效启动帧 = 目标峰值帧 − 音源内部峰值滞后 − 当前渲染管线输出音轨偏移；两项都靠实测，旧常数不能跨管线搬运。

**领域**：AI / 视频 / 声音工程。来源：[[项目笔记/video_shotcraft]]（sound-design §4.6 与本机三音源实验）。

本实验三音源 10ms RMS 峰值滞后为 21.75/16.65/13.65 帧，三探针在 Remotion 4.0.532 管线测得输出偏移约 0。10ms RMS/sample peak 不是 LUFS/true peak，也不自动等于语义落点；更换渲染器、编码器、采样率或容器必须重测。与 [[React逐帧视频渲染]]、[[词锚定语义时间]]、[[事实与判断分离]] 互链。
