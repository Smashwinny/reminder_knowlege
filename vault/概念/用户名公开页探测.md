# 用户名公开页探测

**一句话定义**：把用户名代入各站点公开资料页或探测端点，根据站点特定响应规则生成“命中/未命中/未知”等启发式结果，而不是身份归属证明。

**领域**：OSINT / HTTP 状态推断。来源：[[项目笔记/sherlock_osint]]（v0.16.2 本地桩实验）。

Claimed 不等于同一人；Available 不等于可注册；Unknown/WAF/ILLEGAL 不应被压成“未找到”。HTTP 200、404、429 和“未出现错误文案”都只是规则信号，不是归属证据。与 [[AI味模式库与信号非证据]]、[[可逆派生状态]]、[[健康探测三态]]、[[证据优先质检ProofOverClaims]] 互链。
