# 候选来源草稿三段式

**一句话定义**：选题雷达先给出带理由的候选，再逐条保留来源与信号类型，最后只输出草稿，把事实核查和发布决定留给人。

**属于领域**：AI 内容工作流 / 人工发布门禁。

**操作要领**：候选理由应把时效、目标受众、直接信号、标题脱水初筛和叙事轮换分开；分数只是排序启发式，不证明事实或传播效果。GitHub/HN API 能提供直接平台信号，但 HN 外链仍需回原报道，榜单分数不是事实核验。输出文件必须标为草稿，发布前回源并核对指标释义。

**与已有概念的关联**：
- [[情绪脱水测试]]：可借用五项内审思想，但少量标题词过滤只是初筛，不等同全文事实密度测试。
- [[中继交叉印证]]：直接信号与原报道/官方事实仍须分层。
- [[质量标准死卡与执行手段放开]]：采集手段可自动化，发布门槛不自动下放。
- [[证据优先质检ProofOverClaims]]：候选、评分和真实传播结果分开。
