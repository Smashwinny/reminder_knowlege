# 注意力即优化器

**一句话定义**：SLAM-Former 的后端不做传统全局 BA/位姿图优化的迭代最小二乘，而是把全部 map tokens 喂进同一个 Transformer 做一次全注意力前向（M̄ = f_bn(M)），论文称其全局感受野等价于回环检测 + 位姿图优化——即"用一次前向替代一整套迭代优化器"。

**属于领域**：AI / 优化与 SLAM

**通俗理解**：传统优化像"全班挨个两两对账、改了再对、循环到收敛"（迭代最小二乘）；全注意力像"全班开一次圆桌会，每人同时听到所有人的账，一轮下来账目就顺了"（一次前向、全局感受野）。落回术语：注意力的每一对 token 交互天然构成约束边，softmax 加权平均就是一次联合调和——这正是位姿图优化的图上消息传递的神经网络版。工程节奏：每 bn_every=10 个关键帧跑一次，精化后的 KV 写回前端（cache sharing），前端拿着"干净账本"继续增量跟踪。

**与已有概念的关联**：
- [[漂移与回环闭合]] —— 被替代的对象正是"回环检测+位姿图优化"这套传统收尾
- [[质检Gate与自我纠错循环]] —— 同构的"周期性全局体检"节奏：前端小步快跑，后端定期翻总账
- [[首帧锚定与内存条件坐标系]] —— 后端精化的产物就是那份"记忆"，两者合起来构成 SLAMFormer-∞
