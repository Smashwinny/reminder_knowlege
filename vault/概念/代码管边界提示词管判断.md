# 代码管边界提示词管判断

**一句话定义**：agent 工程总准绳——搞错了无法靠"下次注意"挽回的事（轮数上限、文件权限、付款审批、数据访问）必须写成模型无法谈判的代码；能挽回的质量/路线判断留给提示词。

**属于领域**：AI Agent / 工程准绳

**通俗理解**：给司机配的该是限速器和刹车（机械，求情没用），而不是一张"请勿超速"的字条（可以撕）。提示词是模型读的，模型可以被说服、被注入、被绕——所以**硬限制必须放在提示词够不着的地方**。判断判据一句话：这个错误能不能靠"下次注意"挽回？不能挽回的归代码，能挽回的归提示词。

**与已有概念的关联**：
- [[沙箱与审批正交]] 是落地机制：能不能（sandbox）×该不该（approval）两轴独立
- [[AgentHarness智能体挽具]] 七职责之"停止条件"即"代码管边界"的第一个应用（max_rounds 刹车）
- [[提示词权威边界]] 是它在提示词内部的投影：谁有权改哪段提示词也要写死
- [[HardFailure一票否决与发布门禁]] 是加急版：某些错误连判断都不给，直接熔断
