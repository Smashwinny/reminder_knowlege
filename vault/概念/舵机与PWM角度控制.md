# 舵机与PWM角度控制

**一句话定义**：舵机 = 电机+减速齿轮+角度电位器+驱动板的四合一执行器，用 PWM 脉冲的**高电平宽度**指定目标角度（0.5ms→0°，1.5ms→90°，2.5ms→180°，每 20ms 一帧），内部闭环转到并保持。

**属于领域**：机器人 / 嵌入式硬件

**通俗理解**：普通电机像"踩油门"（给电就转，转多少不管）；舵机像"导航"——你说"去 90°"，它自己看着方向盘转过去并停稳。百元机械手用 SG90（约 ￥2~3/个，扭矩 1.8kg·cm），拉动鱼线手指绰绰有余。

**与已有概念的关联**：
- 协议思想同源：同一套脉宽约定所有厂家都认，与 [[MCP协议]]"标准化接口降 M×N 为 M+N"是同一个道理
- 确定性输入：脉宽↔角度是纯线性映射，类似 [[确定性脚本]] 同输入同输出

**首次接触于**：[[项目笔记/bionic_hand_diy]]

**实测要点**：实验 Step1 验证 1500µs↔90° 往返映射一致（`bionic_hand_sim.py`）；5 个舵机同动峰值电流 2A+，别用 USB 口供电，且外接电源必须与逻辑板共地。
