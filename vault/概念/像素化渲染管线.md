# 像素化渲染管线

**一句话定义**：把 3D 场景先渲染到一张低分辨率渲染目标（如 480×270 的 RenderTarget），再用最近邻采样（NearestFilter，放大不插值）拉伸到全屏——低分辨率供"少细节"，最近邻供"硬边大像素块"，两者缺一不可。

**属于领域**：实时图形学 / 网页 3D 渲染。

**通俗理解**：像素风不是贴图自带的复古滤镜，而是"先在小纸条上画好、再用复印机的'无平滑'模式放大"。只低分辨率不最近邻，GPU 双线性插值会把边缘抹糊；只最近邻不低分辨率，细节太多不像老游戏。第三件帮手是 CSS `image-rendering: pixelated`，让 canvas 被 DOM 拉伸时继续保持硬边。webgl_postprocessing_pixel 官方示例、无数像素风独立游戏（如 Enter the Gungeon）同此管线。
