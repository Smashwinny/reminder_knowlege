# 考情地图与频次证据

**一句话**：把公开面经按公司维度聚合、给每道题标注"被哪些公司问过"的频次证据，让复习优先级从玄学变成可排序的数据问题。

**领域**：学习方法 / 面试备考 / 数据证据。来源：[[项目笔记/ai_engineering_interview_questions]]（598 题 AI 工程面试题库实测）。

结构三要素：
- 公司维度组织（35 家 roles + 面试 loop）
- 单题 Asked at 频次标注（KV 缓存 8 家 = 最高优先）
- 答案深链到可追溯博客形成"题→答→体系"链路

与 [[证据优先质检ProofOverClaims]] 同源：标注来源、区分事实与转述；Ask at 是"被问过"的证据而非"会再考"的承诺。

局限：频次标注覆盖仅 16%（97/598）题目；样本来自公开面经自述，有存活者偏差；题库是动态数字。

反模式：把考情地图当押题脚本；忽略公司间面试 loop 差异（同一公司不同团队差别大）。
