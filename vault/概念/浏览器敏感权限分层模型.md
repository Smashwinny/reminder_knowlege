# 浏览器敏感权限分层模型

**一句话定义**：摄像头、麦克风、定位等 Web 能力依次受安全上下文、Permissions Policy/iframe、浏览器站点权限和操作系统应用权限约束的多层授权模型。

**领域**：Web 安全 / 隐私工程。来源：[[项目笔记/storm_breaker_defense]] 与 MDN getUserMedia、Permissions API、Geolocation API。

点击链接不等于获得敏感权限；已有授权可能不重复提示；`getUserMedia` 成功后应停止轨道；Permissions API 查询不能代替用户撤权。与 [[WebRTC机器人应用]] 的正当用途对照，边界仍需 [[沙箱与审批正交]] 和 [[代码管边界提示词管判断]]。
