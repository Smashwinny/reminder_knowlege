# 提示词逆向工程

**一句话定义**：从社区晒图"图+提示词"中**收集 → 按结构协议拆解 → AI 重写去照搬 → 打标签归档成数据**的四步流水线，把散装经验重造成可检索复用的数据资产。

**属于领域**：AI / 提示工程 / 数据工程

**通俗理解**：像"菜谱考古"——别人做出好菜只留了配料表，你把每一步还原、归位、写成标准菜谱收进菜谱库。逆向的对象不是模型权重，而是**被验证过的提示词写法**：一张图为什么好，答案往往藏在它提示词的某个结构块里（拆解协议见 [[PromptAsCode提示词即代码]]）。

**关键工程做法**（awesome-gpt-image-2 实例）：
- 每条案例带 `sourceUrl` 指回原推（可溯源）；全部 AI 重写保证原创
- 结构化存储（cases.json：id/prompt/category/styles/scenes），数据与展示分离
- **单一事实源**：网站、PDF 文档、Agent Skill 全部由同一份 JSON 生成，改一处三处同步

**与已有概念的关联**：
- 拆解目标协议：[[PromptAsCode提示词即代码]]
- 数据思想同源：[[内容寻址与镜像分层]]（声明式数据由工具生成为产物）——弱关联
- 应用领域：[[RAG检索增强生成]]（归档后的案例库天然可被检索）
