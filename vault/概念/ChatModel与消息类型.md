# ChatModel 与消息类型

**一句话定义**：ChatModel 是"一段消息列表进、一条 AI 回复出"的统一接口，屏蔽各家大模型（OpenAI/Anthropic/Ollama…）的 API 差异；Message 是对话的基本单元，分 System（系统设定）/ Human（用户）/ AI（模型回复）/ Tool（工具执行结果）四种角色。

**属于领域**：LLM 应用开发

**通俗理解**：ChatModel 像**万能转接头**——不管哪家"电器"（模型）插口长什么样，你这边都是同一个插座；换模型 = 换插头，你的电路（代码）一行不改。Message 像**微信群里带身份的聊天气泡**：群公告（System）、成员发言（Human）、AI 发言（AI）、机器人回执（Tool）。关键认知：模型每次看到的不是"最后一句话"，而是**整份聊天记录**——所以工具调用结果才能通过追加 ToolMessage"喂"回模型。

- 相关：[[Agent循环]]（循环的每一圈都在往消息列表追加消息）
