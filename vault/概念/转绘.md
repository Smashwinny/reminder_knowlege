# 转绘

**一句话定义**：拿一张真实照片当"底稿"，让 AI 按指定风格重新演绎它——照片负责"画什么"，风格提示词负责"怎么画"。

**属于领域**：AI 图像生成 / 提示词工程

**通俗理解**：普通文生图是"从一句话开始想象"，转绘是"从一张照片开始翻译"。好的转绘要求**保留与重构的对应关系**：先理解照片里最值得记住的主体、结构、情绪与视觉隐喻，再用风格语言重构，让人一眼认出"这就是刚才那张照片"。例：小小东 xxd-panel-116 把照片上半保留、下半转译成粉彩蜡笔涂鸦；224 用瓷片重构主体；133 转点刻版画。落回术语：转绘 = image-to-image 的风格化重绘（restyle/redraw），照片既是内容来源又是验收参照。

**与已有概念的关联**：
- 是 [[提示词模板]] 的高端实战形态：转绘提示词 = 风格宪法 + 交付变量槽位
- 成品几何可用 [[确定性脚本]] 审计（50:50 缝线检查），不合格走 [[质检Gate与自我纠错循环]]
- 批量转绘 = [[Agent循环]] 驱动 Skill 逐张"读宪法→组装提示词→生图→验收"
