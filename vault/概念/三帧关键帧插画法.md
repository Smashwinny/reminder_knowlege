# 三帧关键帧插画法

**一句话定义**：用每个动作"起势-中程-止点"3 张关键帧静态图 + 前端钟摆式轮播（1→2→3→2→1）表达完整动作，替代视频/GIF。

**属于领域**：前端素材工程 / 动画表现（workout-guide：302 动作 × 3 帧 = 906 张 512×512 SVG）

**通俗理解**（比喻/例子，讲完落回术语）：像武术招式图的"定式三连拍"——起势教摆位、中程教轨迹、止点教收缩；三个定式来回翻就是完整招式。动画术语里这是**关键帧（keyframe）**思想：只画"决定性瞬间"，中间过渡交给观众脑补或 [[补间动画与缓动函数]] 的插值公式。3 帧 SVG 每动作约 7KB，对比视频几十 MB、GIF 数 MB，轻百倍且任意缩放不失真。

**实测要点**：
- 循环顺序用钟摆式 1→2→3→2→1 而非 1→2→3→1，否则止点会"瞬移"回起点，动作语义断裂
- CSS 实现只要 `steps(1)` 三段 opacity 关键帧（见 exercise_gallery.html），悬停播放、离开即停
- 主题适配的坑：线稿是白色描边+透明底，深色 UI 直接用，浅色 UI 必须 CSS invert 或改 fill，否则"隐身"
- 302 动作分 20 主肌群/17 器械/5 种计次类型，元数据与帧一起打包，查询和渲染解耦
