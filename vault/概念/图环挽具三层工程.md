# 图环挽具三层工程

**一句话定义**：把 agent 系统工程拆成三层关注点——**graph engineering**（长流程怎么走：验证门控的步骤转移）、**loop engineering**（失败了怎么爬起来：有界诊断→修复→重试→复验）、**harness engineering**（零信任执行：身份/授权/能力范围/隔离/运行时护栏），完成与否以"机器可查的仓库/部署/运行时证据"门控（arXiv 2609.00050，在 Google Cloud 实例化）。

**属于领域**：AI Agent 系统工程 / 可靠性

**通俗理解**：造一辆自动驾驶车——graph 是高德地图（路线怎么规划、每段路终点要验"真到了"），loop 是爆胎处理规程（靠边、诊断、换胎、复检，且必须有时限），harness 是安全车身（安全带、气囊、权限锁）。三层各自失败模式不同：graph 层怕"假完成"（没验证就宣称到达），loop 层怕无限重试（没有 give-up 路径的修复循环），harness 层怕权限过宽。RRSI 则是第四维：让车自己升级改装的"元循环"。
