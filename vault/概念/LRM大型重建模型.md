# LRM 大型重建模型

**一句话定义**：LRM（Large Reconstruction Model）把 3D 重建从"逐物体迭代优化"改成"Transformer 一次前向翻译"——在海量"图片↔3D"配对上预训练，推理时单张照片几秒直接吐出 3D 场景表示，TripoSR 是其最著名的开源实现（0.5s@A100）。

**属于领域**：三维图形 × AI 生成（图生 3D）

**通俗理解**：传统重建像画家写生，对着一处反复端详（NeRF/3DGS 每个新物体都要重新训练几分钟到几十分钟）；LRM 像熟读十万张脸的画像师，瞥一眼凭经验直接落笔。比喻讲完落回术语："经验"就是预训练权重里的 3D 先验，"一次落笔"就是无迭代的一次前向推理。代价：没看到的面靠先验"想象"，可能想错——所以它本质是"受条件约束的生成"，不是测绘级重建。

**与已有概念的关联**：
- 同门对照：[[点图与前馈重建]]（DUSt3R/Pi3）——同是"前馈替代迭代优化"，但那家是每像素回归 XYZ 点图（场景级、测绘员），LRM 输出 [[Triplane三平面表示]]（物体级、雕塑家）
- 输出可查密度/颜色，末接 marching cubes 萃取网格，GLB 进 [[Three.js与场景图]] 或引擎（[[glTF与GLB资产管线]]）
- 与 [[新视角合成]]/[[高斯泼溅3DGS]] 的区别：那两家输出"照片级画面"，LRM 输出"干净可下载的网格资产"
- 管线骨架：DINO ViT 编码图片 token → 3072 个可学习 token 交叉注意力刷新（16 层）→ 三平面 → NeRF MLP 解码（RTX 4070 实测 2.3s）
