# 政策到纪律翻译

**一句话定义**：把平台政策（例如“无用户价值的大规模生成内容”属垃圾行为）翻译成 Agent 可执行的具体纪律，例如“只换城市名的页不发”“一次一页”，让合规由规则前置而不是靠模型自觉。

**领域**：AI 工具生态 / 合规。来源：[[项目笔记/chatseo_skills]]（pattern-drip 规则与 Google spam policies 对照）。

它是 [[护栏模式Guardrails]] 与 [[Agent指令文件AgentMd]] 的组合：政策文本转成可机检或人工检查的交付规则；频率限制本身不构成质量或合规保证。
