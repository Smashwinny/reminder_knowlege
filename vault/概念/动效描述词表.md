# 动效描述词表

**一句话定义**：动效描述词表是把"我想要什么动效"翻译成 AI 能精确执行的标准词汇——触发（trigger）、动作原语（fade/slide/scale/blur/pop）、缓动性格（ease-out/spring）、时序（duration/stagger）四要素一个不缺。

**属于领域**：前端 / UI 动效 / 提示词工程

**通俗理解**：跟裁缝说"做件好看的衣服"必翻车，说"修身、深蓝、袖口一寸"一次就对。AI 写动效同理：它会的 CSS 动画词汇成百上千，你只会说"高级一点""灵动一点"，它只能拿默认值顶上（0ms 闪现 + linear 机械滑动）——这就是"AI 味动效"的全部来源。词表的意义：**感觉越玄，越需要精确的语言把它钉死**。核心口诀：入场用 ease-out（先给结果再优雅收尾），离场用 ease-in，换位用 ease-in-out，卖萌/跟手用 spring。

**与已有概念的关联**：
- 底层原理：[[补间动画与缓动函数]]——词表描述的每一动，最终都落到补间公式；easeOutCubic 实测 t=0.3 走 0.657 路、easeOutBack 峰值 1.100 过冲，"性格差异"可用数字证明
- 同族方法：[[PromptAsCode提示词即代码]] / [[图像提示八要素]]——把主观意图结构化为可校验的协议槽位，动效版只是换了领域
- 实现落点：[[Three.js与场景图]] / [[粒子系统]]（三维入场动画同样吃这套词汇）
- 验收思想：结构验收（grep 缓动曲线/时长/错峰 delay 序列）是 [[证据优先质检ProofOverClaims]] 的 CSS 版

**实现要点**：
- 万能模板：`【触发】当…【动作】…做（原语）【性格】（缓动）【节奏】时长 Nms + 错峰 Mms`
- 官方血统：描述里直接点名 Material 3 缓动（standard `cubic-bezier(0.4,0,0.2,1)`、emphasized `cubic-bezier(0.2,0,0,1)`），AI 训练数据见过成千上万次，比自己编曲线稳
- 数量级：入场 150~300ms，错峰 20~90ms/个，超 500ms 用户会觉得"卡了"
- spring 与 bezier 的分野：bezier 是"剧本演完"（曲线定死），spring 是"物理在跑"（stiffness/damping/mass，目标变了自己收敛）——拖拽跟手必须 spring
