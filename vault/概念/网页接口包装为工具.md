# 网页接口包装为工具

**一句话**：把无公开 API 的网站网页后端接口，包装成 AI 可调用的标准工具的通用方法论。
**领域**：agent 工具开发。来源：[[12306_mcp]] 项目（也可参照 WeChatBridge 等）。

四件套：
1. 动态路径探测——目标站接口路径会变，启动时先请求 init 页探测现行路径；
2. Cookie/会话预处理——先取会话凭证再调查询接口；
3. 输入翻译——LLM 说"北京"，内部查索引表转站点代码；
4. 输出翻译——把密麻字段格式化成自然语言结论（余票/价格/时刻）。

**关联**：[[MCP模型上下文协议]]（承载协议）、[[证据优先质检ProofOverClaims]]
（包装≠背书，网页数据时效与稳定性有限）。
