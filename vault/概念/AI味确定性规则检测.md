# AI味确定性规则检测

**一句话定义**：把 AI 生成 UI 的套路编译成免 LLM 的确定性规则（字体、色相范围、对比度公式、结构模式），输出命中清单与修复指令，exit 非零即 fail-closed。

**领域**：AI 原生开发 / 设计系统。来源：[[项目笔记/ui_design_resources]]（impeccable 62 规则源码核实 + 自写检测器 6/6 命中）。

与 [[AI味模式库与信号非证据]] 的 UI 孪生、[[设计令牌DesignToken]] 和 [[证据优先质检ProofOverClaims]] 互链。命中是审美风险信号，不是作品质量或作者身份的证明。
