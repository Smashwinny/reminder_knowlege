# 修改与约束分离

**一句话定义**：图像编辑提示词的官方纪律——把"改什么"（只/仅+唯一改动）、"什么不能动"（逐项点名保留清单）、"不要长出什么"（负向排除）写成三个独立段落，多轮修改时一次只改一个变量并重申约束。

**属于领域**：AI / 提示工程（图像编辑方向），官方指南第 6+8 条原则的组合

**通俗理解**：口语编辑"把椅子改一下"像对装修工说"这儿弄一下"——他顺手把你家地板也换了。模型**每轮编辑都是重新画一遍**，不列禁区它不知道什么不许动。ex3 实测：口语编辑 0 分，泛泛说"其他都不变"50 分（翻译官方例），逐项点名"镜头角度、构图、光线、阴影、背景、其他家具不变"75~100 分。

**要点**：
- 三段式模板（可直接抄）：**A 修改段**"只把 X 改成 Y" + **B 保留段**"保持镜头角度/构图/光线/阴影/背景/其他物体完全不变"（≥3 项具体点名） + **C 排除段**"不要添加任何文字/水印/新元素"
- **跑偏的根源是重新绘制**：每轮迭代都有漂移，所以单变量迭代让每次漂移可归因，结果跑偏就重申关键约束
- 像素级必须不动的区域，官方建议**把已批准的局部直接合成回原图**，别指望提示词
- 精修局部编辑还要点名：饱和度、对比度、箭头、镜头角度、周围物体不变
