# 最小验证五步法

**一句话定义**：选择待验证的重复市场场景，做少量可展示样品，写清编辑/交付规格，再观察分层反馈并决定是否继续商品化。

**属于领域**：商业 / 数字产品验证。

**五步**：场景假设 → 1–2 个样品 → 可编辑范围/交付物/时效/轮次/授权 → 曝光/点击/收藏/咨询/成交与退款分层记录 → 按预先声明的阈值复盘。首轮成本还包括调研时间；阈值是自定实验口径，不是行业基准。

**与已有概念的关联**：[[完整单位收益口径]] 扣除平台、工时和退款；[[规格书先行SpecDriven]] 把商品说明变合同；[[质量标准死卡与执行手段放开]] 区分固定模板项和客户字段；[[证据优先质检ProofOverClaims]] 分开点击、成交和盈利。

**验证边界**：[[项目笔记/digital_invitation_case]] 只产出两枚可编辑样品并通过结构/渲染检查，未上架、未获得反馈，原帖销量未核实。
