# 资金操作四步纪律

**一句话定义**：Agent 触达资金时依次明确授权与默认模式、逐项确认写参数、回读真实成交/账单、把撤单/停机等处置交由人决定。

**属于领域**：AI Agent / 金融与支付安全。

**四步**：① config+auth 合并确认账户、站点、API key/OAuth 与 demo/live；② 下单等写操作逐项确认，USDT 区分 quote_ccy/margin，合约先核 ctVal；③ 回执不等于成交，看 fills/positions/账单；④ 需要撤单、停机、平仓等红线处置时呈报，不自动替人决定。

**与已有概念的关联**：[[默认姿态审计]] 是第一步核心；[[技能路由器与授权硬门]] 提供机制授权；[[可逆派生状态]] 区分受理和完成；[[付费调用回执与预算熔断]] 记录真实成本。
