# 智能体框架

**一句话定义**：替开发者管「模型对接、工具注册、消息循环、会话存储」的脚手架库——你只写三件事：用哪个脑（model）、带哪些手（tools）、守什么规矩（instructions）。

**属于领域**：AI / LLM 应用

**通俗理解**：没有框架时,调模型、把工具清单翻译成 JSON Schema、解析"点菜单"、执行回填、循环、存聊天记录……约 200 行样板代码;有了框架(agno 6 行起)。落回术语:**框架夹在「你的几行配置」和「模型 API」之间**。各框架概念互通(见 [[Agent循环]]、[[LLM工具调用]]),换框架只是换语法。

**与已有概念的关联**：
- 实例：agno（awesome-llm-apps 全仓库用）、crewAI（[[多智能体协作]] 默认组队）、LangChain/LangGraph（[[LangGraph与Agent编排]] 流程图派）、Google ADK、OpenAI Agents SDK
- agno 特有：`Team`（组队）、`SqliteDb`（会话/记忆存储）、`AgentOS`（一键起服务）
- 坑：agno 3.x 移除了 `Claude(base_url=...)`，需改 `client_params={"base_url": ...}`（2026-10 实测）
