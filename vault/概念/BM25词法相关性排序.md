# BM25 词法相关性排序

**一句话定义**：结合查询词在文档中的频率、在语料中的稀有程度与文档长度归一化，对文档作词法相关性排序。

**属于领域**：信息检索、搜索系统。

**通俗理解**：查“SaaS dashboard”时，罕见而命中的词更有区分力；同一词重复很多次的收益会饱和；长文档不能仅凭词多无限占优。它衡量所选语料和分词规则下的词法匹配，不是审美评分、质量百分比或可信度概率。

## 固定实现与实测锚点

[[项目笔记/github_tools_increment]] 学习的 UI UX Pro Max 使用 k1=1.5、b=0.75，IDF=ln(1+(N-df+0.5)/(df+0.5))；每个查询词的贡献为 IDF × tf×(k1+1) / (tf+k1×(1-b+b×文档长度/平均长度))，再求和。公式中的 tf 是文档词频，df 是含该词的文档数，N 是语料文档总数。

该实现先小写、按边界替换同义词、移除标点、按空白切分，再过滤短词与停用词。这不是 [[BPE分词器]]；能保留中文字符不等于实现中文分词或跨语言理解。查询中的重复词会按实际 token 列表重复贡献；分词、参与搜索的列和语料改变后，旧分数不能直接比较。

已有实验针对固定 products.csv 的 192 行、查询“SaaS dashboard”，用相同分词契约独立计数并重算公式；全部分数和排序一致，最大绝对差 0.0。前三项为 SaaS (General)、Micro SaaS、Analytics Dashboard。这是公式一致性证据，未提供独立人工相关性标注或真实 UI 质量基准。

BM25 只是整个搜索入口中的排序部件：域选择、身份匹配、阈值、建议词与回退另有分支，不能将最终搜索结果全归因于公式。
