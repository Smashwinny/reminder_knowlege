# Agent 循环

**一句话定义**：Agent = 模型 + 工具 + 自动循环：模型节点每次读完整消息列表，要么给最终回答（循环结束），要么发出工具调用；工具节点执行后把结果回填，再问模型——直到任务完成。

**属于领域**：LLM 应用 / Agent 工程

**通俗理解**：像一个**自己会查资料的实习生**——你交代任务（HumanMessage），他先想（模型），发现要查数据就动手查（工具），查到结果再看一眼决定继续查还是交差（再问模型），反复直到给出答案。LangChain 实测中一次"计算 128+64"的 invoke 产生 4 条消息：Human → AI(请求调工具) → Tool(结果) → AI(最终回答)。**错误也走同一条路**：参数校验失败会被包成 ToolMessage 文字回流，模型读到后下一轮自动改参数重试（自我纠错）。
