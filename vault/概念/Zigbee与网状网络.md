# Zigbee与网状网络

**一句话定义**：Zigbee 是为低功耗、小数据量、海量节点设计的 2.4GHz 无线协议，组网呈网状（Mesh）——市电设备兼任路由器帮邻居转发消息，电池设备只做"终端"省电睡觉。

**属于领域**：物联网无线通信 / 智能家居底层网络

**通俗理解**（比喻/例子，讲完落回术语）：像小区内部步道网：走路送信（省电）、每家帮邻居接力传话（Mesh 路由），不像 Wi-Fi 那样人人开车上高速。三种角色：协调器 Coordinator（建网老大，唯一，需要实体射频芯片）、路由器 Router（市电供电的灯/插座，顺便中继）、终端 End Device（电池传感器，只和父节点单线联系，常睡常醒）。

**与已有概念的关联**：
- 相关：[[MQTT协议与发布订阅]]（Zigbee 管"设备怎么连网"，MQTT 管"数据怎么进应用"）
- 对比：Wi-Fi（大数据量高功耗）/ 蓝牙（点对点为主）

**坑**：与 Wi-Fi 共用 2.4GHz，干扰严重；经验是 Zigbee 选 15/20/25 信道，远离 Wi-Fi 的 1/6/11。
