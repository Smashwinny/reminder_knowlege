# 浏览器权限状态机

**一句话定义**：敏感 Web API 通常按 prompt→granted/denied 状态流转，默认 prompt；拒绝后走 error 回调拿不到数据，并要求安全上下文。

**领域**：安全 / Web 平台。来源：[[项目笔记/browser_security_tools]]（headless Edge 实测 prompt 与 PERMISSION_DENIED code=1）。

HTTPS/localhost 是常见安全上下文，Edge 的 file:// 也可满足；安全上下文只决定能否请求，不代表用户已授权。它是 [[采集分级防御法]] 的权限层，也与 [[护栏模式Guardrails]] 的平台级约束互链。
