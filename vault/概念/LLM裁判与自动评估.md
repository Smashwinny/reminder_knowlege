# LLM 裁判与自动评估

**一句话定义**：写一份评分细则（rubric）喂给强模型，让它按细则给被测 Agent 的输出逐项打分——不知疲倦的外部裁判，《Agentic Design Patterns》模式 19。

**属于领域**：AI Agent 评估 / 质量工程

**通俗理解**：体操比赛的打分表（rubric）+ 裁判（LLM）。书中实例是法律综述质量 rubric：论据可溯源、结构完整、术语准确，逐项给分。配套正确性/相关性基础评估脚本一起构成评估套件。

**可信度三定律**：
1. **细则质量 > 裁判模型强度**——rubric 模糊，再强的裁判也打糊涂分；
2. **裁判不能只评自家**——同家族模型自评有偏，跨家族交叉更公允；
3. **人抽检不可省**——定期人工比对防裁判漂移（[[证据优先质检ProofOverClaims]] 精神：最终看实机证据）。
