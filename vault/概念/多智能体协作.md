# 多智能体协作

**一句话定义**：把一个复杂任务拆给多个各有角色、各自带工具的 AI 智能体，让它们分工、传话、互相校验，共同完成任务。

**属于领域**：AI / 智能体编排（LLM 应用架构）

**通俗理解**：小组作业——有人定计划、有人动手、有人检查。为什么要拆？单个大模型塞进所有角色时上下文过载、角色混乱，"一错到底"；拆开后每个 Agent 的上下文里只有一个角色，专注且能互查（crewAI 实验里 GLM 自己总结的就是这两条）。代表框架：crewAI（[[Agent循环]] 驱动的 Crew）、LangGraph。

**与已有概念的关联**：
- 相关：[[构建流水线与Pass]]（sequential 模式就是流水线思想：每级只加工上一级的中间产物）
- 相关：[[质检Gate与自我纠错循环]]（agent 互查 ≈ 软性质检 Gate；hierarchical 模式的经理 Agent 就是验收员）
- 对照：[[确定性脚本]]（Agent 是概率性的，生产系统需用确定性骨架包住它）
- 每个成员的内核：[[Agent循环]]；成员的技能：[[LLM工具调用]]；成员的人设：[[角色提示]]；成员的资料：[[RAG检索增强生成]]
