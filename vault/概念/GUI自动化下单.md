# GUI自动化下单

**一句话定义**：不开正式 API，而是用程序遥控券商的 Windows 桌面客户端（读写控件、模拟点击）来查询持仓和下单——easytrader 是 A 股个人量化里这条路线的代表库。

**属于领域**：交易执行 / 桌面自动化

**通俗理解**：正规下单 API 像给餐厅后厨直通电话；GUI 自动化像雇了个人坐在电脑前替你点鼠标——能干活，但餐厅换个菜单布局（客户端升级、控件改版）他就傻眼了。A股散户长期没有官方下单 API，才逼出这条土路线；它有三条同门：easytrader（GUI 遥控）、ptrade/QMT（券商量化柜台，官方沙箱，需资金门槛）、富途 OpenAPI（真 API，港美股为主）。

**与已有概念的关联**：
- 相关：[[个人量化工具箱范式]]（GUI 下单是"先跑起来"哲学在执行层的体现：能用就行，不考虑长期工程性）
- 相关：[[健康探测三态]]（依赖外部 GUI 的管道必须做 missing/broken 探测——客户端升级即 broken）
- 对照：[[事件驱动回测]] 里 NautilusTrader 的 InteractiveBrokers/Binance 适配器——机构用协议级 API，个人用界面级遥控
