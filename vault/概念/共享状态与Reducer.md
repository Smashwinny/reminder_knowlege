# 共享状态与 Reducer

**一句话定义**：LangGraph 里全图共用的一块"白板"（State，一个 TypedDict）；节点收到全量快照、只写回自己的增量，而 Reducer（归约器）是声明在某字段上的"并发写入合并规则"。

**属于领域**：AI Agent 编排 / 并发数据合并

**通俗理解**：像一间会议室的唯一一块白板——每人上台只擦写自己负责的格子（进全量、出增量）。但当两条并行分支同时往"留言区"格子写字时，"后写覆盖先写"会丢内容；给格子贴一条规则"后来的一律接着往下写"（`Annotated[list, operator.add]`），冲突就变成了合并。多智能体共享对话历史全靠它。

**关键协议**：节点输入 = 整块白板快照；节点输出 = 部分增量 dict。因此节点互相解耦，增删节点不改他人代码。
