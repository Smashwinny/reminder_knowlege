# 质检 Gate 与自我纠错循环

**一句话定义**：在自动化流程的关键节点插入客观的检查关卡（Gate），不合格就打回重做（带着失败原因重试），形成"生成 → 检查 → 修改"的循环，让 AI/程序自己纠错而不需要人盯。

**属于领域**：AI 编程协作 / 质量工程

**通俗理解**：像"写作文 → 对照评分标准自检 → 修改 → 再自检"的循环。关键在于**标准必须客观可执行**（img2threejs 用 `grimoire\` 目录里的评分文档 + 可运行的校验命令，如 `validate --strict-quality` 会直接拦下"空壳规格书"）。对 AI 编程助手尤其重要：AI 一次写对的概率不高，但"给它打分器让它自己改"就能收敛到合格。

**与已有概念的关联**：
- 相关：[[构建流水线与Pass]]（Gate 就是插在 Pass 之间的检查站）
- 相关：[[确定性脚本]]（打分器必须确定、可复现，否则纠错没有基准）
