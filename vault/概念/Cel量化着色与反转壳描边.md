# Cel量化着色与反转壳描边

**一句话定义**：日式 RPG/卡通渲染的两个基石——Cel shading 把连续光照量化成 2~3 档明暗（无中间过渡），反转壳描边把模型放大几百分点、改成只画背面、涂纯黑，露出的背面边缘就是一圈轮廓线。

**属于领域**：实时风格化渲染（NPR 非真实感渲染）。

**通俗理解**：真实光照像调光旋钮连续变暗；cel shading 像三档位的电风扇开关——要么亮、要么中、要么暗，跳变才是"动画感"。描边则像给每个物体套一层稍大的黑色气球皮：正面被物体自己挡住，只有轮廓边缘露出一圈黑。Three.js 现成零件：`MeshToonMaterial` + 3 像素宽梯度图（如 90/170/255）= 三档 cel；`BackSide` 材质 + `scale ×1.05` = 反转壳。**坑：Toon 材质受光照驱动，场景忘加灯就是一坨纯黑。**
