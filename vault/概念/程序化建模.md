# 程序化建模

**一句话定义**：用代码（程序）来描述和生成三维模型，而不是用建模软件手工雕刻、也不是加载现成的模型文件。

**属于领域**：三维图形 / 计算机图形学

**通俗理解**：传统建模像"捏泥人"——用手（鼠标）一点点捏出形状，存成一个文件（.obj/.glb）；程序化建模像"写菜谱"——把"杯身是圆柱、把手是圆环的一段"写成配方，任何时刻执行配方都能重新"做"出这个杯子。菜谱的好处：改一个参数（杯口半径）整只杯子自动跟着变；菜谱本身就是模型，不依赖外部文件。

**与已有概念的关联**：
- 相关：[[Three.js与场景图]]（程序化建模的代码通常调用 Three.js 的 API 来创建几何体和场景）
- 对比：网格文件（.obj/.glb）是"泥人成品"，程序化建模是"菜谱"
