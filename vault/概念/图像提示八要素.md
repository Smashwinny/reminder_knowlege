# 图像提示八要素

**一句话定义**：OpenAI GPT Image 2.5 官方指南给出的 8 条图像提示词基本原则——明确最终目标、易维护格式、可见细节、人物动作、准确文本、修改与约束分开、参考图分配角色、谨慎迭代——是"好提示词"的官方验收标准。

**属于领域**：AI / 提示工程（图像生成方向）

**通俗理解**：抽卡式提示词（"画一个好看的咖啡店"）是把命运交给骰子；八要素是把需求写成**工程单**——用途定验收标准、主体定画谁、构图/风格/光线/材质定怎么画、文字逐字锁、负面兜底。实测（ex1 体检器）：抽卡式 40 分，官方风格样例 100 分。

**要点**：
- 前两条是总纲：**先说最终用途再说画面细节**；格式（段落/标签章节/JSON）殊途同归，选好维护的，没有特殊语法
- ③~⑤ 管"画什么"：可见细节要点名材质/光线/色彩（要照片级就明说）；人物写景别与动作；文字用**引号逐字锁定+位置字体+负向排除**三件套
- ⑥~⑧ 管"怎么改"：见 [[修改与约束分离]]；多图输入给每张图编号定角色；多轮迭代一次只改一个变量并重申约束
- 复杂需求用带标签章节组织：**场景 / 主体 / 细节 / 限制条件** 四段式
