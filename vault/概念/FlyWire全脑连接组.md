# FlyWire全脑连接组

**一句话定义**：连接组是一个大脑里所有神经元之间的全部连接关系（"完整电路图"）；FlyWire 是普林斯顿牵头、2024 年发布的成年黑腹果蝇全脑连接组公开数据集（v783：138,639 个神经元，配套细胞类型标注，CC BY 4.0）。

**属于领域**：连接组学 / 神经科学基础数据设施。

**通俗理解**：如果把大脑当成一栋楼，连接组不是"照片"，而是**每根电线从哪个插座接到哪个插座、线径多粗**的完整竣工图纸。FlyWire 就是果蝇大脑的这份竣工图——电镜切上万张纳米切片逐张描出来的。拿到图纸后，"通电"（LIF 仿真）灯就亮（行为涌现），不需要重新学怎么接线。注意口径：54M 突触是切片级原始计数，数据表里 15M 条是按"神经元对+神经递质"聚合后的连接条目——同一个大脑，两种数法。

**与已有概念的关联**：
- 通电跑起来的方式见 [[LIF全脑仿真]]；"接线对了功能就涌现、不用训练"见 [[布线特异性与零训练涌现]]
- 与 [[Sim2Real与MuJoCo仿真]] 对照：那边是"先仿真后真机"，这边是"先解剖后仿真"——都是用仿真环境代替昂贵/不可能的真实实验
