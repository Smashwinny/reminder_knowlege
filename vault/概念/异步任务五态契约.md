# 异步任务五态契约

**一句话定义**：长耗时生成服务的标准接口形态——创建即返回 task_id，状态机 queued/running/succeeded/failed/cancelled 轮询或 webhook 推进；客户端必须区分“受理”与“完成”，终态才取货并对账。

**领域**：AI / 视频生成。来源：[[项目笔记/pixstag_api]]（官方文档与本地三轮状态机实测）。

与 [[可逆派生状态]] 的 pending 铁证、[[任务票据与状态外置]] 和 [[快照契约与不可变只读]] 的写侧版本互链。提交成功不等于生成成功；查询、回调与最终用量都需单独核验。
