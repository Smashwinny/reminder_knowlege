# RoPE旋转位置编码

**一句话定义**：把"位置序号"变成"旋转角度"，对注意力中的 Q/K 向量逐维分组做旋转——位置越靠后转得越多，使两个 token 的点积自然携带它们的相对距离信息，是目前主流 LLM（Llama/Qwen/MiniMind）的位置编码标准方案。

**属于领域**：AI / 大语言模型（Transformer 位置编码方案）

**通俗理解**：把每个位置想成钟面上的一个角度。第 m 个词和第 n 个词的角度差永远是 |m-n| 个单位，不管从哪开始数——所以模型从点积里读到的天然是"相隔多远"而不是"在哪一格"。这比直接告诉模型绝对位置更利于泛化。

**关键事实**（MiniMind 源码实测）：
- head_dim 维向量两两分组（如 96 维 → 48 对），每对按不同频率旋转；低频对管远距离、高频对管近距离
- 公式本质：`f'(i) = f(i)·((1-γ)+γ/s)` 的频率缩放族，YaRN 长文本外推（32768）就靠按比例缩放频率实现，MiniMind 内置 `inference_rope_scaling`
- 与"加性位置向量"（原始 Transformer sinusoidal、可学习 absolute）不同：RoPE 只作用在 Q/K 上，是乘法操作，不进残差主干
- 代码极简洁：预计算 `cos/sin` 表 → `q·cos + rotate_half(q)·sin`
