# 推理反思架构族

**一句话定义**：不让 LLM 一次出稿就算完，而是用"生成→评审→改写"的循环（或事后验证）把输出质量顶上去的一类 Agent 架构。

**属于领域**：AI / LLM 应用（Agent 架构）

**通俗理解**：像写论文请导师审——初稿（generate）→ 导师按 rubric 打分写评语（critique，LLMJudge）→ 带着评语重写（refine）→ 分数达标或到最大迭代数就停。Reflection 改"这一份稿"；Reflexion 更进一步，把失败教训写成文字存进情景记忆，下个任务还能检索到——改"人"不改"稿"。CoVe（Chain-of-Verification）是验证链：先答→就出过的具体断言出验证题→独立重答→只保留验证过的内容，专治幻觉；Constitutional AI 用一条"宪法"逐条 pass/fail 判，全过才算合格。

**与已有概念的关联**：
- 上位总纲：[[AI智能体Agent]]、[[Agent循环]]（Reflection/Reflexion 都是"错误回流即自纠"的结构化）
- 同思路：[[质检Gate与自我纠错循环]]（PEV/Reflection 是其 LLM 版）、[[本能学习与置信度评分]]（Reflexion 的教训沉淀）
- 打分实现：[[确定性选择器模式]]（评分由分项布尔/枚举合成，避免"永远 7-8 分"）
- 对照组：[[采样搜索架构族]]（一个改多次，一个试多次）
