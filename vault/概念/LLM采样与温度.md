# LLM采样与温度

**一句话定义**：模型每步输出的是"下一个 token 的概率表"，采样参数决定怎么从表里挑：temperature 控制挑第一名还是掷骰子，seed 固定骰子序列。

**属于领域**：AI / 大模型

**通俗理解**：温度是"保守/发疯旋钮"——温度 0 = 永远选概率第一名的字（稳定复读机），温度 1.5 = 概率差距被拉平（冷门词也有机会，文案更活但易跑偏）。实测：温度 0 + 固定 seed 写广告词连跑 3 次一字不差。落回术语：temperature 是对概率分布做 softmax 前的缩放系数，T→0 趋近贪心解码。

**重要坑**：GPU 上温度 0 **不是数学意义的绝对确定**——并行浮点求和的顺序误差偶尔让两个候选打平、输出分岔（本次学习实测到一次：结尾标点 ！→。）。要稳定：低温 + 固定 seed + 同一硬件。

**与已有概念的关联**：
- 给天生随机的 LLM 上锁复现：[[确定性脚本]] 在 AI 时代的延伸
- 思考模式（thinking）用"打草稿"换取质量：与采样是正交的两个旋钮
