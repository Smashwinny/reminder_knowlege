# AI交易终端

**一句话定义**：把「行情馈送 + 交易所接口 + AI 大脑（Claude）+ 风控引擎 + 21 个聊天平台入口」打包成本地运行的**操作台**，用自然语言对话驱动交易——量化世界的第三种形态（区别于机构框架派与个人工具箱派）。

**属于领域**：AI Agent / 金融工程

**通俗理解**：NautilusTrader 是赛车引擎厂（[[事件驱动回测]]），stock 工具箱是老师傅的修车工具墙（[[个人量化工具箱范式]]），AI 交易终端是**会聊天的自动驾驶套件**——车还是那台车（交易所），方向盘换成了 AI。代表项目 CloddsBot（2888 星，"Claude+Odds"，121 个技能包，10 预测市场+7 永续所）。

**九步数据流中的 AI/确定性分界**（核心架构决策）：收消息→鉴权限流→路由 Agent→载入记忆→**AI 选工具→沙箱执行**（AI 只到这）→比价滑点→**10 道风控→签名下单**（纯确定性代码）。哪怕 AI 被提示注入说胡话，风控和签名层照样拦得住——架构层防注入。

**生态信号**：技能扩展用的就是 [[AgentSkills技能包]] 同款 SKILL.md 格式（自述兼容 OpenClaw 格式）；topics 里的 x402 协议（复活的 HTTP 402）指向"Agent 间互相付费的机器收银台"——[[MCP协议]] 管握手，x402 想管收银。

**推广鉴伪**：此类项目常见"开源+meme 币+返佣"三件套（README 挂币的合约地址、推文带交易所返佣链接、星数月内 3 倍暴涨）；代码真实性（测试绿、commit 活跃）与盈利叙事（"睡一觉赚 280 刀"）是两个独立命题，必须分开验证。
