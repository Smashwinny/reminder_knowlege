# 原子笔记与双链

**一句话定义**：一页只讲一个概念（原子性），页与页用 `[[双链]]` 互连（每条链接双向可见于反链面板），每个论断标注来源——百年卡片盒方法论，成为 LLM-Wiki 知识层的"语言"。

**属于领域**：知识管理（Zettelkasten = 德语"卡片盒"，社会学家卢曼用它写了 70+ 本书）

**通俗理解**（比喻/例子，讲完落回术语）：乐高积木——一块积木（原子页）能拼进无数作品（被多主题复用），一坨浑然一体的大泥团（一页塞五概念）哪都拼不上。落回术语：原子性让页面可被精确链接、单独更新；`[[双链]]` 是 Obsidian 原生语法，链接目标=文件名（不含 .md），反链面板免费得到知识图谱；YAML frontmatter（title/type/sources/related/created）是结构化元数据，让检索排序和 Dataview 动态表格有据可依。

**与已有概念的关联**：
- 是 [[第二大脑LLMWiki]] 中 wiki 层的三条硬规则（原子性/双链/来源标注）
- graph view 展示的连接结构 = 知识图谱；孤儿页（零入链）由 Lint 检出
- F:\reminder 的 vault\概念\ 每条笔记 + `[[双链]]` + 00-总览 MOC 本身就遵循此法
