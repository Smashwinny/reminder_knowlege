# 混音响度验收

**一句话定义**：人声与 BGM 的响度差用 RMS dBFS 客观测量，人声领先 6~10dB 为清晰区；<4dB 浑浊、>15dB 配乐失存——音频验收机检化。

**领域**：AI / 音视频。来源：[[项目笔记/elevenlabs_music_voice]]（合成样本实测 -22.0/-26.1 dBFS，三档混音）。

与 [[证据优先质检ProofOverClaims]] 和 [[规格书先行SpecDriven]] 互链：分贝差当合同。响度只是客观门槛之一，音色相似度和听感仍需人工试听。
