# 多模态嵌入模型

**一句话定义**：能把文字、图片、视频、文档截图等不同模态的内容编码进**同一个向量空间**的 embedding 模型，使跨模态语义检索（一句话搜一张图）成为可能。

**属于领域**：AI / 信息检索 / 多模态

**通俗理解**：单模态 embedding 只会给一种材料发坐标；多模态模型是联合国同声传译厅——不管你说中文、英文还是放一段视频，出来的都是同一套"语义坐标"，坐标近就是意思近。比喻落回术语：同空间的关键是模态对齐训练（[[对比学习]]），且现代方案用**单塔生成式 VLM 改造**——把完整多模态大模型（如 Qwen3.5）拿来，输入末尾加 `<embedding>` 占位符，取该位置最后一层隐状态做 L2 归一化即得向量，不再需要 CLIP 时代的双塔结构。

**两代路线对比**：
- CLIP 时代（2021）：图文双塔各自编码，轻量但只支持图+文、偏粗检索
- 单塔 VLM 时代（VLM2Vec/GME/Qwen3-VL-Embedding/WeMM）：所有模态在同一 transformer 里交错注意力，支持文/图/视频/文档/交错输入，表达力强但重，靠蒸馏、[[混合线性注意力]]、[[Matryoshka套娃嵌入]]压成本

**与已有概念的关联**：
- 是 [[向量与Embedding]] 的多模态扩展；度量仍用 [[余弦相似度]]，存储仍进 [[向量数据库]]
- 让 [[RAG检索增强生成]] 从"只搜文字"扩展到"搜截图/搜图表"
- 抽取机制：`<embedding>` token 位置的隐状态（参见 [[项目笔记/wemm_embedding]]）
