# 声明式视频源语言

**一句话定义**：把视频从"剪辑软件里的工程文件"变成"纯文本源码"——用 XML 方言（Hypit 的 SVML）声明能力包导入、台词脚本、生成节点与组件装配，由编译运行系统渲染成片；**写源码的是 AI Agent，人只提创作要求**。

**属于领域**：AI 工具生态 / 声明式创作

**通俗理解**（比喻/例子，讲完落回术语）：网页不是 Photoshop 画出来的，是 HTML 写出来、浏览器渲染出来的。SVML 之于视频 ≈ HTML 之于网页：`<import from="@hypit/ranking@1"/>` 像引 CDN 组件库，`<script>` 里的台词带 `@{事件}` 锚点像 DOM 事件绑定，`hypit.runtime.json` 选渲染后端像选浏览器。仓库本体是约 120 个 pnpm 包的 monorepo（生成模型包 gpt-image/seedance、本地包 whisperx/render-local、组件包 ranking/chat…），SVML 文件按需 import。

**Hypit 的完整闭环**（v0.2.17 实测）：
- **分发**：`npx skills add hypit-ai/hypit -g` 装成 Agent Skill（导演知识+工具入口），配合 `hypit` CLI（check/measure/plan/build）
- **执行**：Source(.svml) → Run(.svrun 选目标) → Runtime Profile(选服务) → Build(一次执行) → Result(成片+证据)
- **花钱纪律**：`hypit plan` 先报价、用户同意预算才生成——免费层（代码渲染+本地对齐）可先验证创意，生成约 $1/条 20s 口播
- **许可**：修改版 Apache-2.0——产出归用户，禁多租户 SaaS/商用转售/去 LOGO

**与已有概念的关联**：
- 与 [[分镜表驱动生成]] 同构：都是"结构化文本中间表示 → 确定性代码消费"；SVML 更进一步把**人机分工**写死——Agent 当作者，编译器兜底
- 与 [[JSON-IR类型化中间表示]] 同族：类型化中间表示让生成结果可校验、可 diff、可 git 管理
