# 三视角喂料

**一句话定义**：让 AI 做分析规划前同时喂三个信息源——**代码**（这套系统理论上应该怎么运行）、**生产数据**（实际上是怎么运行的）、**PR/决策历史**（它为什么一路变成今天这样）——三者分别回答"设计意图、真实实况、演化理由"，缺任何一路方案都可能是纸上谈兵或重蹈覆辙。

**属于领域**：AI 工程 / 规划方法论。

**通俗理解**：让医生看病不能只看体检表（代码/理论），还要看病人最近的生活记录（生产数据/实际），以及既往病历（历史决策/为什么当年这么治）。例子：想"降低 API 成本"，只看代码 AI 说"加缓存"（理论正确）；看到生产数据发现 90% 成本来自 Ultra 规划调用，方案变成"把规划挪走"（实际有效）；再看 PR 历史发现缓存上过又被撤（stale 数据出过事故），就不会再提同样的馊主意。

- [[证据优先质检ProofOverClaims]]：同族"看实际不看宣称"精神，一个管验收、一个管规划输入
