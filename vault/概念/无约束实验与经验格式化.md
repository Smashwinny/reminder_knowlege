# 无约束实验与经验格式化

**一句话定义**：换了更强的模型后，定期剥掉旧流程的全部步骤预设、只给成片交付标准让它自由解题一次——因为旧 Skill 固化的操作范式，往往就是新模型发挥潜力的天花板（"模型本有能力交付 90 分，却被旧规矩按在 60 分"）。

**属于领域**：AI/工作流方法论

**通俗理解**（比喻/例子，讲完落回术语）：像老司机换新车还沿用化油器时代的踩法——动作经验反而压住了新车的性能。落回工程：作者依赖 Pexels 空镜铺底轨的旧 Skill，是早期模型能力不足的妥协方案，被写死进 Skill 后，新模型（画面贴合度大幅更强）仍在机械执行旧指令；一次"不给 Skill、只给交付标准"的无约束实验，模型自己检索编排的画面贴合度远超旧流程。升级三原则：①定期无约束实验（熟悉题目+只给标准）②留结果不留死板路径（出处/声画同步是死指标，中间手段开放）③别只打补丁（越补越臃肿，敢格式化）。
