# 机器人数字展台

**一句话定义**：把机器人产品官网做成"实时 3D 解剖台"——官网上的机器人不是视频，而是官方模型 + 官方步态数据在浏览器里实时驱动的可交互数字分身，能旋转、行走、分层解剖、爆炸拆解、拖拽肢体的方法论总称。

**属于领域**：Web 3D / 产品展示方法论。范本：Hugging Face 的 Microduck Anatomy（`mishig/microduck-anatomy`，源码公开）。

**通俗理解**：传统官网像"产品写真集"，数字展台像" 把真机搬进展柜还附送螺丝刀"。五层配方，全部数据化：
1. **资产层**：官方 GLB 当零件库（[[glTF与GLB资产管线]]）
2. **骨架层**：kinematics.json/MJCF 关节树装进场景图（[[Three.js与场景图]]、[[前向运动学FK与四元数链]]）
3. **动作层**：RL 策略 50Hz 步态帧按相位插值灌关节——用户看到的走路和真机同一份数据（[[Sim2Real与MuJoCo仿真]]）
4. **交互层**：OrbitControls 必选 + 拖拽 IK 进阶（[[逆运动学IK与CCD迭代]]）；爆炸图 = 每零件一个方向向量 `position = base + vector×t` 指数平滑
5. **分镜层**：聚焦舞台数据表（目标点/机位/缩放/爆炸量），改数据就是改分镜

**点睛细节**：分层解剖 = 按零件名分类（xl330→舵机、lens→传感）+ 透明度权重表；蓝图画风 = 30 行 GLSL（rim 边缘光 + sin 排线 + 颗粒）；零件信息卡带 **confidence 字段**诚实区分"官方确认/功能确认/原型推测"——呼应[[证据优先质检ProofOverClaims]]、[[事实与判断分离]]。
