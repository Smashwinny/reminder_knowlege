# LiveCoding现场编程

**一句话定义**：在观众面前实时编写并修改代码来生成音乐/视觉的表演艺术——代码改一行，作品当场变，过程不打断。

**属于领域**：音乐技术、生成艺术、编程文化（2011 年起的 algorave 派对场景）。

**通俗理解**：传统演奏家练琴十年，live coding 演奏家的"乐器"就是代码编辑器——像 DJ 打碟一样打字，大屏投影观众全程围观。关键是"热替换"：鼓点正在响，你把 pattern 字符串改一个字符，下一循环就变了，音乐从不停机。讲完比喻落回术语：底层支撑是"pattern 是时间的函数"（见 [[Pattern时间函数与Hap事件]]），引擎按循环查询事件，改代码只影响后续查询。

**与已有概念的关联**：
- 与 [[质检Gate与自我纠错循环]] 相通：AI 可"生成 pattern → 查询事件 → 自查节奏密度 → 修改"循环作曲
- 与 [[确定性脚本]] 同理：同样的 pattern 代码永远产出同样的事件时间表，可测试可复现
