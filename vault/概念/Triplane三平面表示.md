# Triplane 三平面表示

**一句话定义**：把 3D 物体的信息压扁存进三张互相垂直的 2D 特征图（XY/YZ/XZ 各一张），空间任意一点的特征 = 该点向三平面各投影一次、三个向量拼接；是 LRM 家族让"Transformer 直接生成 3D"的标准表示。

**属于领域**：三维图形 / 3D 场景表示

**通俗理解**：像用"身份证号、户口本、学籍档案"三份材料共同描述一个人——单独一份信息不全，三份一对就是完整的你。落回术语：三平面是**隐式场的混合表示**，比 NeRF 纯 MLP 查询快（3 次查表+拼接 vs 跑深网络），比体素网格省内存（3 张 64×64×40 而非 64³）。

**为什么 LRM 选它**：Transformer 天然输出"一组 token"，三平面恰好就是"三张由 token 摆成的图"——3072 个 token 重排成 3×32×32，转置卷积 stride2 上采样成 3×64×64，后面接小 MLP（TripoSR：9 层×64）即可查询任意点密度/颜色，毫不别扭。

**与已有概念的关联**：
- 上游：[[LRM大型重建模型]]（Transformer 前向直接生成三平面）
- 下游：marching cubes 从密度场萃网格、顶点再查一次得顶点色（TripoSR 实测 84,156 面/水密）
- 对照：[[高斯泼溅3DGS]]（显式椭球，渲染快但不便转网格）、NeRF 纯 MLP（查询慢）、[[点图与前馈重建]]（点图表示）
