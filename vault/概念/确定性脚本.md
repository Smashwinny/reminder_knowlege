# 确定性脚本

**一句话定义**：同样的输入永远得到同样输出的脚本——没有随机数、没有隐藏状态、没有"看心情"。

**属于领域**：软件工程 / 测试

**通俗理解**：确定性脚本像计算器：按 1+1 永远得 2。非确定性像掷骰子。img2threejs 的 `forge\` 目录约 90 个 Python 脚本全部是确定性、零依赖的，这是它能当"质检裁判"的前提——**裁判自己如果每次判罚不一样，选手就没法纠错**。也让调试变得可能：失败可以精确复现。
