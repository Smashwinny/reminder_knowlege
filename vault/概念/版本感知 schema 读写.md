# 版本感知 schema 读写

**一句话定义**：读写第三方工程格式时先探测版本标记，按版本选择 schema 规则，并对该版本的全部目标位置同步更新，而不是假定单一字段永远是唯一真值。

**领域**：软件工程 / 数据格式。来源：[[项目笔记/capcut_cli]]（version 实测模板 6.5.0、支持 6.x–9.x；8.7 多时间线需同步处理）。

与 [[证据优先质检ProofOverClaims]] 的契约先验一致；也是 [[快照契约与不可变只读]] 在写入侧的镜像。版本未识别时应停止或降级，不可盲目按新 schema 写旧格式。
