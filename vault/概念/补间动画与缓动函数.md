# 补间动画与缓动函数

**一句话定义**：补间（tween）是只指定起点、终点、时长，中间每一帧的值由公式自动算出的动画方式；决定"中间值怎么变"的公式叫缓动函数（easing）。

**属于领域**：前端 / 动画 / 人机交互

**通俗理解**：补间像"自动领航"——你告诉飞机从北京起飞、降落上海、全程 2 小时，仪表自动算出每一秒的位置。缓动函数是飞行性格：线性 = 全程匀速巡航（机械感）；`easeOutCubic` = 先猛冲后滑行（刹车感）；`easeOutBack` = 冲过站台再倒回来（果冻回弹感）。同样 700 毫秒，曲线不同，观众感受到的"性格"完全不同。

**与已有概念的关联**：
- 应用：[[Three.js与场景图]]（3D 场景里每个零件的入场/过渡动画几乎都靠补间）
- 应用：[[程序化建模]]（程序化模型的"生长"动画 = 每个零件一个错峰补间）
- 对照：[[双时钟模型]]（zoetrope）——那边按呈现时钟逐帧推进状态，这边按 elapsed time 算补间进度，思想同族：状态由时间函数导出，不逐帧存

**实现要点**：
- Web 上零依赖做法：`requestAnimationFrame` 循环里用 `t = (now - start) / duration` 算进度，套缓动函数，再 `object.value = start + (end - start) * easedT`。
- 错峰（stagger）：第 i 个元素的 `start` 加 `i × 90ms`，一群元素就有"排队生长"的效果。
- SVG 线条"重绘"是补间的特例：`stroke-dashoffset` 从线长递减到 0（见 [[项目笔记/blueprint_to_3d]]）。
