# 统一数据网关

**一句话定义**：用一个端点 + 一个密钥 + 一份账单，把 N 个上游平台的数据 API 聚合成 Agent 可直接调用的统一服务（如 AgentKey、tikhub）。

**属于领域**：AI 工具生态 / API 经济；是 [[M×N集成问题]] 在"数据获取"维度的商业化解法。

**通俗理解**：像流媒体的"一站式会员"——不再每个平台单独买票（每家 API 注册、充值、管 Key），而是交给一个中间商打包卖给你。代价是中间商抽成 + 请求必经第三方（隐私/单点风险）；收益是上游渠道腐化、风控变化全部由厂商养。
