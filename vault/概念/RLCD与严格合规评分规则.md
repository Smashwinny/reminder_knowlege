# RLCD与严格合规评分规则

**一句话定义**：用"严格合规评分规则"（strictly proper scoring rules）当强化学习奖励来训练决策模型的方法（Laya 的 RLCD）——数学上保证模型唯一最优策略是**报出真实信念的概率**。

**属于领域**：AI / 模型训练（强化学习 × 校准）。

**通俗理解**：设计一张"撒谎不划算"的打分表：你宣布"90% 是 A"，评审按你报的概率和真实结果结账。这类打分表（对数评分、球面评分、排序概率评分）有个数学性质——**期望得分在你报的 P 等于真实频率时取到最大**；报高报低都亏。把它当 RL 奖励反复更新，模型就被逼成"诚实的人"：置信度数字可直接当业务依据。对比普通分类训练（交叉熵只看 argmax 对不对），训出来的模型常常"永远 99% 自信"。

**工程要点**：Laya 用 REINFORCE + GRPO 式组基线（8 个噪声采样一组内互相比），多轮任务加 TD(λ=1)；另训 Act/Escalate 头，置信 <62.5% 学会升级给人。
