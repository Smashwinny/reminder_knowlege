# 对比学习

**一句话定义**：一种"拉正推负"的训练范式——让模型把语义相关的样本对（正样本）的向量拉近，把不相关的（负样本）推远，由此学出有意义的意义空间。

**属于领域**：AI / 表示学习 / 自监督学习

**通俗理解**：像训练鉴宝师：真品和它的档案配对摆在一起（拉近），和同时展出的其他赝品自然隔开（推开）。看多了真假对照，鉴宝师就懂了"像"的尺度。比喻落回术语：常用损失是 InfoNCE——把"从 N 个候选里认出正样本"当成分类问题，batch 里其他样本自动充当负例（in-batch negatives），batch 越大负例越丰富，坐标系分得越开，这也是 embedding 训练显存吃紧的原因。

**与已有概念的关联**：
- 是 [[向量与Embedding]] 的主要训练方法（CLIP 图文对、WeMM 多模态检索都是它）
- 大模型教小模型的**知识蒸馏**常与其配合（WeMM 用跨尺度知识迁移让 2B 打赢 8B）
- 是 [[RAG检索增强生成]] 检索质量的上游：embedding 空间分得好不好决定检索准不准
