# 提示词方言适配

**一句话定义**：跨模型复用提示模板时，先核对目标模型对负向约束、参数和语法等能力的支持，再真正转换表达；无法转换的部分必须显式保留为未解决项。

**属于领域**：AI / 提示工程 / 跨模型兼容性。

**关键纪律**：不能仅删除不支持的“禁止”等词，再附一句“已改写为正向描述”就宣称适配完成。应输出具体目标，例如把“禁止切镜”改为“从起始动作到结束动作保持同一个连续镜头”，并用断言检查旧措辞消失、新目标存在。缺失映射进入 `unresolved`，采用 fail-closed 而非静默成功。

- [[运镜四要素工单]]：本次以 generic 与 Runway Gen-4 两种文本输出为例。
- [[证据优先质检ProofOverClaims]]：转换声明、文本断言与真实生成效果分层。
- [[提示词爬山法PromptHillClimbing]]：简单提示逐项迭代便于定位兼容性问题。
