# 上线前差异闸门（DIFF GATE）

**一句话定义**：AI 改写线上内容前，先机械列出旧版有而新版丢失的元素（表格、表单、图片、链接、H1 等），清单需人工确认；有丢失即 fail-closed 拦截。

**领域**：AI 工具生态 / 内容安全。来源：[[项目笔记/chatseo_skills]]（diff_gate.py 三轮实测）。

它是 [[质检Gate与自我纠错循环]] 在发布域的特化，也是 [[证据优先质检ProofOverClaims]] 的改写实例：编译或“改写完成”不算上线证据，差异清单才算。抓丢失、同页无误报、修复后放行三项应同时验证。
