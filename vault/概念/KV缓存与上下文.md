# KV缓存与上下文

**一句话定义**：KV 缓存 = 模型生成时为"回看前文"而缓存的每 token 中间结果；上下文窗口 = 模型一次能"回看"的最大 token 数，KV 缓存大小随它线性增长。

**属于领域**：AI / 大模型

**通俗理解**：像写作文时不许翻页——前面写过的每一段都要"记在脑子里"（缓存），作文纸越长（上下文越大），脑子里要记的越多（显存）。实测 0.6B 模型 4096 上下文：文件 522MB，显存 930MB，多出的 ~350MB 主要是 KV 缓存。落回术语：**显存 = 权重（固定）+ KV 缓存（随 num_ctx 线性增长）+ 计算缓冲**，显存吃紧时先砍上下文再考虑换小模型。
