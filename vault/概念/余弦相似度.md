# 余弦相似度

**一句话定义**：用两个向量夹角的余弦值（[-1,1]，越大越相似）衡量它们"方向"是否一致，公式 cos θ = A·B / (|A|×|B|)。

**属于领域**：线性代数 / 信息检索

**通俗理解**：只看方向、不看长短。两段文本一个长一个短没关系，只要"意思指向"同一个方向，夹角就小、分数就高：完全相同 = 1.0；换个说法说同一件事 ≈ 0.98；完全无关 ≈ 0（夹角 90°）。文本 embedding 的业界默认距离度量就是 Cosine，Qdrant 建集合时三选一：Cosine / Euclid（直线距离）/ Dot（点积，推荐系统常用）。

**与已有概念的关联**：
- 作用在 [[向量与Embedding]] 产出的向量上
- 是 [[向量数据库]] 检索排序的打分函数
- [[HNSW近似最近邻索引]] 就是在图里找"余弦分数最高"的邻居
