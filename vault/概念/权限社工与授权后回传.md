# 权限社工与授权后回传

**一句话定义**：攻击者用功能伪装、紧迫话术、重复提示等使用户主动授权，再通过周期上传、第三方接收方和结果存储形成数据暴露的社工—技术复合链。

**领域**：社会工程防护 / 数据安全。来源：[[项目笔记/storm_breaker_defense]]、CISA 钓鱼建议及上游静态审计。

拒绝会阻止本次敏感 API 调用，但不抹去页面访问和普通指纹事实。检测应看权限必要性、重复上传、第三方接收方和系统最近活动；响应按停止、撤权、证据、影响、报告、复盘推进。与 [[证据状态机]]、[[证据优先质检ProofOverClaims]] 互链；不能把 mock 通过扩写为真实硬件或跨浏览器验收。
