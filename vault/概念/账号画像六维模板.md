# 账号画像六维模板

**一句话定义**：用 identity/style/audience/platforms/preferences/memory 六个 Markdown 文件，把账号定位、表达风格、受众、平台、偏好红线与长期记忆资产化；换账号即换目录，创作时整体注入上下文。

**领域**：AI 工具生态 / Agent 记忆。来源：[[项目笔记/easel]] 的增补实验（profiles/_template 实测六文件齐备）。

它是 [[角色提示]] 的长期文件化实现；memory.md 可对应 [[三层记忆]] 的长期层，并遵循反膨胀纪律——只有真正有价值的洞察才写回。与 [[决策记忆结算反思闭环]] 的写回机制同构。
