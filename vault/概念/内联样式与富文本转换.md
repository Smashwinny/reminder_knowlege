# 内联样式与富文本转换

**一句话定义**：把 Markdown 渲染成"每个标签都自带 style 属性、零 class、零 style 标签"的 HTML，使排版在微信等只保留内联样式的富文本编辑器里一字不差存活。

**属于领域**：前端 / 内容发布管道

**通俗理解**：CSS 有三种挂法——外链样式表、页内 `<style>`、内联 `style` 属性。微信公众号后台（UEditor 内核）粘贴时做**白名单消毒**：`class` 属性和 `<style>` 标签整段删除，只有内联 style 能通过。类比：外链样式像"装修手册放在物业办公室"，进小区时手册被没收、房子变毛坯；内联样式像**把装修直接烧进砖里**，房子搬哪都带装修。落回术语：**style 内联属性是随标签自包含的样式声明，不依赖任何外部选择器**，代价是 HTML 体积膨胀。

**实现套路**（火星编辑器的做法，可迁移）：
1. `markdown-it` 把 Markdown 解析成 Token 流（heading_open → inline → heading_close 这类"开门/内容/关门"标记）
2. **全量覆盖渲染规则**：每条 open/close 规则都输出带主题配色的内联 style 版本，主题只是经 env 注入的配色数据
3. **剪贴板双格式**：`ClipboardItem` 同时写 `text/html`（内联 HTML）+ `text/plain`（纯文本兜底），粘贴方自选；复制前剥掉 data-line 等预览专用标记
4. 图片免图床：转 **data URI**（二进制 base64 内嵌 src），随 HTML 走，实测微信后台保留
