# 记忆四层模型

**一句话定义**：Memmy 把个人 AI 记忆分为 L1 Trace（原始轨迹）→ L2 Policy（归纳出的程序性策略）→ L3 World Model（项目/环境稳定知识）→ Skill（可调用 SOP）四层，由后台流水线按奖励逐层"蒸馏升值"，每层有独立的检索通道和注入顺序。

**属于领域**：LLM 应用 / 个人记忆系统

**通俗理解**：像"**监控流水账 → 经验总结帖 → 项目百科页 → 标准操作手册**"。流水账什么都记但量大值杂；值钱的流水账被归纳成"遇到 X 该怎么做"（L2）；同类经验再抽象成"这个项目/环境是什么样"（L3）；反复验证有效的 L2 直接结晶成能一键复用的 SOP（Skill）。关键在<span style="background:#FFD600;font-weight:bold">每层晋升都有门槛（证据数 minSupport、收益增益 minGain、可撤销的归档线 -0.05）</span>——记忆不是记进去就算，而是被结果反复修正、能升也能忘。注意与 [[三层记忆]]（deeptutor 的 L1轨迹/L2界面摘要/L3用户画像）区分：同为逐层压缩，Memmy 压的是**可执行经验**而非**摘要**，且终点是可复用技能而非画像。

**与已有概念的关联**：
- 同构：[[三层记忆]]（同"逐层压缩"思想，分层语义不同：策略 vs 摘要；Memmy 多一层 Skill 和奖励遗忘机制）
- 相关：[[本能学习与置信度评分]]（同样"价值由结果修正"：gamma/lambda/30天半衰期 ≈ 置信度评分的记忆版）
- 相关：[[RAG检索增强生成]]（四层记忆最终靠检索注入上下文，是"记住你"侧的 RAG）
- 相关：[[AgentSkills技能包]]（Skill 层产物就是技能包形态：名字+指南+步骤+验证条件）
