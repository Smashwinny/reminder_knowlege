# 布线特异性与零训练涌现

**一句话定义**：行为的来源不是训练也不是规则，而是"接线接对了"——证明手段是 shuffle 对照：每条突触保留强度和符号、只随机换目标，行为随之消失，即布线特异性（wiring specificity）。

**属于领域**：连接组仿真方法论；可迁移到任何 AI 系统的机制归因实验。

**通俗理解**：人家灯亮，你怀疑是"灯泡好"还是"线接对了"？把导线全部剪断换着乱接（灯泡和功率都不变）——乱接后灯不亮，就证明亮灯靠的是布线本身。果蝇开无人机正是这套：real 布线 20 次全躲避（平均 1.89m），shuffle 布线 0~50%，随机网络 0~50%，断脑 0% 撞毁。**两个反直觉实测**：① 布线特异性不在"能不能到达"——13 万神经元的密网里打乱布线后 2 跳可达率仍 20/20；特异性在"连接有多强"（糖→MN9 直接突触 0 条，靠 59 条特定两跳边，强度合计 204 个突触）；② 单摘任一下行神经元避障仍在（分布式冗余），全摘转向读出才失效。

**与已有概念的关联**：
- 底座是 [[FlyWire全脑连接组]] + [[LIF全脑仿真]]；对照设计与 [[证据优先质检ProofOverClaims]]、[[质检Gate与自我纠错循环]]、[[Agent评测框架八步法]] 同血统——"real vs shuffle vs rand vs nobrain 四组对照 + n=20 + 置信区间 + 消融"可直接搬到 AI 系统评测
- "不训练也出功能"给 [[Agent后训练SFT与RL]] 提供对照物：学习不是产生能力的唯一途径
- 与 [[Sim2Real与MuJoCo仿真]] 互补：那边验证"仿真→真机"，这边验证"解剖→仿真"
