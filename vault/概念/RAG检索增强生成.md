# RAG 检索增强生成

**一句话定义**：Retrieval-Augmented Generation——回答问题前先从你的文档库中**检索**出最相关的几段，塞进提示词再让模型回答，即"开卷考试"模式；依赖 Embedding（把文字变成高维坐标点，意思越近坐标越近）和 VectorStore（存坐标、支持最近邻检索的数据库）。

**属于领域**：LLM 应用 / 信息检索

**通俗理解**：模型没读过你公司文档，上下文窗口也塞不下整个文档库——RAG 就是**先建图书馆（离线：文档切块→每段算"语义指纹"向量→入库），再开卷查资料（在线：问题也算向量→找最近的几段→塞给模型）**。"小猫"和"猫咪"的向量几乎重合，和"股票"相距很远——这就是"语义相关"的数学化。收益：有据可依、可标出处、大幅减少模型胡编。
