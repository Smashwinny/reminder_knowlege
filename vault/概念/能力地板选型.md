# 能力地板选型

**一句话定义**：给任务先画出"真实能力地板"（稳定工具调用、遵守输出规则等最低要求），按地板选最便宜的模型，而不是按模型天花板付钱。

**属于领域**：LLM 工程 / 模型选型。

**通俗理解**（比喻/例子，讲完落回术语）：买菜刀切葱不必买斩骨刀——先量清楚要切什么。落回术语：微信随记任务的地板是"能稳定调用保存脚本 + 按规则生成短标题"，正文一个字不许模型碰，于是 DeepSeek V4 Flash 级的便宜模型就是最优解；高频 × 低难度任务，性价比模型总成本最低。

**操作要领**：
1. 把任务拆成"AI 必须做的"和"脚本/确定性代码能做的"——能下沉给脚本的绝不留给模型（随记里写文件/Git 同步全在脚本）
2. 地板通常只有两三项：工具调用稳定性、规则遵守、输出格式简单
3. 高频任务的 API 费 = 单价 × 次数，地板选型省的是乘数最大的那项

**与已有概念的关联**：
- 相关：[[确定性脚本]]（能下沉的重活交给脚本，模型只做不可确定的一小步）
- 相关：[[事实与判断分离]]、[[数据源降级链]]（同样是"给活儿匹配最合适的执行者"）
- 相关：[[LLM工具调用]]（工具调用稳定性常是唯一硬地板）
