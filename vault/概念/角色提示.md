# 角色提示

**一句话定义**：用 role（身份）/ goal（目标）/ backstory（背景故事）三段文字构造系统提示词，让模型持续以特定身份、口吻和判断习惯输出。

**属于领域**：AI / 提示工程

**通俗理解**：给演员发剧本。crewAI 实测：同任务把 role 从"资深技术研究员"改成"武侠小说家"，要点立刻满纸江湖气——改一个字符串就是换人格。多智能体协作里它还有架构意义：每个 Agent 的上下文只装一个角色，避免角色混乱。
