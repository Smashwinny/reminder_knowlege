# QDD准直驱与反驱力控

**一句话定义**：QDD（Quasi-Direct Drive，准直驱）= 电机不经大减速比齿轮箱直接驱关节；高反驱（Backdrivability）= 从输出端施力电机端会被带着转——两者合起来让电机绕组天然充当力传感器，再用重力补偿前馈把"自重"从人手/算法肩上卸掉。

**属于领域**：机器人学 / 力控

**通俗理解**：传统工业臂像"隔着很长的变速自行车链条"——手掰不动关节，撞人电机也不知道；QDD 像把链条拆掉直接用手拧电机轴，力一摸就透回来。反驱是把双刃剑：断电的手臂会被自重拖塌（OpenArm v1 模型 MuJoCo 实测：力矩全零 2s，肩关节 joint2 掉 100.1°，峰值 7.64 rad/s），所以必须配**重力补偿**——按当前位姿用动力学模型算出"恰好抵住自重"的力矩先发给电机，剩下才是人手该出的力。前馈管"已知的重力"，反馈管"意外"，实测竖直伸展位姿保持：纯 PD 残差 0.135°，加重力补偿后 7 关节误差全 0（改善 100%）。

- 反驱红利直达数据层：遥操作数据能记 qtorque，喂给 [[策略观测向量与动作契约]] 与 [[Sim2Real与MuJoCo仿真]]
