# 免费层额度墙设计

**一句话**：SaaS 免费试用层的额度墙通常同时卡在五个维度——数量（各产品固定量）、对象（已验证 recipient 上限）、内容（仅官方模板）、地理（限注册国）、时间（30 天过期）——Twilio 试用号是五维齐全的标准样本。

**领域**：SaaS 商业模式 / 试用机制设计。来源：[[项目笔记/twilio_trial_number]]（trial_simulator.py 9/9 断言建模验证）。

五维额度墙拆解（Twilio 实例数字）：100 SMS/100 WhatsApp/3000 邮件/75 分钟（各产品固定，非共享余额）；验证 recipient 上限 5；仅官方模板；限注册国；30 天过期。

防滥用核心机制 = 验证 recipient 列表；CPaaS 四层模型（号码/额度/模板/合规）。

反模式：把试用号当长期资产绑定重要账户；只看"免费额度"数字不看维度；用试用号做营销发送（直接撞 A2P 合规墙）。
