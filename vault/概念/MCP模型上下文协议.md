# MCP 模型上下文协议

**一句话定义**：MCP 是 AI 应用连接外部工具和数据源的开放标准接口——"AI 应用的 USB-C"。

**属于领域**：AI 工具生态 / 客户-服务器协议设计。

**通俗理解**（比喻/例子，讲完落回术语）：
以前每个 AI 应用接每个工具都要单独写对接代码（M×N 乱麻）；MCP 规定大家用同一套消息格式说话，应用只需实现一次客户端、工具只需实现一次服务器（M+N）。三个角色：**Host**（宿主，如 Claude Desktop，跑大模型）、**MCP Client**（宿主内部的连接器，一个连接对应一个）、**MCP Server**（工具提供方，把文件/数据库/浏览器等能力包装成标准工具）。协议本身构建在 [[JSON-RPC与stdio传输]] 之上，日常交互就是 [[工具调用生命周期]] 里的 initialize → tools/list → tools/call。生态见 awesome-mcp-servers 清单（4086+ 服务器，约 60 类）。

**与已有概念的关联**：
- 相关：[[JSON-RPC与stdio传输]]、[[工具调用生命周期]]、[[M×N集成问题]]
- 安全上类比 [[质检Gate与自我纠错循环]]：在"模型想调用"与"真正执行"之间设人工/规则 Gate，配合最小授权与审计日志。风险包括过度授权和 [[提示注入]]。
