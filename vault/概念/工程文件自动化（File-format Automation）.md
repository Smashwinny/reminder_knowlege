# 工程文件自动化（File-format Automation）

**一句话定义**：对没有 API 的 GUI 专业软件，直接解析其工程文件格式，按版本感知 schema 读写并配合原子写与备份，把只能人工操作的软件变成可编程资源。

**领域**：AI 工具生态 / Agent 集成。来源：[[项目笔记/capcut_cli]]（无 CapCut 环境建草稿、加文字轨道、lint 全过）。

工程文件可以视为 [[JSON-IR类型化中间表示]]；[[Checkpoint存档与持久执行]] 的 .bak+restore 是文件级恢复机制。集成前必须确认许可和版本，不能把能写文件等同于兼容宿主软件。
