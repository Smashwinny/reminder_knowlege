# 世界模型（World Model）

**一句话定义**：学习“环境接下来会怎样”的预测模型（压缩时空表征），策略在模型生成的想象轨迹中训练——没有仿真器就自己学一个。

**领域**：AI / 强化学习。来源：[[项目笔记/world_models_series]]（六项目一手核实 + 迷你 MLP 复现三要素）。

与 [[Sim2Real与MuJoCo仿真]] 的替代路线、[[漂移与回环闭合]] 的开环误差累积和 [[策略观测向量与动作契约]] 的动作条件预测互链。视频预测、动作输出和闭环控制是三件事，必须分别验收。
