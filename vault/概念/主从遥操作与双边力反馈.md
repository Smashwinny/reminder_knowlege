# 主从遥操作与双边力反馈

**一句话定义**：主从遥操作 = 用一台同构机械臂（Leader）被人手抓着动、把关节角抄给真干活的从臂（Follower）；双边控制（bilateral）= 从臂在真实世界受到的力矩再原路传回主臂变成人手的推拉感（力反馈），单边控制（unilateral）= 只抄角度不回传力。

**属于领域**：机器人学 / 遥操作

**通俗理解**：单边像"看直播抄作业"——从臂抓没抓到东西你毫无感觉；双边像"握着徒弟的手教写字"——鸡蛋捏多重，掌心就尝到多重的反作用力。OpenArm 的主从臂是**同一套 QDD 硬件**，力才"透得回来"（[[QDD准直驱与反驱力控]] 是物理前提）；主臂为外骨骼穿戴式架构（项目称 KER，Kinematic EXO-frame Replica）。控制环 500Hz，数据落盘 250Hz。

**与已有概念的关联**：
- 力反馈数据存进 LeRobot 格式（openarm_dataset，含 qtorque），是模仿学习的"带力觉燃料"
- 从臂端执行走 [[CAN总线与MIT电机帧]]
- 采集-训练-部署闭环见 [[Sim2Real与MuJoCo仿真]] 与 [[策略观测向量与动作契约]]
- 与 [[Stewart并联平台]] 同属"把运动变成伺服"家族：并联管 6DOF 刚性定位，串联 7DOF 主从管柔性操作
- 主从两端都是"描述-通信-控制"分层的机器人工程范式（[[机器人守护进程架构]] 是进程层同款分层）
