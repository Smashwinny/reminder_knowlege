# 混合线性注意力

**一句话定义**：把"线性注意力"和"全注意力"按配比混装在同一模型里——大部分层用 O(n) 的线性注意力速读、少数层保留 softmax 全注意力精读，兼顾长序列效率与表达精度。

**属于领域**：AI / 模型架构 / 高效推理

**通俗理解**：全注意力像开会时每人都和所有人逐对深谈，效果最细但人数一多就开不完（序列变长算力平方增长）；线性注意力像传阅纪要，每个人只看压缩后的状态，快但细节会丢。混合架构 = 大部分议程传阅纪要、关键议题停下来逐对深谈。比喻落回术语：线性层把注意力改写成固定大小的递推状态（类 RNN，每 3 层一循环），全注意力层（每 4 层插 1 层）负责精确的长程检索，Qwen3.5 一代的配比是 3:1。

**与已有概念的关联**：
- 是 [[KV缓存与上下文]] 压力的缓解路线之一：长上下文场景下替代/补充 GQA 等传统省显存手段
- 实例：WeMM-Embedding（24 层 = 6 组 × [3 线性 + 1 全注意力]）、Qwen3.5 系列
- 服务于"亿级调用"工程目标：视频几百帧、文档几千 token 的输入长度下保持吞吐
