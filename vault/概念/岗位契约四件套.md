# 岗位契约四件套

**一句话定义**：把常驻 Agent 当员工管的四个文件化要素——契约（可验收职责+红线+失败定义）、试用期（小样本试运行）、转正条件（连续通过才放权）、交接（岗位上下文落盘）。

**领域**：AI Agent / 治理。来源：[[项目笔记/grok_bot_method]]（样例契约 6/6 通过官方安全对照）。

与 [[Agent指令文件AgentMd]]、[[AgentHarness智能体挽具]] 和 [[代码管边界提示词管判断]] 互链。作者的三次试运行/五次通过是经验值，不是平台保证；红线触发应能回退权限。
