# 确定性信号引擎

**一句话定义**：用可测试的关键词/模式规则（而非大模型）把原始消息流打成"类别 × 阶段 × 优先级"信号，并按对象聚合出行动清单的引擎。

**属于领域**：规则引擎 / 情报处理流水线。

**通俗理解**：矿山里的选矿机——泥沙（聊天记录）倒进筛子，按网眼（规则）分出矿石（信号）。同一批泥沙永远筛出同样的石头：[[确定性脚本]] 的"同输入同输出"保证了它可以被单元测试钉死。代价是筛子不认语境："明天记得买票"会被当成商务"排期"（实测误报）。所以它是筛子不是裁判：每条信号都附证据原句，最终判断交给人——这正是 [[AI味模式库与信号非证据]] 的铁律"信号不是证据"的工程化。

**与已有概念的关联**：
- [[确定性脚本]] 的"情报版"实例：同输入同输出，测试可锁定
- 报告管线（读入→打标→聚合→写报→渲染）是 [[构建流水线与Pass]] 的迷你形态
- "引擎产事实、人做判断"是 [[事实与判断分离]] 的小型实践
- 宁可多报不可漏报的误报倾向，与 [[评分契约与护栏]] 的"评分只是信号"同理

**实测要点**（wechat-intelligence-hub v0.9.2-preview.2）：一条消息可命中多条信号（"预算650 USD 这周五发布"→ 报价+排期+创作 3 条）；金额可抽取（650 USD / 3000-5000 RMB）；对闲聊干扰（快递、JD 推销）抗干扰正确；对"改好了，晚上发你"类承诺句漏报。
