# 事实与判断分离

**一句话定义**：让 LLM 应用里"能算的绝不猜"——数字事实（指标、评分、统计量）全部由确定性代码先算好，LLM 只负责事实之上的综合研判与人类可读的表达，禁止模型直接对原始数据"口算"。

**属于领域**：AI / LLM 应用架构（高可靠性输出场景的通用模式）

**通俗理解**：像医院出诊断——验血报告由仪器打印（确定性代码），医生（LLM）拿着报告做综合判断、写诊断意见；你绝不会让医生瞪着病人的脸"目测血红蛋白"。daily_stock_analysis 的两段式：`stock_analyzer.py` 先用 pandas 算出 MA/MACD/RSI/乖离率并打出 0-100 规则评分，`pipeline.py` 再把这些**算好的事实**连同新闻公告拼成上下文包交给 LLM 写决策仪表盘。对比反例"把行情 JSON 直接扔给模型问涨跌"——模型对一串数字做心算 RSI，错一位全盘皆错。

**与已有概念的关联**：
- 是 [[LLM工具调用]] 的前置纪律：工具（确定性代码）负责算，模型负责点菜和解读，与"LLM 只点菜、框架炒菜"同族
- 与 [[质检Gate与自我纠错循环]] 配套：事实层可 Gate（指标有口径锁定测试），判断层才需要护栏（见 [[评分契约与护栏]]）
- [[RAG检索增强生成]] 是它在"知识"维度的镜像：先检索事实再回答，先计算事实再研判
