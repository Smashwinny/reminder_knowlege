# LoRA低秩适配微调

**一句话定义**：冻结基座模型全部权重，只在每个目标线性层旁路注入一对可训练的小矩阵 A（r×d）、B（d×r），用 W' = W + B·A 近似权重变化，秩 r 通常只有 8~64——训练参数量降到全量的约千分之一。

**属于领域**：AI / 模型微调（参数高效微调 PEFT 家族的代表方法）。

**通俗理解**（比喻/例子，讲完落回术语）：W 是一台精密仪器的主机（不敢乱动），LoRA 是外接的几个旋钮——学会新技能只需调旋钮，不用重造主机。依据是经验发现：微调引起的权重增量 ΔW 虽然是几十亿维的矩阵，但有效变化集中在很少几个方向上，即"低秩"。于是不直接学 ΔW，而是用两个小矩阵的乘积 B·A 去逼近它（r=8 时参数量仅为原矩阵的千分之一）。好处有二：优化器状态只存在于小矩阵上，训练显存暴降；一个基座可以挂多个 adapter（身份旋钮、客服旋钮），各存几 MB~几十 MB 的小文件，随时叠加切换。
