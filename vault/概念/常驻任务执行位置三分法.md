# 常驻任务执行位置三分法

**一句话定义**：常驻 Agent 的任务应分别标注在云端电脑、授权本机或派生产品执行，因为在线条件、登录态、权限与计费不会自动跨位置继承。

**属于领域**：AI Agent / 产品机制 / 权限与成本。

**操作要领**：云端离线继续不代表能访问已关机本机；本机需逐台授权并在使用时保持在线和应用开启；派生 Work/Codex 任务按各产品额度。以 2026-11-22 Dots 文档为例，可连接多台电脑，但每线程一次一台；云浏览器不继承个人浏览器登录。位置数量不是安全隔离证明。

**与已有概念的关联**：
- [[共享环境非隔离原则]]：每线程一台是执行粒度，不自动隔离信任。
- [[沙箱与审批正交]]：执行位置与批准动作是不同维度。
- [[付费调用回执与预算熔断]]：Dot 对话与派生任务分账。
- [[显式控制权交接协议]]：位置明确后，接管/交还才有可审计对象。
