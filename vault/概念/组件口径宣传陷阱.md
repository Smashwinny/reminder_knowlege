# 组件口径宣传陷阱

**一句话定义**：多组件模型（text encoder、transformer、VAE 等）拿单一组件参数量当整体宣传，导致用户按错误预算准备磁盘和显存；防御法是用仓库 tree API 查分片体积再算账。

**领域**：AI / 模型工程。来源：[[项目笔记/qwen_image_21]]（text_encoder 17.54GB + transformer 14.23GB 实测）。

与 [[证据优先质检ProofOverClaims]] 同源：官方模型卡的单一数字也要放回组件结构解释；与 [[面数口径与减面下限]] 同属“先问口径”的跨域陷阱。参数量、文件体积和运行时显存不是同一个指标。
