# 底图复用与程序化叠加

**一句话定义**：要"画面钉死、只动一个元素"时，让 AI 只生成**一张**完美静帧，把运动部分（扫光/雪花/角标闪烁）交给代码作为纯函数叠加——几何只画一次，动的那层可被数学严格证明没碰它。

**属于领域**：AI / 图像工程（生成结果的确定性后处理），动画与批量场景的工程纪律

**通俗理解**：图像模型是"重画匠"不是"复印机"——每出一帧都重新画一遍，瓶身 Logo 每帧都在 ±3px 游移（实测）。复印才不会走样，所以**同一个东西出现两次以上就别让模型画第二次**：AI 负责那"一份"，代码负责"复印 N 份 + 只动光"。

**要点**：
- 判据一句话：**重复 = 复印，交给代码；理解 = 生成，交给模型**
- 实操配方（商品扫光广告）：上传商品图 → AI 出一张摄影棚级商品底图（唯一 AI 步骤）→ Python 叠加 softbox 高斯光带（宽、低峰值 ~13%、边缘羽化、轻微暖色）从左扫到右 → 循环 GIF
- softbox 三要素：高斯亮度分布（非纯白矩形）、峰值 34/255 只"提亮"不"覆盖"、R 通道增益> B（钨光灯暖调）；加 3.2σ 硬截止让光带有确定支撑域，可严格验证
- **构造性保证 > 提示词约束**：光带是只依赖横坐标 x 的纯函数，支撑域外像素连加都加不上——实测 48 帧 × 逐像素偏差 = 0；对比逐帧重绘的仿射抖动模拟 ±3px
- 局限：叠加层只能改亮度/色温，不能改透视、遮挡、反光形状；物理真实运动仍需视频模型
- 验证必须在**合成帧层**做：GIF 是 256 色有损调色板，回读自带量化色差，不能拿 GIF 当几何证据
