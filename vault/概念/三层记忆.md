# 三层记忆

**一句话定义**：把用户与 AI 的长期历史按"原始轨迹 L1 → 界面摘要 L2 → 用户画像 L3"三层存储、由 LLM 逐层压缩的记忆架构——L3 档案小到可以每轮注入提示词，但每句话都能通过 Memory Graph 链回 L1 原始证据。

**属于领域**：LLM 应用 / 个性化系统

**通俗理解**：像"**监控日志 → 周记 → 个人简历**"。全存聊天记录有两个致命问题：上下文塞不下、噪音淹没重点。DeepTutor 的实测布局（`data/memory/`）：L1 是 `trace/<界面>/<日期>.jsonl` 只追加流水账（每次提问、每次检索都记）；L2 是每个使用界面一份 `L2/<界面>.md` 摘要，带脚注引用；L3 跨界面浓缩成 4 个档案（recent 近况 / profile 画像 / scope 范围 / preferences 偏好）。consolidator（LLM 驱动）定期执行 L1→L2→L3 的压缩。**个性化因此是可见、可编辑的，不是黑箱**——L3 里一句"你总忘记初始化列表"能点回原始证据。

**与已有概念的关联**：
- 相关：[[RAG检索增强生成]]（记忆解决"记住你"，RAG 解决"记住资料"，互相独立又互补）
- 同构：[[构建流水线与Pass]]（压缩是一个多 Pass 流水线：日志 Pass → 摘要 Pass → 画像 Pass）
- 相关：[[Agent循环]]（L3 档案最终作为上下文注入循环的每轮提示词）
