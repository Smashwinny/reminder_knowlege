# 情绪脱水测试

**一句话定义**：把脚本/大纲里的情绪宣泄词（"令人发指""惊天内幕""离谱"）全部删掉，看剩下的事实逻辑还站不站得住——站不住 = 内容厚度不合格；常作为"选题五项内审法"的第 4 道阀。

**属于领域**：AI/内容质检（选题与脚本门槛）

**通俗理解**（比喻/例子，讲完落回术语）：像给文案做"去油见骨"——把辣椒油画掉，看汤底还有没有料。落回操作：删掉情绪词后计算保留比例与剩余文本中的事实引用数（数字、法条、比例）。实测对照：好题脱水后保留 100%、4 处事实引用；纯情绪题只剩 53%、0 处事实引用。"推动进度条前进的必须是事实密度，不是骂街的语调。"

**选题五项内审法**（每阀独立否决，任一不过整题毙掉）：
1. 热点时效：72 小时内必须有新进展，旧闻翻炒必须说明"为什么今天被再次审视"
2. 痛点圈层：个案特例要能提炼成普适经验（"A 市某小区"→"你每年多交了多少冤枉钱"）
3. 增量材料硬度：能翻到判决书/质检报告/招股书原件，而不是十万博主互洗的二手通稿；证据链断裂就承认"公开资料无法断定"
4. 情绪脱水测试（本条）
5. 叙事类型轮换：连续两期禁用同一种叙事模型，防八股文流水线
