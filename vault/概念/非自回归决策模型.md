# 非自回归决策模型

**一句话定义**：不做 token 生成、对输入做**单次前向传播**直接输出带校准概率的结构化决策的编码器模型（代表：开源 Laya，Jev 的开源同类）。

**属于领域**：AI / 决策模型（生成式 LLM 之外的"判断层"，路由/分诊/审核/护栏）。

**通俗理解**：LLM 回答判断题像写作文（一个字一个字往外蹦，越写越贵还可能写坏 JSON）；非自回归决策模型像涂答题卡——卷子看一眼（双向编码器整句理解），所有题的选项概率一次涂完。快（GPU 33ms / CPU ~250ms）、延迟固定、输出结构天生合法、不会幻觉出不存在的选项。代价：**只能答题不能写作文**。骨架 = ModernBERT-large 395M 编码器 + ~25M 决策头（421M 总量）；多语言版用 mmBERT-base 322M 覆盖 100+ 语言。

**关键事实**：
- 三原语与 Jev 兼容：choice（选选项）/ score（量表分布取期望）/ noul（校准真假概率）
- checkpoint 路由：英文 checkpoint 离英语即塌方（印地语 0.100 vs 乱猜 0.050 且高置信 ECE 0.855），靠脚本检测切 multilingual
- 准确率口径敏感：零样本 0.362 → 域内微调 0.766（typed-decisions 基准）
- criteria 就是决策模型的 prompt：语言错配会静默劣化（实测中文输入+英文 criteria，urgency 全饱和在最高档；换中文措辞 4/12→7/12）
