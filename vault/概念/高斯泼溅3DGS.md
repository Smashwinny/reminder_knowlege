# 高斯泼溅 3DGS

**一句话定义**：用上百万个显式的彩色半透明 3D 椭球（各向异性高斯）表示整个场景，配合可微光栅化"泼溅"渲染，实现照片级新视角的**实时**（1080p ≥30FPS）合成与渲染。

**属于领域**：三维图形 / 新视角合成（计算机视觉 × 实时渲染交叉）

**通俗理解**：NeRF 把场景藏进神经网络这个"黑盒"，看一眼要查表几百次；3DGS 把场景摊在桌面上——每个"雪球"的位置、大小、朝向、颜色都看得见。训练像画家修画：哪里画淡了再点几笔（克隆）、哪里涂成一坨抹开画细（分裂）、废笔擦掉（剪枝），即**自适应密度控制**。渲染则是把每个椭球透视投影成 2D 椭圆、按深度排序、逐像素 α 混合——就是 GPU 光栅化老路，所以快。

**关键事实**：
- SIGGRAPH 2023 最佳论文（INRIA Kerbl et al.），官方开源 graphdeco-inria/gaussian-splatting（24k+★）
- 一个高斯 = **62 个 float32 = 248 字节**（位置 3 + 法线 3 + SH DC 3 + SH 高阶 45 + 透明度 1 + 尺度 3 + 四元数 4）；尺度存 log、透明度存 logit，用时 exp/sigmoid 还原
- 初始化来自 COLMAP（SfM）稀疏点云；训练 = 渲染与真照片比差（L1+SSIM）反传 ×30k 迭代
- 文件很大：百万高斯 ≈ 250MB，催生压缩研究（类比 [[量化与GGUF]] 的同族思路）
- 官方代码为 INRIA **非商业研究许可**，商用需授权
