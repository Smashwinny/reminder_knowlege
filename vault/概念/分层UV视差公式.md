# 分层UV视差公式

**一句话定义**：把一幅画拆成多层、每层按"带符号景深"沿视线方向平移贴图 UV——`uv' = uv + uView.xy / max(|uView.z|, 下界) × depth × 系数`——层越深同一个转头挪得越多，大脑就读出立体感。

**属于领域**：三维图形 / 卡面渲染（全息闪卡、光栅卡的网页等价物）

**通俗理解**：小时候文具店门口"会闪的卡"靠塑料透镜条纹换画面；网页版靠**层与层错开**：视线斜了，前凸层（depth>0）和后缩层（depth<0）的贴图各自平移不同距离，像抽拉贺卡。**两条铁律**：① 两层 depth 相同就"焊"成一张平面，立体感当场消失（skill 作者称之为卡片变扁的头号原因）；② 分母 `max(|uView.z|, 0.4)` 设下界，视线几乎平行卡面时不会除零爆炸。

**与已有概念的关联**：
- depth 必须带符号 + 两转向都要测：glTF Y-up 转换会动本地轴，uView 须在卡牌根坐标系算，否则一个转向拖花贴图或视差反相（[[glTF与GLB资产管线]]）
- "同一公式 Blender 与网页各写一遍"的另一半见 [[材质名契约重建]]
- 视觉目标是复刻光栅卡，与 [[三帧关键帧插画法]] 同属"用最小成本表达运动/立体"的素材工程
- 与 [[球面谐波视角色]] 同族：都是"颜色/位置随视角变化"，SH 是光照的连续函数表示，这里是显式公式
