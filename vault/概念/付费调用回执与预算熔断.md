# 付费调用回执与预算熔断

**一句话定义**：将每次付费请求的状态和结果持久保存，重试优先复用结果，并通过分钟/小时/日预算限制异常耗费。

**属于领域**：AI 应用 / 成本控制 / 可靠性。

**通俗理解**：买过的票留收据，任务断线后先查收据，不盲目再买；达到预算就停止继续购买。请求发出但结果未知时，还需要核对状态，不能保证零重复付费。

**源码来源**：AIHOT `packages/backend/src/providers/receipts.ts` 与架构文档。模型仅由后台任务调用，打开公开页面不触发付费请求。

**验证边界**：本次阅读设计，没有调用服务商、连接数据库或验证真实账单；不把架构说明写成“预算系统已在我的站点上线”。
