# 第三方工具数据流审计

**一句话定义**：评估中转/管理器时分别检查上游端点、凭据文件与流程、更新/外发通道和许可，再对照当前官方授权边界；静态命中不能冒充完整运行数据流。

**属于领域**：软件安全 / 供应链审查。

**操作要领**：固定 commit；只读扫描端点和凭据文件名；保存路径/行号/哈希；区分“引用 token 文件名”和“读取真实 token”。维护者 README 的“不碰凭据”也是待验证声明，需要源码、运行和发布包证据。官方允许的 API/企业路径应另查当前文档。

**与已有概念的关联**：[[证据优先质检ProofOverClaims]] 要求静态/运行证据分层；[[CleanRoom只读读取器]] 区分技术读取与授权；[[登录排查四层拆解]] 区分网络修复和协议/凭据访问。
