# 想象误差复利发散

**一句话定义**：自回归想象 rollout 中预测误差逐步输入自身，误差随步数复利增长，长程想象面目全非——是世界模型第一痛点，也是 Dreamer 正则/Cosmos 物理约束的对症目标。

**领域**：AI / 强化学习。来源：[[项目笔记/world_models_series]]（训练顺序 bug 对照实验：0.023→1.798）。

与 [[漂移与回环闭合]] 的无校正开环累积同构。完全确定玩具环境也会发散，真实物理/视频环境更快；必须分别报告单步精度和多步滚动稳定性。
