# 决策记忆结算反思闭环

**一句话定义**：把 agent 的每个决策先落盘为 pending 条目，等现实结果揭晓后回填结算数据（回报/超额收益），再让 LLM 把"决策+结局"浓缩成短教训，回注到未来同类决策的 prompt 里——给 agent 装上"经验值系统"。

**属于领域**：AI Agent 记忆系统 / 金融工程

**通俗理解**：交易员的复盘笔记本。每笔交易先记"我当时为什么买"（pending），到期后补一行"实际赚了还是亏了"（结算），再写一句"下次记住什么"（反思）。下次开仓前先翻旧账。TradingAgents 的实现是一个 append-only markdown 日志三步走：`store_decision` 写 `[日期|代码|评级|pending]`；结算后原子写回变 `[+3.1% | +1.2% | 5d]`（raw 回报|alpha 超额|持有天数）；Reflector 用 LLM 把结局压成 2-4 句教训。工程细节值得抄：**同 (日期,代码) 重复写入幂等挡掉**（防重复计数）、**temp-file + os.replace() 原子写**（崩了不坏账本）、**point-in-time**（反思只来自该日期前已结算条目，防未来函数）。
