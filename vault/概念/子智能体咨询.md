# 子智能体咨询

**一句话定义**：把本机已有的编程智能体 CLI（Claude Code / Codex / Kimi CLI 等）包装成一个工具 `consult_subagent`，让主 Agent 按需"请教"它——主 Agent 决定问什么，子智能体在自己机器权限内真跑真查，结果流式回传。

**属于领域**：Agent 工程 / 多智能体协作

**通俗理解**：主 Agent 是**会讲题的老师**，子智能体是**会动手的管家**。机制四件事（源码约 600 行，`capabilities/subagent/`）：① 自动发现——扫描 PATH 认出本机已装的智能体 CLI；② 工具化——往循环挂 `consult_subagent`，模型只填一个 `question` 参数；③ 无头运行——CLI 以非交互模式跑（Claude Code 用 `--permission-mode bypassPermissions`，绝不卡在授权确认上），中间步骤实时流式显示；④ 咨询预算——每轮最多咨询 5 次（可调 1~12），用完工具拒绝并要求主 Agent 自己作答；同轮多次咨询共享子智能体会话，上下文连续。**关键安全边界**：子智能体只能看到它的内容工作区，工作区外的文件它真的够不到（本机实测验证）。
