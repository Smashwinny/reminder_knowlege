# 能力运行时

**一句话定义**：让多种功能（讲题/出题/研究/画图…）共享同一个 Agent 循环的架构——每种功能是一个"能力"插件包（提示词 + 工具集 + 上下文声明），由注册表统一挂载，即插即用。

**属于领域**：LLM 应用 / 软件架构

**通俗理解**：普通 AI 应用像"**每道菜一个专用厨房**"，功能之间记忆不通、上下文不通；能力运行时是"**一个中央厨房**"——[[Agent循环]] 是唯一的心脏，切功能只是换挂载的工具和提示词，循环本身不换。判断标准：一个应用是否 agent-native，看它加新功能是"再写一条流水线"还是"注册一个能力"。DeepTutor 源码落点：`deeptutor/capabilities/<名字>/`，每个含 `protocol.py`（声明需要什么）+ 提示词 + 工具挂载逻辑，`registry.py` 统一管理。

**与已有概念的关联**：

- 进化：[[构建流水线与Pass]]（把"固定阶段"升级成"可插拔标准件"）
- 实例：[[子智能体咨询]]（subagent 本身就是一个 capability）
