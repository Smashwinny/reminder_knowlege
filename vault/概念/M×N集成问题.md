# M×N 集成问题

**一句话定义**：M 个应用各自对接 N 个工具时需要 M×N 套定制代码；引入统一协议后降为 M+N（各实现一次协议端点）。

**属于领域**：软件工程 / 协议设计。

**通俗理解**（比喻/例子，讲完落回术语）：
就像充电口：诺基亚时代每个手机一个专用充电器（M×N），USB-C 统一后一根线走天下（M+N）。HTTP、USB、蓝牙、MCP 的取胜逻辑相同——**先统一语言，再谈连接**。判断"某领域是否需要一个新协议"的信号：对接组合数随双方数量相乘增长、且双方都愿意为标准化让出一部分灵活性。[[MCP模型上下文协议]] 正是为解决 AI 应用与工具之间的 M×N 问题而生。
