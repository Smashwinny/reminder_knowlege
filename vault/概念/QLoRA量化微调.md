# QLoRA量化微调

**一句话定义**：LoRA 的省显存升级版——基座权重以 4bit（NF4）而非 bf16 载入显存，训练时临时反量化计算，梯度与优化器状态仍只落在 LoRA 的 A、B 小矩阵上；论文级成果是 48GB 单卡微调 65B 模型。

**属于领域**：AI / 模型微调。

**通俗理解**（比喻/例子，讲完落回术语）：LoRA 已经只调旋钮，但"主机"还得整个搬上桌（bf16 权重全进显存）。QLoRA 把主机拆成压缩包搬运（4bit 存储），要用哪块零件现场解压（反量化前向），精度靠三件套撑住：NF4（为正态分布权重设计的 4bit 编码）、双重量化（连量化常数本身再量化一次省显存）、分页优化器（显存峰值时把优化器状态临时挪到内存防 OOM）。显存账单：7B 全参微调 ≈ 112GB → LoRA ≈ 14~16GB → QLoRA ≈ 4~6GB。

**与已有概念的关联**：

- 相关：[[量化与GGUF]]（同一个"有损压缩权重"思想的两用：GGUF 为推理装得下、QLoRA 为训练装得下）
- 相关：[[本地推理引擎]]（消费级显卡玩大模型的同一前提）
