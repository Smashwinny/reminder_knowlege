# 确定性图布局

**一句话定义**：图节点的位置由纯几何规则（占比→扇区角度、连接度→环半径）算出，不做物理模拟、不用随机种子——同样的图永远画出同一张画。

**属于领域**：数据可视化 / 图布局算法

**通俗理解**：力导向布局像让一群人站在光滑冰面上互相推挤，最后"力气平衡"时停下——每次队形都不一样，还可能挤成一团；确定性布局像体操队列表：每个人按规则表站固定点位，排练一千次队形不变。代价是牺牲"自然感"，换来三样东西：**可复现**（同一数据同一图）、**可学习**（看一周能记住"我的概念都在橙色大扇区"）、**可比较**（两张截图能逐点对比）。Vault Graph 实测同一 vault 每次生成 756KB 产物中布局完全一致。

**与已有概念的关联**：
- 是 [[确定性脚本]] 思想在可视化上的直接延伸：输入相同则输出相同，图形才能当"事实"被引用
- 相关：[[原子笔记与双链]]（双链图是它的典型输入）；[[JSONL事件日志与折叠模型]]（zoetrope 的流动图也强调可回放的事实底座）
