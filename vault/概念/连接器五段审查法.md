# 连接器五段审查法

**一句话定义**：安装社区连接器前分别核对 Auth、catalog_hosts、Operating Rules、Files 和 Maturity；结构完整只是审查起点，不等于安全、可运行或兼容。

**属于领域**：Agent 技能 / 供应链与权限。

**五段**：凭据流程与 HTTP 头；允许主机；写操作确认与禁止行为；实际文件清单；Draft/特定命令 Live-tested 证据。Live-tested 只覆盖所列命令、日期与环境，不能升级为“整个工具已验证”。缺失段应显式标出，模板不应计为连接器。

**与已有概念的关联**：[[四级验证编目法]] 区分编目和验证；[[健康探测三态]] 是运行观察，成熟度是维护者声明；[[技能路由器与授权硬门]] 提供机制层授权。
