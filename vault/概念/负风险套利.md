# 负风险套利

**一句话定义**：同时买入同一事件的 YES 股和 NO 股（或同一事件在两个平台的对价方向），当 **买入成本合计 < $1.00**（赔付固定值）时，无论结果如何都锁定正收益——推文里"不预测涨跌也能赚"的真身。

**属于领域**：金融量化 / 套利

**通俗理解**：两家里卖同一张"必中彩票"的拼图，左半张+右半张总价低于头奖金额，就闭眼全买。CloddsBot 的 `src/arbitrage/index.ts`（737 行）就是干这个：跨平台比价、算 `profitPer100`、打置信度、过滤后通知/执行。

**工程三件套**（缺一不可，缺了就是亏钱）：
1. **市场配对**：跨平台要先认出"两个市场说的是同一件事"——Jaccard 相似度海选 + LLM 终审（见 [[净边际与多跳套利环]] 同款"便宜粗筛+昂贵精判"分工）；
2. **净边际过滤**：毛边际 − 手续费 − 滑点，热门市场实测毛边际为负；
3. **风控拦截**："好得不像真"过滤（边际 >15% 多半是解析错误/币种错配）+ 流动性门槛。

**残酷实测**（cloddsbot ex1，2026-10-03）：Polymarket 前 25 热门市场全部 YES+NO ≥ 1.001（= tick 地板），0 个机会——缝隙被做市机器人 0.1 秒内搬走，散户拼的是速度与费率，不是运气。
