# AI 智能体 Agent

**一句话定义**：以 LLM 为大脑、以工具为手脚、以自主循环为驱动的程序——会说还会做。

**属于领域**：AI / LLM 应用

**通俗理解**：聊天机器人像电话客服（只动嘴，问→答→结束），智能体像有手有脚的助理（你交办一件事，它自己查、算、操作、汇报）。本质区别：智能体的输出可以是**工具调用请求**，由程序真正执行后把结果喂回大脑继续决策。落回术语：**Agent = LLM + Tools + 循环**（[[Agent循环]] 是它的心脏）。

**与已有概念的关联**：
- 内核循环：[[Agent循环]]；动手机制：[[LLM工具调用]]
- 同族思想：[[质检Gate与自我纠错循环]]——智能体的"执行→看结果→再决策"就是生成/检查/修正循环；区别是裁判从确定性脚本变成了 LLM 自己
- 延伸形态：[[多智能体协作]]（分工组队）、常驻智能体（定时/事件驱动，如每日 HN 日报）、语音/生成式 UI 智能体
- 配套：[[RAG检索增强生成]]（给它私有知识）、[[MCP模型上下文协议]]（给它标准化的外部工具插座）、[[AgentSkills技能包]]（给它方法论）
