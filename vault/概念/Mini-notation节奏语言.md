# Mini-notation节奏语言

**一句话定义**：Strudel/Tidal 用一行字符串描述节奏的微型语言：`"bd sd hh*4 [bd ~] <c3 e3>"`，空格顺次、`~`休止、`*`重复、`[]`细分分组、`<>`逐循环交替、`(3,8)`欧几里得节奏。

**属于领域**：领域专用语言（DSL）、音乐记谱法。

**通俗理解**：它就是"数字简谱"——把鼓谱压缩成一行文本，8 个符号覆盖 90% 的节奏需求。像正则表达式之于文本，mini-notation 是节奏的正则。讲完落回术语：字符串被解析成 Pattern 对象（[[Pattern时间函数与Hap事件]]），再由声音引擎逐事件发声。

**要点**：
- 音符直接写音名+八度（`c3` `f#2`），鼓件沿用 Dirt 采样库缩写（bd=底鼓、sd=军鼓、hh=踩镲、cp=拍手）
- `bd(3,8)` 欧几里得节奏：3 声均匀撒进 8 格，数学上等价于众多世界传统节奏（如 clave）
- 因为是纯文本，**LLM 天然会写**——这是"用 Claude 做音乐"成立的根本原因
