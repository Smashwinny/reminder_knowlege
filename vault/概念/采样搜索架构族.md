# 采样搜索架构族

**一句话定义**：单条推理路不可靠，就高温采样多条路（Self-Consistency/Ensemble 投票选多数）或显式搜索解空间（ToT/LATS 按价值/UCB1 挑节点），用多样性换正确率的一类 Agent 架构。

**属于领域**：AI / LLM 应用（Agent 架构）

**通俗理解**：像考试检查——卷子从头重算三遍（采样），三回里两回得 391，就信 391（多数表决，确定性逻辑而非 LLM 拍板）。Tree of Thoughts 是把解建成树逐层展开打分，LATS 再引入蒙特卡洛树搜索的 UCB1（探索/利用平衡）+ 价值回传。关键前提：**错误要随机、正确要收敛**——3B 小模型可能 5 条采样集体偷懒输出同一个占位符（2026-10-03 实测），投票就失效；模型能力是地基，架构是楼层。
