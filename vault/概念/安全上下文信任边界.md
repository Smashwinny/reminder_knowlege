# 安全上下文信任边界

**一句话定义**：HTTPS、可信回环等条件只决定来源是否满足敏感 Web API 的安全上下文门槛，不证明页面内容、运营者或权限请求善意。

**领域**：Web 安全 / 身份与传输。来源：[[项目笔记/storm_breaker_defense]] 与 MDN Secure Contexts。

HTTPS 不等于网站可信；localhost/127.0.0.1 是开发例外而非恶意免疫区。回环服务仍需 Host/Origin、令牌和端口审计，与 [[本地MCP端点安全四道门]] 的请求侧加固互补；[[OAuth资源发现]] 的来源与元数据信任也需独立核验。
