# 词锚定语义时间

**一句话定义**：视频里的事件（字幕弹出、B-roll 插入、特效触发）不钉死在时间线的某一秒，而是**挂在内联台词的某个词上**——配音念到那个词，事件就在那个词的实际发声时刻触发；词的时刻由词级对齐（WhisperX）从真实音频测得。

**属于领域**：AI 视频生成 / 时间轴架构

**通俗理解**（比喻/例子，讲完落回术语）：传统剪辑像**按绝对时刻报时的火车时刻表**——"贴图 5.2s 飞入"，火车一晚点全盘乱套；词锚定像**报站名**——"到'发胶'这站弹发胶图"，车快车慢都到站才触发。Hypit 的写法是直接把锚点写进台词：`@{hair-gel} more hair gel than @{trophy} trophies`，两个事件各挂一个词。

**实测证据**（hypit 实验1/实验3，2026-10-03）：
- 官方 ranking-football/reference.svml（329 行）**硬编码秒数属性 = 0**，8 个词锚事件全部配对；语义时间模拟显示语速 160→130/190wpm 时锚点词时刻移动 0.4~2.6s——锚定秒数将全部错位穿帮
- Hypit 同时保留秒锚定作为选项：纯动画场景（semantic-composition 的聊天消息 at="0.5s"）没有台词可锚，就用绝对时间——**两种时间观并存，按"有没有词"选**

**与已有概念的关联**：
- 是 [[分镜表驱动生成]] 的时间维升级：分镜表把画面钉在"每帧记录"上，词锚定把画面钉在"词"上，配音一换表自动重排
- 与 [[补间动画与缓动函数]] 分工：缓动管"事件怎么演"（入场/出场曲线），词锚定管"事件何时演"
- 与 [[角色一致性锚定]] 同为 AI 视频的"锚定"家族：一个锚空间身份（脸不变），一个锚时间位置（点不偏）
- 是 [[机制流与资产流隔离]] 的触发器实现：资产（贴图/提示词）独立存在，词事件决定它何时进场
