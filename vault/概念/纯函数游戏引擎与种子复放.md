# 纯函数游戏引擎与种子复放

**一句话定义**：游戏引擎写成纯函数——输入旧状态 + 输入事件，输出新状态 + 事件列表；不读时钟、不碰网络、不存全局，随机数用自己的种子 PRNG。

**属于领域**：游戏开发 / 软件架构。

**通俗理解**：引擎像银行流水 fold（[[JSONL事件日志与折叠模型]]）：状态进、状态出。三个超能力：① 无头仿真——整局游戏用假输入在电脑上重放，调平衡不用出门（Deadrun 平衡仿真：雕像 2m16s 被抓、跑者+捡补给 13m11s）；② 确定性——同一种子复放同一局，bug 可复现；③ 时间旅行——暂停恢复时把所有绝对时间戳整体平移，敌人不会在你暂停时瞬移。
