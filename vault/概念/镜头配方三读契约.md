# 镜头配方三读契约

**一句话定义**：先用 Gallery 索引校验卡名与 style-key，再读配方卡的意图、参数与命门，最后按“参考实现”读取准确 demo TSX；卡片是语义地图，demo 才是调校参数真相。

**领域**：AI / 视频 / 动效资产工程。来源：[[项目笔记/video_shotcraft]]（124 卡/150 镜头目录与 pipeline 阶段 5）。

它避免只凭卡名或风格形容词生成镜头，与 [[风格即渲染器]] 的“学机制而非逐像素复刻”一致；与 [[证据优先质检ProofOverClaims]] 和 [[补间动画与缓动函数]] 的参数级验证配套。
