# 默认姿态审计

**一句话定义**：接入交易、支付、外发等高风险能力前，先查清不传任何可选参数时的默认行为，并识别看似真实但仅为占位符的配置值。

**属于领域**：AI Agent / 安全配置与授权。

**案例**：固定 OKX preflight 文档中，OAuth profile 没有 demo 字段，省略 `--demo` 即实盘；`not_logged_in` 时的 `site="global"` 是默认占位，不代表用户选择。API key 优先于 OAuth，也不能从 auth 内部 apiKey=false 推断 config 中没有 key。

**与已有概念的关联**：[[沙箱与审批正交]] 区分模拟环境与行动批准；[[资金操作四步纪律]] 把默认姿态放在写操作之前；[[证据优先质检ProofOverClaims]] 要求用合成状态验证默认值和优先级。

**验证边界**：[[项目笔记/cue_okx_skills]] 只验证文档规则的合成模型，未证明真实 CLI 在最新版本或所有异常分支中的行为。
