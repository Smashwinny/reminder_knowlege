# 单二进制自托管架构

**一句话定义**：把平台全部功能（API、代理、后台任务、分析管道）静态链接进一个可执行文件，唯一外部依赖是一个数据库——部署面从"N 个容器"缩到"1 个文件 + 1 个库"。

**属于领域**：软件架构 / 自托管部署（Temps、Windmill、PocketBase 是三种语言下的同一物种）

**通俗理解**（比喻/例子，讲完落回术语）：传统自托管像开合租房——七个室友（容器）分摊房租但天天闹矛盾（升级/备份/网络互相踩）；单二进制是"一人一居":除了银行账户（Postgres）什么外置依赖都没有,搬家=拷一个文件。落回术语：**模块化只发生在源码层（94 个 Rust crate 各管各的），不发生在进程层（运行时只有一个 PID）**。Cargo workspace 静态链接让"工程上好维护"与"运维上零拼装"兼得。

**实测证据**（Temps，2026-10-03）：workspace 94 crates 分 9 大领域；4 个 `main.rs` 目标但发布产物单一 `temps` 二进制，18 个子命令（serve/proxy/migrate/join/agent/node/network/edge/sandbox/firecracker…）；官方 deploy.sh（4418 行 TUI）只装两样：GitHub Releases 的 temps 二进制（systemd 托管）+ timescale/timescaledb-ha:pg18 容器。
