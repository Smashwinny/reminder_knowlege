# 构建流水线与 Pass

**一句话定义**：把一件复杂工作拆成一串顺序执行的阶段（Pass），每个阶段只做一件事、产出明确的中间结果，后一阶段在前一阶段的结果上继续加工。

**属于领域**：软件工程（同样思想见于编译器、图形渲染、图像处理）

**通俗理解**：像工厂流水线/做菜备餐：洗菜 → 切菜 → 炒菜 → 装盘，每步只管自己的事。img2threejs 把"从一张参考图到 Three.js 代码"拆成 **8 层 Pass**（探测图片 → 生成规格 → 校验规格 → 生成代码 → …），好处是：① 出问题时能定位到具体哪一层；② 每层可以单独测试、单独重跑；③ 中间结果（JSON 规格书）可以被检查。

- 同类思想：编译器的"词法分析→语法分析→代码生成"多阶段结构
