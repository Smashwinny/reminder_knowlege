# 护栏模式 Guardrails

**一句话定义**：在 Agent 的输入侧和输出侧各设一道安检门——输入防注入防敏感，输出做 schema 校验、白名单、越界拦截，坏内容根本进不了执行层——《Agentic Design Patterns》模式 18。

**属于领域**：AI Agent 安全

**通俗理解**：机场安检分两层：X 光机（确定性代码校验，一条都不能漏）+ 安检员目视（LLM 当护栏，能看懂语义但会疲劳漏检）。**确定性校验永远在 LLM 护栏外面**——代码是底线，模型是补充。

**实验实测**（pydantic 协议门）：越权工具名 `delete_db` 被正则白名单拒收；置信度 1.7 被 `Field(le=1)` 拒收；拒收理由（ValidationError 文本）直接回流给模型带错重试，第三次合法调用放行。
