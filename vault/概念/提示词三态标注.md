# 提示词三态标注

**一句话定义**：把提取到的提示词分为 original（原帖原文）、brief（简介级）和 unknown（未知）三态，禁止用“有简介”冒充“拿到原配方”。

**领域**：AI / 提示工程。来源：[[项目笔记/awesome_ai_motion]]（original 244、brief 233、unknown 1251）。

它是 [[提示词逆向工程]] 提取物的状态管理，与 [[证据状态机]] 共享“事实与未知分层”的原则。只有 original 可逐字引用；brief 只能作为线索，unknown 不应被补写。
