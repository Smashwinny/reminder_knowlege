# 交易成本与鞭打效应

**一句话定义**：策略信号越频繁，每次进出场都要付手续费/承受滑点，这些成本像砂纸一样磨掉利润；震荡市里快均线反复金叉死叉"鞭打"（whipsaw），亏得比趋势捕捉赚到的还多。

**属于领域**：金融量化 / 策略评估

**通俗理解**：实测数据（NautilusTrader AUD/USD 9.98 万 tick，EMA 交叉，maker/taker 手续费 2e-5）：均线 5/10 → 145 信号、手续费 388.62 USD、亏 883.62；10/20 → 85 信号、227.82、亏 526.82；20/60 → 32 信号、85.76、亏 326.76。周期砍半，信号数和亏损都接近翻倍——**成本结构才是高频策略的第一道生死线**，信号多不等于赚钱多。教学策略 EMACross 官方明说 "has no edge"，价值在于让你先看清成本，再谈 alpha。
