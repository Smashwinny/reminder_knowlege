# 漂移与回环闭合

**一句话定义**：漂移（drift）= 逐帧接力估计位姿时每步的小误差不断叠加，轨迹越走越偏；回环闭合（loop closure）= 检测到"重访来过的地方"时，用这个重合硬约束把累积误差一次性摊掉。

**属于领域**：机器人 / SLAM / 三维重建

**通俗理解**：像蒙眼走路靠"每步迈多大、转多少度"数步子——每步差一点点，走一公里能偏出几十米（本机仿真：每帧航向误差 0.05°，一万帧终点漂 203 m，五万帧 735 m，随机游走式无界增长）。回环闭合就是你绕小区走回大门口那一刻发现"咦这不是刚出发的地方吗"，把一整圈攒的账一口气清了（仿真中终点误差 203 m → 3 m，且多圈不清账会滚雪球、清账则始终有界）。工程实现是**位姿图优化**：里程计边（相邻帧约束）+ 回环边（重访帧约束）组成图，加权最小二乘让所有约束同时尽量满足。ABot-Recon 用 DINOv2-SALAD "地点指纹"找重访帧，再让模型自己预测这两帧的相对位姿当回环边。

**与已有概念的关联**：
- 误差源治理：ABot-Recon 的"运动-视觉旋转精修器"先压每步误差（源头），回环兜底（终点）
- 组合数学同族：[[正运动学向量接力]]（也是变换逐级相乘、误差逐级传播）、[[前向运动学FK与四元数链]]
- 检索依赖：[[向量与Embedding]] 思想（SALAD 地点描述子本质是图像→固定向量的编码）
