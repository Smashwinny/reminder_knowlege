# 共享环境非隔离原则

**一句话定义**：多 Agent 共用一台机器或账户时，各自的屏幕/会话视图不构成安全边界；敏感文件不放共享盘，分信任级别要分账户/分机器，回收权限要同时移出团队并撤销会话。

**领域**：AI Agent / 安全。来源：[[项目笔记/grok_bot_method]]（官方原文“Do not use separate Bots as a security boundary”）。

与 [[沙箱与审批正交]]、[[共享状态与Reducer]] 的风险面互链。terminate 机器或关闭界面不等于撤销账号权限；真正的收权还需管理组成员和 IdP 会话。
