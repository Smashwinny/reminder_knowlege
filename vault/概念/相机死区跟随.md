# 相机死区跟随

**一句话定义**：地图相机不焊死在玩家身上，屏幕中央留一个死区盒子（如 16%×12%），玩家在盒内移动时地图不动，顶到边缘地图才"推回"——延迟跟随反而让系统状态可见。

**属于领域**：移动开发 / 地图交互设计。

**通俗理解**：焊死的相机下，"GPS 完美"和"GPS 完全死了"长得一模一样（箭头都静止在正中央）。留死区后，"我自己在屏幕上动"成了最直观的传感器健康指示器：fix 一断，你立刻看见自己不动了。相机是输入状态的可视化仪表盘。

**与已有概念的关联**：
- 相关：[[Web墨卡托与瓦片金字塔]]（相机决定拉哪些瓦片）、[[环境显示与触屏Agent面板]]（ambient display 思想：状态在你余光里，不用你去查）
- 实现要点：纯函数 `followCamera(相机, 玩家, 屏幕)` 返回新相机；不动时返回原对象，React 靠引用相等跳过重渲染
