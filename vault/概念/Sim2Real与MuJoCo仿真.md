# Sim2Real与MuJoCo仿真

**一句话定义**：sim2real = 在物理仿真器里训练机器人策略，再迁移到真机运行；MuJoCo 是 Google 出的物理仿真器，其场景描述格式叫 MJCF（XML）。

**属于领域**：机器人学 / 强化学习

**通俗理解**：先在游戏里练级再上真人赛场。仿真器是"物理考场"——鸭子摔一万次不要钱；真机摔一次可能就坏。关键坑：仿真太"完美"会导致策略到真机水土不服，所以训练时要故意加噪声（改摩擦/质量/延迟），即**域随机化**，让策略学会"容忍不完美"。训练 MJCF 有个反直觉之处（microduck 实测验证）：`kinematics/assets/alpha/robot_walk.xml` 只有骨架（15 关节+惯量，**无地板无执行器**，丢进仿真 0.24s 掉 0.285m ≈ 精确自由落体）——模型文件只描述机器人，"世界"是训练场景额外给的。

**与已有概念的关联**：
- microduck 管线：MJCF 建模 → PPO 训练 → 域随机化 → 导出 ONNX 模型 → robotd 50Hz 加载运行
- 训练出的策略像 App 一样分发，契约思想同 [[MCP协议]]（见 [[机器人守护进程架构]]）
