# 前向运动学FK与四元数链

**一句话定义**：前向运动学（FK）= 已知每个关节的角度，沿运动链逐级折叠变换，算出脚/头等部位在空间中的位置；旋转用四元数（w,x,y,z 四元组）表示以避免万向锁。

**属于领域**：机器人学 / 三维数学

**通俗理解**：像叠路条——"从髋关节出发，大腿长 5cm、转 30°，再小腿长 4cm、转 -20°……"一路加到脚尖。每一节是"先平移再绕轴转"，四元数负责把"绕某轴转 θ°"变成可乘的四个数。microduck 的坑与亮点：MuJoCo 引擎太重不适合 50Hz 控制环里反复问"脚在哪"，官方用 Rust 把 MJCF **编译**成每条 site 的固定变换链，查询一次就是一次链式折叠——不查哈希、不分配内存；正确性用 64 随机姿态对拍 MuJoCo 官方 `mj_kinematics` 钉死（`fk_against_mujoco.rs`）。我用 Python 手写同样算法对拍：64 姿态 × 4 部位最大误差 1.8×10⁻⁷ m。

**与已有概念的关联**：
- 四元数旋转与 [[Three.js与场景图]] 的父子层级变换同一数学：都是"局部变换沿树折叠成世界变换"，FK 就是只含旋转关节的场景图求值
- [[参数曲面采样]] 同属"用公式精确算出每个点位置"的思想
