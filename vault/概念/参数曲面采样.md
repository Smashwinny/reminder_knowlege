# 参数曲面采样

**一句话定义**：用带参数的方程描述一个三维表面，在参数范围内随机/均匀撒点得到表面点云——"不加载模型文件，公式本身就是模型"。

**属于领域**：计算机图形学 / 数学建模

**通俗理解**：[[程序化建模]] 是"写菜谱不捏泥人"，参数曲面是其中最细的写法——细到**表面每个点的坐标都有公式**。像给地球每一点写"经度+纬度"两个坐标就能定位：一张曲面也只需要两个参数（如花瓣的 t=沿瓣长、s=沿瓣宽），映射函数 (t,s)→(x,y,z) 就是整张曲面。想要"玫瑰感"，就在映射函数里做四件事（粒子玫瑰实测公式）：**中心线弧线**（瓣根竖直→瓣尖外翻的 α 角过渡，包心结构的来源）、**瓣宽包络**（根窄-中宽-尖收，宽度∝2π/瓣数留缝隙）、**横向内折**（s² 项，勺状瓣面）、**瓣尖上卷**（tip² 项，点睛之笔）。

**适用场景**：花瓣/贝壳/缎带/螺旋星系等"有数学骨架"的形体；不规则形体（人物、建筑）则退回网格文件或雕刻。

**与已有概念的关联**：
- 相关：[[程序化建模]]（参数曲面是程序化建模的连续曲面特例："泥人"→"菜谱"→"逐点公式"）
- 相关：[[粒子系统]]（公式算出的点云正是粒子的目标点；换一套公式=换一个作品）
- 相关：[[确定性脚本]]（公式是纯函数，天然确定可复现）
