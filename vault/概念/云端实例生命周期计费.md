# 云端实例生命周期计费

**一句话定义**：按量 GPU 实例从开机到关机持续计费，与进程是否实际运行无关；付费磁盘关机后仍计费。省钱大头是生命周期管理，而非单纯比较每小时单价。

**领域**：AI / 成本工程。来源：[[项目笔记/qwen_image_21]]（AutoDL 官方计费文档核对）。

建议按“无卡下载→有卡推理→关机→释放磁盘”组织工作流，并记录 [[付费调用回执与预算熔断]] 所需的版本、显存峰值、通道、耗时和费用。停止 Python 进程不等于停止计费，关机也不一定让存储费用归零。
