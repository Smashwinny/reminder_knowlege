# 风格即渲染器

**一句话**：每种艺术风格可解构成三元组——程序化渲染器（怎么画）+ 母题动作（画怎么活）+ 签名转场（怎么进入它）——解构成代码配方后，没见过的风格也能照公式产出，且种子化随机保证可复现。

**领域**：程序化艺术 / AI 视频生成。来源：[[项目笔记/huashu_art_motion]]（huashu-art-motion skill 6/6 结构断言验证）。

三元组拆解 + 一帧先行工作流（静态帧过关再谈动）；五层机制（场景骨架×活的画×签名转场×节拍网格×叙事锚）。

频道级视觉语法（9 种解说语法）比"风格"更细，是可参数化（JSON spec）的可组合单元。

质量诚实标注法：星级+当前短板自我披露，是知识工件可信度的加分结构。

反模式：逐像素复刻（应学机制）；忽略角色一致性（普遍短板）；把 skill 目录营销数字当质量证据。
