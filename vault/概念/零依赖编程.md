# 零依赖编程

**一句话定义**：只用语言自带的官方标准库（如 Python 3.10+ 自带模块），不安装任何第三方包。

**属于领域**：软件工程 / 工程实践

**通俗理解**：装第三方包像"每做一道菜都要先进口一种外国调料"——环境坏了、版本冲突了、断网了都做不了菜。零依赖像"只用家里常备的盐和油"：把代码拷到任何一台有 Python 的电脑上直接就能跑。img2threejs 全部 forge 脚本零依赖，实测在 Windows 11 + Python 3.14 上开箱即用。代价是有些功能要自己手写（比如它自己写 PNG 解码），换来的是极强的可移植性。
