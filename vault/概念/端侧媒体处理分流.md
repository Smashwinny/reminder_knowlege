# 端侧媒体处理分流

**一句话定义**：通过请求偏好和实例策略，在服务端 FFmpeg 与客户端 libav.js 之间分配 merge、remux、mute、audio、gif 等媒体处理工作。

**领域**：媒体工程 / 前后端协同 / 边缘计算。来源：[[项目笔记/cobalt_tools]]。

`localProcessing=disabled/preferred/forced` 表达客户端意图，`FORCE_LOCAL_PROCESSING=never/session/always` 表达实例策略；最终响应还受动作类型约束。localProcessing 不是“是否下载到本地”的同义词，而是“合成/转码在哪里执行”。与 [[能力层与后端路由]] 互链。
