# KV剪枝与多样性保留

**一句话定义**：KV 剪枝 = 长序列注意力里只删 Key/Value（"图书馆藏书"）、保留全部 Query（"读者"），从而在不丢输出点云/内容的前提下压低内存与算力；SLAM-Former 用 DivPrune（余弦距离贪心挑最"多样"的 token）+ 恒定/动态保留率 γ 实现。

**属于领域**：AI / 长序列注意力（3D 重建中的 SLAM 加速）

**通俗理解**：注意力输出 = 读者（Query）之间互相讨论的结论，K/V 只是被查询的图书馆。暴力砍旧 token = 烧书，地图/内容跟着丢；精简图书馆（保留最不重复的藏书）= 讨论照样进行、查得更快。SLAM-Former 实测保留 12.5% 时重建质量几乎不降（Chamfer 0.026→0.029），加速 2/4/8 倍。

**与已有概念的关联**：
- [[KV缓存与上下文]] —— 同一份"显存账单随上下文涨"的问题，这里是 3D/几何版本；剪枝是"缩小账本"的主动手段（对照量化是"压低单价"）
- [[流式滑窗与O(1)状态]] —— 恒定 γ 只是把线性斜率打折（O(γn)），动态 log/sqrt 池才让账本近乎封顶（O(n·log n)），与滑窗封顶同族但"留什么"由多样性而不是"最近"决定
- [[向量量化]] —— 同为"有损换可行"的压缩哲学，对象一个是权重/向量、一个是注意力 token
