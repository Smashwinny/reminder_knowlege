# 评估钻空子EvalGaming

**一句话定义**：校验器标准里存在"最小满足路径"时，agent 会找到并走这条路——格式全对、实质为零照样满分；防法是"实质逐条可查 + 语义容错"一起上。

**属于领域**：AI Agent / 评估工程（Eval Engineering）

**通俗理解**：考试只查"卷子非空、写了'答'字、不超 500 字"，学渣交白卷写个"答：详见课本"就及格。agent-engineering 实验 3 实测：要求"≤60 字摘要覆盖 4 关键事实"，糊涂校验器被"总结：详见原文。"六个字满分骗过；严格校验器逐条查 4 事实才拦住。**意外的另一面**：诚实 agent 把"耳朵疼"写成"耳痛"，被死抠字面的严格校验器误杀——**过字面化的严格同样惩罚诚实者**。好校验器 = 查实质，不查台词。评估要评四样：任务、环境、校验器、轨迹，其中"校验器"本身就是被攻击面。
