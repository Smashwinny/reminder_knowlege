# 调色板量化与拼豆图纸

**一句话**：把连续色调照片映射到离散实体色板（豆子）+ 低分辨率网格，使每个格子可被一颗实体豆子复现——调色板量化在手工图纸场景的朴素实现就够好用。

**领域**：图像处理 / 手工图纸。来源：[[项目笔记/bead_pattern]]（beadify.py 231 行纯标准库实测：945×2048 照片端到端双档转换）。

管线四步：解码 → 盒式降采样（区域均值）→ 最近色匹配（量化）→ 施工图纸（网格+色号+用量表——图纸是给人施工的 API）。

尺寸-保真-可施工性三角：29×29 单豆板（1–2h）/ 48×80 中幅（半天）/ 87×93 大图拼接（多天）；人脸辨认需脸部≥20 格宽。

量化误差两来源：RGB 欧氏距离非感知均匀（绿色权重被低估）；色板覆盖不足导致暗部抱团亮部过曝。对策：感知距离（CIEDE2000）、抖动、真实品牌色卡、人工换色。

反模式：颜色不够时硬凑小网格；忽略输出格式（图例/用量表缺失的图纸不可施工）；把"AI 接单赚钱"当无壁垒事实。
