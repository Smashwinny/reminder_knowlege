# 显式控制权交接协议

**一句话定义**：接管与交还应是显式状态转换，并记录控制者、原因、状态、必要的本地快照与审计轨迹；非法交接和红线动作要 fail-closed。

**属于领域**：AI Agent / 人机协作 / 治理。

**操作要领**：只有允许的状态能 takeover/handback；交还时附交接说明；红线可从执行态或人工态进入 STOPPED；若协议声称有快照或落盘，就必须有真实数据和持久化/重载证据，不能只打印一句“已保存”。

**与已有概念的关联**：
- [[人机协同Interrupt]]：都涉及人工介入，但 takeover/handback 不等于 LangGraph interrupt/resume。
- [[Checkpoint存档与持久执行]]：本地快照可借鉴恢复思想，但不同产品未必提供相同功能。
- [[Handoff交接简报续跑]]：本概念管控制权，后者管跨会话上下文。
- [[岗位契约四件套]]：红线和交接应前置到岗位协议。

**验证边界**：[[项目笔记/chatgpt_dots]] 的 JSON 快照/审计/红线是本地自写协议，8 项测试通过；2026-11-22 Dots 官方只确认 takeover/return control，未文档化快照恢复。
