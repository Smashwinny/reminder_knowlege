# 同源可编辑视频清单

**一句话定义**：Main 与 `src/workbench.ts` 共享 SHOTS/SFX/CAPTIONS，镜头以 component+props+schema 拆成可编辑多轨，并以 original/imported 同帧像素对照证明拆解无损。

**领域**：AI / 视频 / 编辑工程。来源：[[项目笔记/video_shotcraft]]。

它把 [[分镜表驱动生成]] 的数据时间轴、[[JSON-IR类型化中间表示]] 的结构化中间表示和 [[React逐帧视频渲染]] 的执行器连接起来。清单结构通过不等于浏览器 UI 或官方 parity 通过；本实验仅验证真实清单执行与同源数据契约。
