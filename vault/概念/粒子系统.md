# 粒子系统

**一句话定义**：把成千上万个点各自当作独立演员、用同一套时间函数驱动其位置/颜色/大小的群体动画技术——每个粒子有"起点"和"终点"，动画就是从前者到后者的插值。

**属于领域**：计算机图形学 / Creative Coding

**通俗理解**：像"团体操开幕式"——每个演员（粒子）拿着自己的座位号（目标点）从广场随机位置（起点）走到自己的位置；导演（全局进度 uProgress）只喊一个 0→1 的数，几千人同时听着这个数按自己的节奏走。两个灵魂细节：**每个演员有随机延迟**（像潮水此起彼伏，不是齐步走）、**缓动函数**（起步慢-中段快-到位刹车，机械感变生命感）。

**实现要点**（particle-rose 实测）：
- 起点双缓冲：`aStart`/`aTarget` 两个顶点属性常驻显存，JS 每帧只更新 1 个 uniform（进度），GPU 顶点着色器并行算 `mix(start, target, ease(p))`——3.4 万粒子稳 60 帧
- 加法混合（AdditiveBlending）+ 软边圆点 + `depthWrite:false` = 免费的辉光层次；调参心法：单粒子刻意调暗，合叠才亮
- 固定随机种子（mulberry32）→ 粒子云 100% 可复现，参数实验才有对照意义

**与已有概念的关联**：
