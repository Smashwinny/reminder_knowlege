# 新视角合成

**一句话定义**：给一组从不同角度拍摄的场景照片，合成出**从未拍过的新机位**下该场景照片级画面的技术。

**属于领域**：计算机视觉 / 三维图形

**通俗理解**：像"给场景造一台时光机"——拍一圈照片，之后任何人都能在手机上重走拍摄现场的任意机位。灵隐寺高斯孪生、古戏台 3D 地图，本质都是"新视角合成 + 实时渲染"的文旅落地。

**技术路线演进**（为什么 3DGS 是分水岭）：
- 传统 mesh 重建（摄影测量）：照片→点云→三角面片+贴图；反光/半透明/植被重建差
- NeRF（2020）：MLP 隐式辐射场，逐光线采样查网络；质量好但**渲染秒级/帧**
- [[高斯泼溅3DGS]]（2023）：显式椭球 + 光栅化；质量持平或更好且**实时**——把表示从"隐式查询"换成"显式泼溅"

**与已有概念的关联**：
- 相关：[[高斯泼溅3DGS]]（当前最强实时路线）、[[球面谐波视角色]]（视角相关外观）
- 前端"建"的新流派：[[点图与前馈重建]]（ABot-Recon 秒级出轨迹+点云，可当 3DGS 的上游）
- [[证据优先质检ProofOverClaims]] —— 思想同构：3DGS 训练就是"渲染出来和真照片对比"的证据闭环
