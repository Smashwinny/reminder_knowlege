# 运镜四要素工单

**一句话定义**：把运镜意图拆成稳定方式、空间路径、观看视角、时间结构，并可补事件触发点，以结构化参数减少“电影感”等模糊描述的歧义。

**属于领域**：AI 视频 / 提示工程 / 验收设计。

**操作要领**：写清手持/稳定器/固定机位，推拉摇移环绕的路径，POV/FPV/俯瞰等视角，以及单镜头时长和动作交接；需要事件锚时写“当主体抬手时镜头上摇”。一镜头一主运动是保守起步策略，不是已测得的硬上限。文本更明确不等于模型必然执行。

**验收**：连续镜头可检查起终点、路径节点、主体尺度、触发动作和剪切点；Dolly Zoom 要同时满足主体尺度基本恒定与背景透视明显变化，只看出缩放不算通过。

- [[PromptAsCode提示词即代码]]：结构槽位可参数化、编译和断言。
- [[提示词方言适配]]：跨模型时负向等能力假设需转换。
