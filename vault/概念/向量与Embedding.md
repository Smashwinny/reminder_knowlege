# 向量与Embedding

**一句话定义**：把一段内容（文字/图片/音频）用神经网络"压"成一串固定长度的数字（向量），这段数字代表内容在"意义空间"里的坐标。

**属于领域**：AI / 信息检索 / 表示学习

**通俗理解**：像地图坐标——两个点的 (经度,纬度) 接近，两地就真的近。embedding 模型给每段文本发一个 512 维（维度数由模型定死）的"意义坐标"，训练时模型见过海量文本，学会了把意思相近的内容放到相邻位置："猫吃鱼"和"小猫捕食鱼类"字面几乎不同，但坐标几乎重合。比喻讲完落回术语：向量本身没有人工含义，是模型从数据中学出的统计压缩坐标；**入库和查询必须用同一个模型**，否则坐标系对不上。

**与已有概念的关联**：
- 是 [[向量数据库]] 存储和检索的基本对象
- 是 [[RAG检索增强生成]] 第一步（问题要先向量化才能去库里检索）
- 衡量两个向量像不像用 [[余弦相似度]]
