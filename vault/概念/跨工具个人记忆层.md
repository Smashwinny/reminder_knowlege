# 跨工具个人记忆层

**一句话定义**：把散落在各 AI 工具（Claude Code/Codex/Cursor…）里的协作历史收敛成本机一份共享记忆库，任何 Agent 都能自动读写的"操作系统级个人上下文层"，代表实现是开源项目 Memmy（口号 "All AI remember the same you"）。

**属于领域**：LLM 应用 / 个人知识管理

**通俗理解**：各 Agent 自带记忆（CLAUDE.md、Cursor Rules）是"**每人自己的笔记本**"，换个人干活就得从头自我介绍；跨工具记忆层是"**团队共享知识库 + 专职图书管理员**"——管理员不只收藏，还自动抓取每轮对话、提炼策略、写成手册，谁需要就递上相关的十条。三个支柱：<span style="background:#FFD600;font-weight:bold">①扫描存量（直接读各工具本地历史文件）②Hook 增量（turn.start/complete 自动抓取新对话）③统一检索（换词也能找回）</span>。与 mem0（给开发者用的记忆 API）、MemGPT/Letta（自带记忆 OS 的单 Agent 框架）定位不同：它是"给你的全部 AI 工具装同一份记忆"。数据全在本地 SQLite，模型可全本地（Ollama + transformers.js 嵌入）。
