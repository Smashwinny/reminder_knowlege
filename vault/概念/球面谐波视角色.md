# 球面谐波视角色

**一句话定义**：定义在球面上的"傅里叶"——用一组系数（低阶给平均值、高阶给细节）表示一个随方向变化的函数；3DGS 用它让每个高斯的**颜色随观察视角变化**（高光、反射、闪烁）。

**属于领域**：三维图形 / 数学基础

**通俗理解**：给每个高斯发的不是"一个固定颜色"，而是"一份从任何角度看该是什么色的配方"：DC 项（0 阶）是平均色，45 个高阶项是修正细节。训练从 0 阶逐步解锁到 3 阶——先学大色块，再学高光（源码 `oneupSHdegree`）。

**与已有概念的关联**：
- [[向量与Embedding]] —— 同构思想：把连续函数（球面颜色函数/语义）离散成一串可优化数字
- [[高斯泼溅3DGS]] —— 它的外观建模组件；f_rest 45 项全置 0 也能渲染（只剩基础色，实验 1 即如此）
- [[LLM采样与温度]] —— 无关但同为"参数决定输出性格"：SH 阶数决定反光度，温度决定发散度
