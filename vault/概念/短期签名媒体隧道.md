# 短期签名媒体隧道

**一句话定义**：把媒体流处理计划短期保存，并用带身份、到期时间、HMAC 签名和解密参数的临时 URL 提供给客户端的流式代理入口。

**领域**：媒体工程 / Web 安全 / 临时资源管理。来源：[[项目笔记/cobalt_tools]]。

cobalt 隧道 URL 含 `id / exp / sig / sec / iv`；默认 TTL 90 秒；缓存的是上游 URL、文件名、头部和处理参数等元数据，不是长期媒体内容。签名篡改实测返回 401。与 [[缓存]] 关联时须区分短期元数据与长期媒体缓存。
