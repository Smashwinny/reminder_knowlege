# GPS朝向融合

**一句话定义**：GPS course（航向）告诉你正在"去哪"，罗盘（磁力计）告诉你正在"面对哪"；速度高于 ~1.4 m/s 信 course，低于信罗盘，两者都缺退化指正北。

**属于领域**：移动开发 / 传感器融合。

**通俗理解**：GPS 只在移动时才算得出 course，且慢跑以下基本是噪声；站着不动时 course 不存在，而且位置 fix 只在移动时上报——此时读 fix 里的 heading 会冻结在最后移动那一刻，雷达和方向箭头全部悄悄指向错误方向。罗盘永远可用但更噪。融合规则一句话：**跑动信 GPS，静止信罗盘，罗盘以 2° 节流独立上报**（不能等 fix 才更新，否则转身原地冻结）。

**与已有概念的关联**：

- 对照：[[漂移与回环闭合]]（SLAM 位姿漂移 vs GPS 朝向漂移，都是有界误差管理）

## Route Studio：保留历史阈值，收窄可用性表述（2026-10-06）
