# 逆运动学 IK 与 CCD 迭代

**一句话定义**：逆运动学（IK）是"给末端（脚尖/手指）目标位置，反算各关节角度"的问题；CCD（循环坐标下降）是最常用的近似解法——从末端往回逐关节"各转一点"，循环几轮就够到目标。

**属于领域**：机器人学 / 三维动画，是[[前向运动学FK与四元数链]]的对偶问题（FK：角度→位置；IK：位置→角度）。

**通俗理解**：FK 像"报出每节车厢加的偏转角，算车尾在哪"；IK 像"指定车尾要去的地方，回头问每节车厢该拐多少"。CCD 的笨办法很有效：先只转离目标最近的那节（踝），不够再转膝、再转髋，转完一轮再来一轮，每次都用 `atan2(轴·(v₁×v₂), v₁·v₂)` 算带符号夹角，并限幅（如每次 ≤0.14 rad）防关节抽搐。

**与已有概念的关联**：
- 对偶：[[前向运动学FK与四元数链]]（该笔记原注"逆运动学是下一站"，即本条）
- 应用载体：[[Three.js与场景图]]——浏览器里 `localToWorld` 取末端位置、`transformDirection` 转轴到世界系，迭代 10 次即收敛
