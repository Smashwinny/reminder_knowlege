# 本能学习与置信度评分

**一句话定义**：让 agent harness 自动"长经验"的机制——hook 观察每次会话，把重复出现的好行为提炼成一条条**原子本能（instinct）**，每条带 0.3~0.9 的置信度分，本能多了再聚类进化成正式的 skill/command/agent。

**属于领域**：AI 工具生态 / 编程智能体

**通俗理解**：像驯兽师不给马上课，而是每次它做对就轻轻记一笔。一条本能长这样：

```yaml
id: prefer-functional-style
trigger: "when writing new functions"
confidence: 0.7        # 见得越多分越高，低分不生效
domain: "code-style"
scope: project         # React 的习惯留在 React 项目里
```

**ECC v2.1 的关键设计**：
- **观察点**：v1 用 Stop hook（会话结束才提取），v2 改成 PreToolUse/PostToolUse 事件（100% 可靠）；分析由后台小模型（Haiku）做，不占主上下文
- **原子粒度**：不学"整个技能"，只学一条条小行为，进化路径是 instinct → cluster → skill/command/agent
- **项目作用域隔离**：按 git remote/路径哈希分桶，React 模式不会污染 Python 项目；同一模式在 2+ 项目出现才升为全局（`/promote`），防跨项目污染
- **"昨天日志变记忆"**：harness 每次醒来先注入积累的本能，这正是"harness 会越用越聪明"的落地形式

**与已有概念的关联**：
- 本能是 [[AgentSkills技能包]] 的"胚胎"：先低成本记小经验，攒够了才固化成 SKILL.md
- 接续 [[三层记忆]]：本能≈程序性记忆（怎么做），置信度≈记忆强度
- 观察依赖 hook 事件系统（[[Agent中间件]]），提取依赖 [[LLM工具调用]] 的后台委托
- 与 [[质检Gate与自我纠错循环]] 互补：Gate 管单次对错，本能管长期变好
