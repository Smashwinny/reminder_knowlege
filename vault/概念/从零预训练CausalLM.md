# 从零预训练CausalLM

**一句话定义**：从随机初始化的权重开始，让模型在海量文本上做"给前文猜下一个 token"（next-token prediction）的练习，用交叉熵损失 + 反向传播逐词把语言规律、事实知识和推理模式压进权重——这是大语言模型一切能力的起点。

**属于领域**：AI / 大语言模型（基础模型侧；区别于应用侧的 [[RAG检索增强生成]]、Agent 编排）

**通俗理解**：预训练像"无师自通地读完图书馆"——没有老师出题，规则只有一条：读到第 n 个字时猜第 n+1 个，猜错就罚。为了把这件事做到极致，模型被迫在隐藏向量里学会语法（什么词能接什么词）、常识（北京是中国首都）、推理框架（因为…所以…）。损失函数本身不智能，但把这个任务做到极致，统计规律就变成了能力。

**核心机制**（MiniMind 实测验证）：
- 目标函数：`cross_entropy(logits[:-1], labels[1:])`，标签就是输入本身右移一位
- 因果掩码保证预测第 n 个词时只能看 1..n，否则作弊（见 [[KV缓存与上下文]] 的因果注意力）
- 训练循环四动作：前向 → 反向 → 梯度裁剪（防爆炸）→ AdamW 更新 + cosine 学习率衰减
- 健康 loss 曲线：从 ln(词表)（随机瞎猜，6400 词表 ≈ 8.77）快速下降后趋缓；本机 RTX 4070 实测 625 步 7.36 → 3.91
- 训练成本公式：≈ 6 × 参数量 × token 数（浮点运算次数），这就是"小模型个人可训、大模型烧千万美元"的全部根源

**与已有概念的关联**：
- [[BPE分词器]]：预训练前先把文本切成 token，词表大小直接决定瞎猜 loss 的起点和嵌入层参数量
- [[RoPE旋转位置编码]]：预训练时给模型注入词序信息的方式
- [[MoE混合专家]]：前馈层的可替换结构，加大容量不加大算力
- [[知识蒸馏]]：预训练之后的"老师带学生"阶段；[[RLHF偏好对齐]]：之后的"学人类口味"阶段
- [[Agent后训练SFT与RL]]：SFT/RL 阶段的方法论（那边侧重 Agent 轨迹与可验证奖励，本概念侧重基础模型的语言建模起点）
