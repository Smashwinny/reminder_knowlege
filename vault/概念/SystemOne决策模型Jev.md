# SystemOne决策模型Jev

**一句话定义**：Jev 是 TypeSafe AI 2026-09-15 发布的"系统一"决策模型——不发任何文字，只对 state+questions 返回带校准置信度的类型化决策（Choice/Score/Noul 三原语）。

**属于领域**：AI / 决策模型（LLM 之外的"判断层"新物种，路由/审核/护栏场景）。

**通俗理解**：医院分诊台不需要主任医师坐诊——病人进门，分诊护士只回答"内科还是外科""急不急"两个判断，不开药。Jev 就是这个分诊台：大模型（医生）负责生成，Jev（护士）只负责"判断型工作"，毫秒级出结果，价格约为便宜 LLM 分类器的 1/26（官方口径：$0.042/百万输入 token、输出免费；100 万次决策 $21 vs Haiku $550；均未经独立验证）。

**三原语**：
- Choice：2~255 个预设选项里挑一个（模型路由）
- Score：2~10 级量表打分（复杂度/质量评分）
- Noul：校准真假概率（"这是不是注入攻击"）

**关键事实**：
- 闭源托管 API，无公开权重，不能本地跑；接入通道：TypeSafe 官方（白名单审核）、OpenRouter（typesafe/jev-1.13，不在 /models 列表里）、Vercel/Cloudflare/Netlify 各云网关；官方 Python/JS SDK 开源，支持 TYPESAFE_BASE_URL 改指向（mock 实验的接缝）
- 局限：不能写/总结/编码，只能" complement "大模型；类型安全 ≠ 事实正确（可以自信地错）；路由需把用户 prompt 发到 TypeSafe 云端（隐私敏感场景要掂量）
