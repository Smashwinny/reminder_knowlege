# 提示词配方真源（STYLES.md 模式）

**一句话定义**：把多套成品提示词模板收进单一 Markdown 真源（代码块+槽位声明），渲染脚本、Skill 入口和 Agent 规则只从真源机械提取，避免文档与实现两份拷贝漂移。

**领域**：AI 工具生态 / 提示工程。来源：[[项目笔记/hand_drawn_styles]]（23 配方、116 别名实测）。

与 [[PromptAsCode提示词即代码]] 的版本化资产思想同源，侧重单一真源与机械提取；渲染器可用 [[确定性脚本]] 实现，槽位完整性由 [[槽位 fail-closed 渲染]] 保证。
