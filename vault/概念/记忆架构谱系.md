# 记忆架构谱系

**一句话定义**：解决"LLM 上下文有限、任务结束就失忆"的一类 Agent 架构——管的是记忆的存取策略与跨任务沉淀，而不是记忆的存储介质。

**属于领域**：AI / LLM 应用（Agent 架构）

**通俗理解**：[[三层记忆]] 规定了书放哪几层（L1 轨迹/L2 摘要/L3 画像），记忆架构族给的是**管理员**：MemGPT 把上下文当操作系统内存——Context 是内存（有限、FIFO 挤出）、Archival 是硬盘（向量库），Agent 用函数调用自己决定何时倒腾；Voyager 每完成一个任务沉淀一个"技能"（带文档的代码片段）进技能库，新任务先查库复用，不会就现写——终身学习越做越强；Graph Memory 用知识图谱存"谁和谁什么关系"，Episodic+Semantic 分情景/语义两仓。

**与已有概念的关联**：
- 分层标准：[[三层记忆]]；存储底座：[[向量数据库]]
- Voyager 技能复用 ≈ [[AgentSkills技能包]] 的运行时版
- 与 [[RAG架构谱系]] 共享向量底座但目的不同（治"记不住" vs 治"不知道"）
