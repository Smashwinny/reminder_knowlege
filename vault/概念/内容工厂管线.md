# 内容工厂管线

**一句话**：面向社交平台的量产内容管线 = 素材获取（yt-dlp）→ 语义选择（金句时间轴）→ 精确切分（取帧+字幕条裁剪）→ 版式排版（先拼源像素再统一缩放）→ 契约质检（几何回归测试+人工否决回路），每一环都可自动化但保留人工闸门。

**领域**：内容生产 / 社交运营。来源：[[项目笔记/native_subtitle_quote]]（39+17 全绿测试+合成视频端到端实测）。

与 [[生成后处理管线]]（sprite_gen，机器消费）相对：本概念面向流量消费，契约从 manifest.frame_layout 变为平台比例（3:4）+ 质检标准。

伦理红线：原生不重绘/脚本不冒充——信任是内容资产的抵押品。

质量哨兵：几何回归测试（圆形不变形）；先拼后缩放防首句变形。

交付决策：捆绑运行时（imageio-ffmpeg）免除环境地狱。

反模式：用 AI 重绘冒充原生截图；让平台比例当最后一道工序（应为契约起点）；无否决权的全自动量产。
