# 概率校准与温度缩放

**一句话定义**：校准 = 模型说"90% 把握"的事真实发生率确实接近 90%；温度缩放 = 对输出 logits 除以温度 T 再 softmax 的校准修正手术（T>1 变谦虚，T<1 变自信）。

**属于领域**：AI / 模型可靠性（置信度能不能直接当业务数字用）。

**通俗理解**：天气预报说"90% 下雨"的日子，十次里真下九次——这就是校准。衡量指标 **ECE**（期望校准误差）：把预测按自信度分桶，比"平均自信"和"实际对率"的差距。**校准 ≠ 准确**：Laya 温度夹紧修复让 51 语言宏平均 ECE 0.733→0.571，准确率一个百分点没动（温度缩放不改 argmax）——自信程度和答案对错是两个独立旋钮。反面教材：英文 checkpoint 在印地语上准确率比乱猜高不了多少，却自信拉满（ECE 0.855），"自信地错"是校准失效的极端形态。

**实测坑**：Laya checkpoint 自带按选项数分桶的温度表，本机首调即遇 `choice:11+ 桶温度 0.1006 超出 [0.5,5] 被夹到 0.5、该桶置信度视为未校准` 的 RuntimeWarning——用置信度前先看有没有这种告警，必要时用仓库自带校准工具（fit_abstention_thresholds / fit_binning_map）在自己的数据上重校。
