# 私有子图输出隔离

**一句话定义**：把每个并行 agent 编译成一个自带私有消息历史的子图，子图与外界只通过 output_schema 暴露的少数键交换数据——并行成员互不可见对方的工具报文和中间消息。

**属于领域**：AI Agent 并行编排

**通俗理解**（类比，讲完落回术语）：像考试时每个考生有自己的草稿纸，交卷只交答题卡。草稿纸（私有消息历史）上怎么演算随便你，但别人看不到、你也别想看别人的；答题卡（output_schema 的 report_key）才是唯一进入公共状态的东西。TradingAgents 的实现：`StateGraph(AgentState, output_schema=TypedDict(..., {report_key: str}))`，4 个分析师并行时各自在 ThreadPoolExecutor 线程上跑自己的"agent↔tools"小循环，共享状态里只多出各自的报告字段。还带一个 wrap_up 兜底：数工具调用轮数，超过 max_tool_rounds 就注入一条 HumanMessage 勒令交报告，防止模型无限调工具打爆递归上限。
