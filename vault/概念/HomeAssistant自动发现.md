# HomeAssistant自动发现

**一句话定义**：Home Assistant 订阅 `homeassistant/#` 主题，设备桥（如 Zigbee2MQTT）每接入一台设备就向 `homeassistant/<组件>/<设备ID>/<对象ID>/config` 发布一条发现消息（retained），HA 收到即自动创建对应传感器——零配置接入。

**属于领域**：智能家居系统集成 / 约定优于配置

**通俗理解**（比喻/例子，讲完落回术语）：发现消息是设备的"出生证明"：写清数值去哪个主题取（stat_t）、从 JSON 哪个字段取（val_tpl）、单位是什么、设备叫什么名字。HA 不用预先认识任何设备，凭证据自助建档。retain 标志保证 HA 重启后重新订阅仍能立刻拿到所有出生证明。
