01 / 它是一个模型，还是转接层？

【源码证实】magpie 是模型配置、路由与协议适配工具，不提供模型权重。Agent 保留任务循环，网关接收请求并选上游；插件扩展供应商。README 宣传的“体验一样”不等于能力、权重或政策相同。

[S2] magpie README 中文：范围与默认地址 [S3] Anthropic 解析：消息类型

02 / 本地网关为什么仍可能泄露数据？

【源码证实】本地只描述监听位置，不代表推理离线。插件文档说明会使用认证状态，服务端仍处理提示词。源码 README 还写有自动账号发现；本次因此不启动 magpie，只用不读环境和账号的自写网关。

4. 用量对账

python3 ma-laoshi-20261111-test_gateway.py usage

目的：区分成功请求、尝试数和合成计数，不做费用估算。
真实结果：success=2，upstream_attempts=2，input_units=4，output_units=4，rejected=0。

5. 故障与拒绝契约

python3 ma-laoshi-20261111-test_gateway.py errors

目的：检查不支持能力不静默丢弃，并注入模拟上游故障。
真实结果：6类本地拒绝且上游0请求；模拟503→502；假Authorization被400拒绝，最终上游仅1次且成功0。
验收：404/501/400状态断言，503不记成功；所有服务finally关闭，打印CLEANUP。

不要把 mock 成功升级成产品结论

自写测试是回归检查，不是第三方独立审核。mock响应固定为“mock answer”；合成输入计数是split空白词数，输出固定2。未提供真实模型、SSE/取消、工具执行、多模态、缓存、账号轮换、真实配额、安全审计和负载性能验证。

本程序只服务本地教学。不要放到公网、不要接入真实凭证、不要用作生产代理。临时端口在每组测试结束后关闭，无常驻服务。

初次提取公开HTML时使用python命令，环境报python: command not found（退出127）；随后明确改用python3成功。WebFetch原帖403，但普通公开curl得到200并含完整长文。Kiro terms-of-service尝试404，官方ACP路径抓取403；均未绕过登录或安全设置，未将失败页作为政策证据。
