# 实验日志 · 上海交通大学生存手册

- 实验：一周时间投资审计器（time_invest_audit.py）
- 环境：Windows 11 Pro，Python 3.14（C:\Python314\python.exe），`PYTHONUTF8=1`
- 日期：2026-10-07

## 实验设计

手册《正确地浪费剩下的时间》提出任务价值四档（终身/中期/短期/负向）。本实验把该框架实现为标准库 Python 脚本：

1. `exercise/week_log.csv`：三列时间日志（date,activity,hours）。
2. `exercise/time_invest_audit.py`：CATEGORY_MAP 关键词→档位映射（可编辑）；统计四档时长与占比；计算"时间投资评分"（终身×1.0 + 中期×0.5 + 短期×0.1 − 负向×0.5，归一百分制）；终端输出 + 生成彩色 HTML 报告 `report.html`；附手册《你的身价是多少》2024 价格锚点表。

## 真实执行记录

### 运行 1（原始示例数据，16 条记录）

命令：`PYTHONUTF8=1 python time_invest_audit.py`

输出（实测原文）：

```
记录总时长：26.0 小时
终身受益    11.0 小时 ( 42.3%)
中期影响     3.0 小时 ( 11.5%)
短期满足     4.0 小时 ( 15.4%)
负向消耗     8.0 小时 ( 30.8%)
时间投资评分：34.2 / 100
```

报告文件：`exercise/report.html` 已生成。

### 运行 2（改参数验证敏感度）

改动：
- CATEGORY_MAP 中 `"学校英语课": "shortterm"` → `"lifelong"`（反思：认真上的语言课收益是长期的）
- 新增映射 `"帮同学调试代码并写复盘": "lifelong"`
- week_log.csv 追加一行 `2026-10-04,帮同学调试代码并写复盘,1.5`

重跑结果（实测）：

```
记录总时长：27.5 小时
终身受益    14.5 小时 ( 52.7%)
中期影响     3.0 小时 ( 10.9%)
短期满足     2.0 小时 (  7.3%)
负向消耗     8.0 小时 ( 29.1%)

```

评分 34.2 → 44.4，占比与评分联动正确，report.html 同步更新。参数确实驱动结果。

## 结论与坑

- ✅ 框架有效：示例数据暴露"负向消耗占 31%"的问题，与手册"平庸的生活方式是麻醉药"的警告对应。
- ✅ 工具可复用：换真实数据即可成为每周习惯；未登记活动默认中期档并在终端提示，避免静默错分。
- 坑 1：Windows 中文终端需 `PYTHONUTF8=1`，否则 CSV 中文活动名在 GBK 下可能解码异常。
- 坑 2：未在 CATEGORY_MAP 登记的活动会落入默认"中期影响"档，审计时应先补登记再跑。
- 局限：评分权重（1.0/0.5/0.1/−0.5）是教学用设定，非手册原文；四档归类含主观判断。
