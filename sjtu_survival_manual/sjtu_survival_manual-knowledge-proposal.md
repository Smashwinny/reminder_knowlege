# 时间价值四档

**一句话**：任务的价值取决于它在时间尺度上的作用效率，按影响时长分四档决定做不做。
**领域**：学习方法 / 时间管理。来源：《上海交通大学生存手册·正确地浪费剩下的时间》。

- 终身受益（多做）：对整个人生产生正面影响，如锻炼、专业素养、表达能力
- 中期影响（适度）：对中期未来产生影响，如 GPA（保研/转专业场景）
- 短期满足（少做）：转瞬即逝的愉悦，如形式主义会议
- 负向消耗（避免）：熬夜、被当壮丁使唤

**关联**：[[高考思维]]（评分只是中期档的指标之一）；
与"证据优先质检"互补——时间投向可验证的能力积累。
**应用**：[[sjtu_survival_manual]] 项目的时间投资审计器实验；可用于 400+ 学习项目的优先级分级。
```

# 高考思维

**一句话**：用一个量化分数概括衡量一个人的思维方式，在应试教育中登峰造极并延续到大学。
**领域**：认知偏差 / 学习方法。来源：《上海交通大学生存手册·失败的思维方式》。

核心论断："如果一个人把政策评分作为自己的至高追求，那么他就是这个政策的牺牲品。"
大学仍有无数评分（考试、综合测评、保研、出国），毕业出路与入学分数关系不大、方差极大。

**关联**：[[被动思维]]（一体两面）；[[时间价值四档]]（GPA 多为中期档）；
[[证据优先质检ProofOverClaims]]（分数是指标不是证据）。
```

# 被动思维

**一句话**：做什么事都需要外部给理由、无主见地忙碌的思维模式。
**领域**：认知偏差 / 学习方法。来源：《上海交通大学生存手册·失败的思维方式》。

"怕点名""抄作业""记考点"只是被迫的借口，心悦诚服的理由只应是求知欲；
当自学效率显著高于课堂时，应理性选择自学。

**关联**：[[高考思维]]；[[时间价值四档]]（被动承接的任务多落入短期/负向档）。

# 信息素养

**一句话**：信息的查找获取、理解吸收、评价、使用、加工、呈现与信息安全的综合能力。
**领域**：通识能力 / 信息安全。来源：《上海交通大学生存手册·认识信息素养》。

要点：提问前先自行搜索；政策看官网原文；会截图会打码；发文档删作者信息；
群发用密送；警惕钓鱼邮件与下载助手类骗局。信息差 = 信息素养差距 = 价值差距。

**关联**：[[高考思维]]（独立思考、不被带节奏）；[[被动思维]]（主动获取 vs 被动等待投喂）。
