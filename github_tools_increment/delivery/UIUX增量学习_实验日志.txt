== 结果解释 ==
加词后换了产品类别：输入 SaaS dashboard accessible 命中 SaaS (General)；完整输入追加 dark mode 后命中 Smart Home/IoT Dashboard。这证明本版本此样例的查询敏感性，不是独立颜色参数的因果对照。
空检索与默认推荐同时存在：无关 UX 检索返回0条；无关生成需求 zzqqxx flarble blorpt 的 reasoning_default=true，产品与规则来源为空，但仍有回退建议。不能把输出完整误当成资料命中。
原值与派生都有可核对路径：三个生成样例的来源身份逐一解析；每个样例的20个颜色输出字段与所选配色原字段一致。另一个固定 SaaS 类别的暗色函数对照改变7个颜色字段并标记 derived-dark，焦点环/背景数值对比度约3.4541。这个数值不是页面无障碍合格证。
本地实现是顺序检索与确定性规则：普通生成链实际顺序调用 product、product、style、color、landing、typography 共6次搜索；中间重复的产品结果之后被最初结果覆盖。README 的5路并行描述与这段代码不同。
验证计数与覆盖范围分开：61项自建证据检查全过；选定上游73个测试方法全过。未运行全部测试模块、完整CI、持久化与覆盖测试。固定快照和样例可重现，不等于任意需求都能获得正确设计。
